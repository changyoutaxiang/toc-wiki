# 当前判断

入门期薪酬倾斜是 Q2 提升新招老师质量的高确定性抓手之一。  
它的核心不是普遍加钱，而是把有限预算集中投向老师入门阶段的课时费和首月保障收入，用更直接的因果链改善招募质量。

- Agent 下一步: 继续跟踪它和薪酬改革主方案、B+ 目标、直通车项目之间的联动是否被真正写实

## 为什么它重要

- 比 Rebook / MyStudent 这类结果指标激励更直接
- 更不容易被运营动作或口径问题扭曲
- 能更快影响老师是否愿意加入、是否愿意在早期留下来
- 与宽带薪酬、直通车、收入保障计划天然联动

## 当前共识

- 大部队底薪不需要一起抬升
- 更优打法是把钱集中投到新老师最脆弱、最关键的起步阶段
- 如果资源必须二选一或三选一，优先级高于部分易被 manipulate 的结果奖金
- 它既是招聘质量抓手，也是供给端价值传输抓手

## 主要设计方向

- 入门阶段课时费倾斜
- 首月收入保障或 Guarantee Pay
- 与 B+ 新老师收入保障计划形成配套
- 明确边界，避免长期高成本失控

## 当前待回答的问题

- 倾斜力度多大才足以改变行为
- 首月保障的适用人群和退出机制怎么定
- 与宽带薪酬原方案如何配套而不互相打架
- 高薪保护期结束后的留存和 ROI 怎么评估
