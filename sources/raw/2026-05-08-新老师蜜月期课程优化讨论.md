# 会议摘要

这次会议把“老师质量战役”收缩到了一个更具体的小战场：**新老师里的 A/B+ 优秀老师 + 新生蜜月期课程优化**。

## 1. 核心转向：从宏大叙事切到具体问题

- 过去容易从“沟通阵地 / 沟通矩阵”这类宏大概念出发，容易滑回纯供给思维
- 现在明确转向：先把 **新老师中的好老师** 给 **新生蜜月期课程** 用好
- 这个小切口和退费率、升舱续费直接相关，更容易看见业务结果

## 2. 为什么只盯这个小切口

- 当前新教师里 A/B+ 占比约 13.4%，但利用率只有约 35%
- 这部分老师本质上是“货压仓库”，先把这批好老师用透，比继续盲目扩池更有价值
- 用好这批老师后，可以形成正反馈：老师赚钱 → 我们敢加大投放 → 吸引更多好老师
- 新生蜜月期的前几节课，直接影响退费和升舱，是当前最该优先优化的窗口

## 3. 关键认知：蜜月期里，体验细节比教学能力更直接影响退费

对于零基础新生，深层教学能力不容易在一开始被感知，真正更直接影响退费的，是肉眼可见的体验问题，也就是会议里说的 **“五害”**：

1. 课前缺席（爽约 / 临时换课）
2. 课中缺席
3. 迟到
4. 早退
5. 网络卡顿 / 设备问题

结论很明确：如果是为了尽快改善退费率，先把“五害”压下去，比优化老师教学能力更直接。

## 4. “密钥”主张草稿

会议中形成了一版很适合做成项目主张的草稿：

1. **百分之百优选**：从现有新教师里，用数据 + 质检筛出无口音、低五害的优质老师，优先匹配给新生蜜月课
2. **百分之百备课 + 培训**：课前推送学生信息、示范课培训，要求提前备课，首课通过考核后再授课
3. **0% 五害**：通过标签和管控，把蜜月课里的五害尽量压到最低
4. **百分之百质检**：所有蜜月课都要有质检
5. **百分之百共享视野**：学生、老师、质检结果同步给课程顾问、学管、家长，方便协同调整

## 5. 后续待办

- 重新梳理“密钥”主张，至少输出两个版本，方便沟通
- 联动凤头（凤和）退费率项目和直通车项目，避免重复作战
- 拉取退费原因里教师问题的真实占比
- 拉取新生蜜月期老师网络问题明细，给老师打风险标签
- 把这个小切口做成可验证的退费率 / 升舱优化试点

## 6. 对战役脑的影响

- 这不是新的大叙事，而是把老师质量战役压成一个可执行的小战场
- 如果跑通，后面可以再滚动扩展到更大范围
- 这个方向与好老师生命周期、老师质量飞轮、沟通基建、直通车都有关联，但落点更具体
