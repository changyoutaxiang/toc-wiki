## 当前判断

直通车项目仍然是 Q2 高确定性的 Quick Win 之一，但它的角色已经从“把老师送到前线”进一步转向：**把在库好老师快速出清、快速满约、快速进入商业循环**。
2026-05-09 之后，它的落地形态进一步清晰为 **Trial Only / 体验课绑定常规课**：把高潜 leads、最会卖的 CC、可包装的 A/B+ 老师和可锁定的常规课档期捆在一起，服务 M0 转化率提升。

它的价值不止是把老师送到前线，更重要的是让家长获得“所见即所得”的确定性：体验课喜欢这个老师，当场就能锁定未来常规课档期。这个确定性比老师 60 分和 65 分之间的体感差异更能促单。

### 2026-05-08 新判断

- 当前问题已经不是“愁货源”，而是“愁售卖”
- 月新增两三百名老师，但 4 月新老师利用率只有 8.5%～14%
- 所以优先级要从搭供给转向做出清：先把在库好老师卖出去、用起来、跑起来
- Fast Track 不是重建系统，而是轻做方向与主张，让菲律宾供应链团队去落地
- 真正的主战场是 A / B+ 新老师运营出清

### 2026-05-09 Trial Only MVP 新判断

- Trial Only 是直通车从“好老师出清”进入“绑定业务转化”的落地形态。
- 业务目标被明确量化：小红书直播渠道 M0 已从 4% 提升到 6.4%，Q2 底线要拉到 8%，对标 Poly。
- 合肥 4999 元小课包“小船模式”已跑出较好转化，5 月要复制到上海 7000+ 元“大船”，高客单会放大“体验课/常规课老师割裂”的抗性。
- 合肥团队对 Trial Only 需求最强，也最适合作为 MVP 场；先跑闭环，不急于追求严格 A/B。
- Trial Only 的底层逻辑是“掐尖 + 强强联合”：最有脑子的销售 + 最优质 leads + 筛出的优质老师。
- MVP 阶段可以“积极作弊”：课前深度备课、课后 CC 高频介入、针对性反馈，把转化率再向上拔 0.5–1 个点，用来验证机制上限。
- 核心杀手锏不是“师资绝对碾压”，而是“所见即所得 + 当场锁定常规课档期”。
- 体验课后当场锁定未来一个月常规课排期，是把好老师价值转成成交理由的关键动作。
- 硬件/网络标准被上升为老师能力硬门槛：未来 4–5 个月，硬件好坏会成为老师质量的“阶级鸿沟”。

## 项目定义

- 打通体验课与付费课的老师供应链
- 让学生试听满意后，后续还能继续约到同一位老师
- 让好老师更快满定、更快挣钱、更快留存

## 当前战略意义

- 它是价值传输机制，不只是流程优化
- 它既是智能匹配项目，也是商业转化项目
- 它是老师质量飞轮里的“商业反哺”抓手：如果好老师真的有价值，应该最早在新学员报名、前 10 节课、M0 转化中被验证
- 它能把在库 A/B+ 老师从“库存”变成“可售卖商品”，缓解新老师利用率低的问题

## 当前已知设定

- 初期可以先人工跑，不必等待完整系统化。
- Trial Only 当前优先合肥团队 / “锦州之战”项目组，而不是一开始多区域铺开。
- 业务范围只做青少儿 ESL（听口、词汇语法、自然拼读等），暂不做成人。
- 当老师产能接近约满时，应退出直通车，这是好结果而不是失败。
- 负责人定位仍与黄荣Sophia（Sophie） 教学专业线相关，Leon 负责跨业务、运营、产研推进。

## MVP 设计

### 试点场景

- 优先合肥团队 / “锦州之战”项目组。
- 业务形态：4999 元小课包标品，小船先跑通。
- 对照背景：同样小红书渠道，合肥转化约 6.31%，上海约 3.02%；MVP 阶段先用合肥单点跑流程闭环，后续再考虑更严谨 A/B。
- 未来扩张：如果合肥跑通，再服务上海 7000+ 元“大船”复制。

### 师资范围与包装

- 优先盘活现有池子中未被充分利用的 A / B+ 老师。
- 发音、形象、网络、设备是基础门槛；硬件/网络不再是附属项，而是 Trial Only 老师能否被售卖的硬条件。
- 统一老师包装：专业自我介绍视频（含教学片段）、形象照、教学经验 / 证书（如 Tesla 等），以链接形式给 CC 直接发给家长。

### 排课与生命周期

- 系统标签：FDR (Regular)。
- 核心高峰时段：18:00–20:30。
- 产能要求：每周不低于 30 slots。
- 可见性：FDR slots 对试点销售团队隔离可见，不开放普通随机分配。
- 生命周期：暂定 8 周；按转化率、出席率等动态考核。
- 退出机制：不达标淘汰；表现优异且课表排满后回归常规池，并可升级为项目“培训师”。

## CC / 销售打法

- 坚决放弃“课前 2 分钟随机分配体验课老师”的开盲盒模式。
- 采用人工销售代约制：CC 扮演“媒婆”，左手盯高潜家长，右手盯 FDR 专属 slots。
- 体验课完成后，当次沟通里直接锁未来一个月常规课排期，例如一周两次。
- 引入直播间稀缺话术：优质外教是稀缺商品，“今天不占坑，明天档期就没了”。

## 教学与销售闭环

- 黄荣Sophia（Sophie） 负责输出强标准化教学 SOP，例如核心词汇带读次数、关键互动动作、课后反馈格式等。
- 教学 SOP 要二次加工成《教师手册》/销售武器，让 CC 先谈专业、再谈价格。
- 教师课后 Feedback 不只是给家长评语，还要给 CC 具体转化线索，服务成交。
- 协作原则：黄荣Sophia（Sophie） 懂教学标准和项目模型，但不熟 51Talk 现有系统分配机制；业务、运营、产研必须主动暴露系统限制和历史坑点。

# 风险清单

| 风险 | 判断 | 缓解方式 |
|---|---|---|
| 系统基建跑不动 | FDR 标签、隔离可见、代约、链接展示都依赖产研 | 先用最小人工流程跑 MVP，同时把系统需求拆成必需/可后置 |
| 老师资源被体验课池和常规课池抢夺 | FDR 专属池可能与现有排课机制冲突 | 明确 8 周生命周期、退出机制和课表排满后的回归规则 |
| CC 只会卖稀缺，不会卖专业 | 容易变成低级饥饿营销 | 用《教师手册》把教学 SOP 翻译成销售话术，先谈专业再谈价格 |
| 黄荣Sophia（Sophie） 方案脱离现有系统约束 | 她懂教学，但不熟公司内部系统 | 所有协同方必须主动暴露系统限制和坑点 |
| MVP “积极作弊”不可规模化 | 课前深备和课后高频介入可能只是小样本加料 | 明确区分试点加料与规模化 SOP，先验证上限，再抽象可复制动作 |
| 高硬件门槛减少可用老师池 | 未来 4–5 个月硬件会成为阶级鸿沟 | 与设备分/硬件采购/电脑租赁项目联动，提前把硬件变成可运营变量 |
| 上海大船复制失败 | 高客单价下家长更敏感 | 先在合肥跑出机制和话术，再迁移到上海，不要一开始双线硬推 |
