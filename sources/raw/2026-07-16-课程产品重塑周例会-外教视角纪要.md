## 一、上线时间线与牛津合同（外教供给相关）

- **国内**：7/22 起市场端一对一体验课逐步放量（只放 3 个 level、每 level 50%）；7/14 发布预热、**7/21 国内正式发布**；**8/1 起统一售卖全新 Cocos 课程**（前端全面售卖）。
- **中东**：**7/19 上线**（上线宣传绕不开牛津）。
- **🔴 牛津合同延迟**：预计要到 **7/24** 才能出（牛津英国总部流程慢）。中东侧 7/8（日庆）曾发出一个含牛津的链接被英国总部发现、已投诉过来——外宣口径受约束，19 号上线的牛津话术要规避。

## 二、Cocos 课件教师培训进度

- **体验课**：海外 6 节 + 国内 3 节，**95% 已培训完**，满足 7/19 中东上线前的体验课老师需求。
- **付费课**：两渠道——①招聘新老师 **7/14 起全部改培训 Cocos 课件**（H5→Cocos）；②一站式 7 月底改完、8 月上线。产业侧做 Cocos 标签自动化（海旋/长青负责）。**从昨天起所有新老师培训全走 Cocos，每月 2000 新进量。**
- **打标缺口**：国内老师培训率覆盖 40%，但 Cocos 打标签占比只 30%——**约 10% 老师培训完却不够格打 Cocos 标签**（设备问题）。NTT/CE pass 率没掉、NTT show up 掉（判定与 Cocos 培训无关）。结论：教师端**不会成为上线卡点**，供给侧越来越乐观（源头新老师都已签）。

## 三、设备 / 版本 / 回退 / GPU（与上午 Cocos AC 治理会同源，此处从课程产品角度）

- **40% 老师不升级**→强升计划分批"小船换班"（升 100 回退 30、再升再退，最后回退那部分放弃、直接干掉标签）。要求把小船换班情况**放进外教侧一起汇报**（"很重要的闭环"）。
- **回退归因**：老师回退多因上课出问题（教材加载不出 / PDF 乱码 / 音视频撑不住）——是自我保护机制。下周**用蜂巢专门归因、实时监控这波强升老师**。
- **GPU 手动关**：部分老师标签/设备都达标，却手动关了 AC 的 GPU 加速开关→客户课件出问题；已有埋点能监测、跑出一批给海泉去通知。定性：**不新增为招聘标准**（现有标准 90% 已自动覆盖）。
- **付费课固定老师**：收藏/固定老师若中途换设备致不达标→**临时下线、从推荐列表去除**（产品化）；需梳理"何时拿掉 Cocos 标签、拿掉后对客户体验影响"的业务流程。

## 四、🔥 Leon 现场把"新师训营认知突破"带进课程产品团队（往共识推）

同一套 07-16 和 Sophia 谈的 reframe，Leon 在本会讲给曲老师/产品团队并寻求共识：

- **主要矛盾不是口音/教学技巧，而是负体验占比太大。** "口音好难干预，这玩意（网络/设备/负体验）可干预，而且用户更 care 这个，不是那些我们以为改不了的东西。"
- **Poly 对标（车厘子模型）**："他的四勾车厘子跟我们差不多、二三勾也差不多，**但他没有一勾车厘子，我们一勾车厘子比他们多**。Poly 聪明两点：①把四勾（最好的两三百个）摆店前玩命包装造 noise（精品水果店 vs 普通水果店）；②把一勾（最差的）都删掉。"
- **未来老师 = good driver**："教学水平更多像 Cocos 包装、用产品能力吸掉；未来老师是非常好的客户驾驶员，七个模板哪个都会点、很熟练——这是试用期出营要求。经过试用期别有断网掉线、黑看不清楚，那就是好老师。"
- 团队回应印证：用户绝大部分投诉确实不是口音；核心是网络/硬件（老师 CPU 跑满→"渣渣"），学生以为是老师问题（老师是他唯一能接触的人）。**"if 成立，几个月内就能在客户价值上让我们老师追平（对标对象）。"**

## 五、🔥 "一勾车厘子"识别与淘汰——新监控能力打开的新战场（与 Selina 共识跨会互证）

- **新能力**："过去脑子里只有四害（缺勤/迟到/早退），有数据；但**网络 / CPU 稳定性过去没有监控指标，现在有了、能看见了**——这是用户最大的体验问题。"（100% 单课程质检是以前没有的能力。）
- **不只新老师**：会上提出"要把现有几万个老师做一次诊断"，不能只诊断新老师。
- **动作**："从这个视角能筛出 **10%–20% 有问题的老师**……一勾的都给他搞出来。不用都踢走——**特别严重的踢走，其余慢慢降权、打标、不让约新生**，切断跟新生的关系，几个月自然淘汰。"**"后面卡顿的数据应该统计到老师身上，推荐老师时也用。"**
- **成本极低**："**仅限 1 万块钱、一天就能干成，一勾车厘子翻一遍，我们就知道谁是一勾了。**"（好车厘子好好整"一两个月这仗就打完"。）

> 这条与今天上午和 HR Selina 的共识（把反复出 PC/网络问题、造成"基础体验崩溃"的约 10% 老师数据辨识出来、给流量惩罚甚至下线）是**同一件事，两个会独立收敛**。

## 六、呈现层落地 + 模板军规（呼应昨天 Top 300 / 呈现层差距）

- **精彩表现视频**：报告产品化里，Leon 强调"要看用户，Polly 找这些点很强——**他们老师就必须要有视频**。精彩表现 = 高潮部分，**家长会很有感觉，不管中东还是国内**。"（直接落"呈现层差距 / Top 300 极致包装"到课程产品的家长报告里。）
- **模板高可用性军规**（Leon，苹果品控类比）："模板不能只看炫酷——**如果测试不能保证稳定和高可用，宁可不做**。这是技术团队和徐老师学术团队要明确的标准、要建立高可用测试流程；渠道也要理解这个技术逻辑。"

## 七、中东 Cocos 体验课 AB 测数据（放量 6/5–7/15）

- A 组 = H5 课、B 组 = Cocos 课；Cocos 总完课 **457 人**（中东），放 L1/L2 两个体验课、约占实验 45%。
- **90% 的课能在 Cocos 上完**（老师没换 PDF）；切 PDF 主因：学生 APP 版本过低 / 无 Cocos 标签 / 后进教室分到非 Cocos 老师 / GPU 关。看三个数：完课率（90%，相对安全）、完课质量（卡不卡顿，拿去和同老师 H5 数据比对）、课中教师主动切换（最该关注）。
- ⚠️ **AB 测转化率结论暂不可用（勿被"90% 完课"误读成利好）**：同会另一口径显示 Cocos 组转化率低于 H5 组，但会上定性为**测试设计缺陷**（难度错位 + 早期样本偏差）造成、非产品本身差，需从 7/1 切片重算并补 level 粒度对比。完课率（体验通畅度）与转化率（商业效果）是两个数，别混。〔来源=同会全会自动轻纪要 [[journal/2026/07/2026-07-16/_agent/轻纪要-课程产品重塑周例会-2026-07-16]]，DWS 听记管线独立生成、与本外教视角摘录互证〕

## 可沉淀判断（外教战役相关）

- **认知突破在跨部门扩散**：07-16 "负体验>口音 / good driver / 教学吸进 Cocos" 的 reframe，当天已从「和 Sophia 单聊」推进到「课程产品重塑会上和曲老师/产品团队找共识」——不再是一个人的直觉，开始变组织共识。
- **【新战场】一勾车厘子识别 = 新监控能力（网络/CPU 稳定性）打开的低垂果实**：过去无指标、现在能看见；成本极低（"1 万块一天翻一遍"）；处置 = 降权打标不让约新生、卡顿数据归到老师身上。与 Selina 共识跨会互证，可作为独立于新师训营的一条并行动作线。
