# 外教触达原子小队周报

:::
**外教触达目标**

在AC中增加触达通道，提升外教触达的及时性和阅读率
:::

## 周报维护原则

*   每周更新一次，最新一周放在最前；历史周次保留，持续形成路线与进展记录。
    
*   进展只写可验证结果，并区分：开发中、已联通、已验证、已上线。
    
*   业务需求必须同时说明对蜂巢框架的验证点，避免只交付业务、不沉淀框架能力。
    
*   下周计划必须写清交付物与完成口径；非下周承诺单独进入后续路线。
