## 常规纪要

### 核心结论

1. **已上线动作成效显著：NoNoti 缺席 400–500 → 200+（降约 40%），连续缺席从 1.3+ → 1.0，确认出席率 24% → 45%。** 海外与国内趋势一致；"老师确认出席后 100% 到场"——确认机制有效且老师不说谎，下一步治理重心转向 availability（可预约性）而非确认本身。
2. **NoNoti 两大根因定位：①开课前 0–2 小时紧急约课（sudden booking）缺席风险高（约 10%–14% 课时占比，含部分临时代课 sub）；②新老师/回归老师前 10 节课高缺席（8 月新 launch 中约 25% 已 inactive）。** 两个根因分别对应方案一（Toggle 开关）与方案二（新师前 10 课规则）。
3. **本场拍板：方案一先灰度测试（白名单小范围、约百人级），方案二 9/1 上线测试；两方案错开以保归因。** 方案一已开发（全量老师可用开关），方案二开发中（预计 9/1 前完成）；先测方案一、9/1 测方案二，避免同时上导致无法判断哪个有效。
4. **Leon 以 sponsor 身份做授权决策：DRI 制 + 四象限第三象限（小范围有影响）→ "go but set control"。** 明确海璇（Shayne）为 DRI，吸收全部 feedback 后自己做决策，Leon 团队当 sponsor；切"可承受的量"、把监控指标说清楚、证据出现立即调整。该原则适用于全部原子小队（含菲律宾）。
5. **产品机制分歧收口：给老师开关权限 vs 系统硬控。** Jovic 主张"不给老师这个权力"（避免 Q4 圣诞季老师大量关闭导致求老师开开关、产能危机）；Katherine/Tao 主张老师可控性（系统无法预判谁不能接紧急约课）。收口：方案一保留老师开关但先小范围测开/关比例，用真实数据决定全量策略；方案二（新师前 10 课）走系统硬控。

### 可沉淀判断候选

- **确认制优于惩罚制**：老师确认出席后 100% 到场，说明"先说清后果 + 让老师主动确认"比事后惩罚更有效，且老师诚实不滥用；治理重心从确认转向 availability。本地正本指针见 [[projects/TOC/战役/战线/原子小队上线治理/2026-08-25_外教战役原子小队_认知增量日报与CEO-AI回复_蒸馏正本]]。
- **DRI 授权四象限落地样例**：第三象限（小范围 + 有影响）"go but set control"——切可承受的量、监控指标明确、证据出现即调；Leon 只 reinforce 方向与原则、不指点具体方案。本地正本指针见 [[projects/TOC/战役/战线/原子小队上线治理/外教战役原子小队_信息透明与上线决策纪律_v0.1]]。
- **产能与缺席治理的张力需数据回算**：开关功能若全量推广，老师大量关闭会削弱可预约产能（Q4 圣诞季风险），capacity summary 页本身不准；灰度开/关比例是回算真实产能影响的前置输入。

## 基本法审视

- **本场启用包**：`系统化交付`（数据驱动灰度 + 监控指标 + 退出机制贯穿全场）；`原子小队和任务制`（DRI 决策、sponsor 授权、四象限纪律本场直接落地）；`蜂巢三原则`（简单规则 2h/10 课/5 节、信息流向决策节点、真实结果反馈迭代）
### 系统化交付
- **基本法原文依据**：第 2 条《坚持系统化交付》｜"可重复、可观测、可纠错，并有真实结果与独立证据"
- **本场证据**：NoNoti 400–500→200+（约 -40%）有 dashboard 数据佐证；方案一、二均以灰度 + 白名单小范围 + 开/关比例/缺席率数据回算决策；Leon 明确"证据出现改变观念，没有面子""数据不好马上下线不丢人"。
- **判断**：正向样板。治理链条（根因定位 → 双方案 → 灰度 → 数据回算 → 退出机制）可重复、可观测、可纠错。
- **要补的闭环**：灰度期的监控指标集（开/关比例、NoNoti 降幅、产能影响）需 DRI 明确写出并落到 OB/看板，作为"证据出现即调"的判定依据。

### 原子小队和任务制
- **基本法原文依据**：第 4 条《探索原子小队和任务制组织的新工作方式》｜"明确 DRI、授权边界、资源、结果收据与退出条件"
- **本场证据**：Leon 明确海璇为 DRI（"你是 DRI 吧""我们就得授权你干"）、sponsor 制（"我们当你的 sponsor"）、授权边界（切可承受的量、量小、不行赶紧撤）、退出条件（证据不达即下线、五节硬停）。
- **判断**：正向样板。本场是原子小队工作方式（DRI 决策 + sponsor 授权 + 快速试错）的完整落地样例，并明确"该原则适用于所有原子小队（含菲律宾）"。
- **要补的闭环**：DRI 两句话决策（范围 + 证据触发条件）需书面化并回传 sponsor，作为本场"结果收据"；后续灰度结果需按约定回验是否调整范围。

### 蜂巢三原则
- **基本法原文依据**：第 5 条《蜂巢组织的三原则》｜"以简单规则明确目标、边界、责任和红线…让带来源、状态、时效和权限的信息流向能判断和行动的节点…通过真实结果反馈迭代"
- **本场证据**：规则简单化（2 小时紧急约课窗口、前 10 课默认关、连续 5 节停排）；数据面向相关人开放（"数据我都给他们开了"）；灰度测试 + 开/关数据回流决策节点（DRI），迭代下一轮动作。
- **判断**：正向样板。三原则在坏课治理中均有落地证据，尤其"信息流向能判断和行动的节点"——数据直接开放给 DRI 做决策。
- **要补的闭环**：灰度数据的时效（何时回看、回看哪几项）需与 DRI 决策节奏对齐，避免数据回流晚于上线决策。
