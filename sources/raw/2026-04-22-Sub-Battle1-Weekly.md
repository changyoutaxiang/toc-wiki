# 当前判断

这次 weekly 的核心，不是继续讨论“量要不要追”，而是把视角明显切到 `在 Launch 仍需达标的前提下，如何尽快把 B+/A 质量目标做成执行口径`。  
会议里最有价值的信号有三类：质量目标从百分比翻译成绝对数、国内外 demo / entity 表现差异需要校准、以及若干影响转化的具体 friction 已被点出来。

## 关键共识

### 1. 战役压力正在从 quantity 切到 quality

- 团队明确提出，前一阶段主要在救 quantity
- 现在要快速切到“如何做到 15% quality”
- 讨论口径已经开始从被动救火转向更客观地看 pass rate / quality gate 是否合理

### 2. B+/A 目标的执行口径应按绝对数管理，而不是只盯百分比

- 会议明确澄清：4 月没有硬性 15% 目标，5 月与 6 月开始进入 15%
- 执行层应把 15% 直接换算成每月 launch target 对应的绝对数
- 例子：若月度 launch target 为 2000，则意味着约 300 个 B+/A 老师
- Q3 的目标被继续指向 25%

### 3. 国内外在 entity / demo 环节存在明显表现差异

- domestic 在 entity passing rate 高于 overseas
- 但 domestic 的 demo passing rate 明显低于 overseas
- 会议把这定性为需要继续校准 trainer / screener / rubric 的问题，而不是简单归因为原料变化

### 4. CEFR / demo 评价体系需要继续标准化

- 当前不少 screener 是新人，对 CEFR / 内部 metric 不熟
- 需要 revisiting CEFR rubrics，并继续做 calibration
- 视频 / human review 被提到是当前阶段少数可用杠杆之一

### 5. 若干转化 friction 已被明确点名

- profile page / field form 过于复杂，应简化
- 候选人侧“AI interview”表述会触发压力，改成 `online test / online reading test` 更有利于降低决策门槛
- 没有足够人手及时处理 leads，会错过最佳时机
- CE 结果同步存在流程或数据问题：有人参加后未及时拿到结果，系统与 Google 记录之间存在 gap

### 6. 渠道优先级在会议中被进一步压缩

- referral 被明确为优先盯住的主线
- Tipcap / TV cap 被点名需要单独做政策讨论
- 会议里出现一个重要判断：不可能所有渠道同时率先达到质量标，需挑一个更可控的渠道先跑出来

## 这次会议改变了什么

- 质量目标第一次被更明确地翻译成“按月绝对数执行”
- B+/A 质量管理开始和 trainer / screener 校准、CEFR rubric、demo 结果流转这些具体机制连接起来
- 团队不再只讨论总量，而是开始辨认哪些 friction 正在真实影响 quality conversion
