# 当前判断

这次同步已经从首版名单底表升级为“带项目占用雏形的资源图”。  
当前中国区资源盘子已扩成 24 人、约 21.9 FTE，不仅有产品/研发/测试，还单独列出了 4 位 AI 工程师；右侧技术资源矩阵也首次把部分项目与前端/服务端/测试人员对应起来。

## 关键事实

### 1. 资源总盘子升级

- 总人数：24 人
- 按已知投入折算：约 21.9 FTE
- 角色分布：产品 3、前端 3、PHP 6、Java 4、测试 4、AI工程师 4

### 2. 资源结构有三处关键变化

- 新增 AI 工程师 4 人：李雨熹、杨世文、李冠辰、Qays（约旦）
- Java 侧明确李洋为 50% 投入
- 测试侧明确曹宝玲为 30% 投入

### 3. 项目占用视图开始出现

表内新增“技术资源情况”矩阵，至少已出现以下项目-资源映射：

- 转介绍项目：前端乔志强、刘博伟；服务端张鹤、牛琪；测试刘波
- NTT+CE自动化：前端刘博伟；服务端张鹤、李波、李洋、谷艳峰、刘旸豪；测试李威、杨卓妍
- Switcher项目：服务端吴国峰
- Facebook massage：服务端石佳佳
- 老师等级体系调整：服务端牛琪
- AI匹配V1.3期（默认推荐+交互优化）：前端李凯凯；服务端郝雨烁、谷艳峰；测试待定

### 4. 后端仍是主承载池，但不再是唯一焦点

- PHP：6 人，约 5.2 FTE
- Java：4 人，约 3.4 FTE
- PHP + Java 合计：10 人，约 8.6 FTE
- AI 工程师：4 人，4.0 FTE，意味着资源盘点已从纯产研资源进一步扩到 AI 支援资源池

## 这次同步改变了什么

- 中国区资源盘点不再只是名单视图，而是开始进入项目占用视图
- “可写接口资源”这件事终于有了更具体的排查底座，不需要再完全从零盘
- AI 团队被显式列出后，AI 支援不再只是额外想象空间，而是已进入资源池视角

## 仍待确认的问题

- 哪些前端 / 服务端 / AI 资源是可机动的，哪些已被项目锁定
- 项目完成时间中的 46140 / 46142 是否是 Excel 日期序列，需统一转成可读口径
- 表中的“刘波”是否与既有名单里的“刘博伟”是不同人，需核实名单一致性
- 还缺 owner、调拨优先级与统一资源调用规则
