## 一、问题定位：前五节课为什么是退费重灾区

- **退费集中在 1–3 节课和 4–6 节课**，所以才单独组建 S5/F5 专项；前五节课定性为「**脆弱的信任建立期**」=试炼场+信任桥梁。
- 退费数据拆解（国内 3 月 M0，57 名退费学员）：
  - **22.5% 一节课都没上过就退**（与老师基本无关，先排除）。
  - **41.2% 在前三节课内退费**；累计到 **第 4–5 节课约 64%**。
- 影响首五节课体验的核心要素（王韬归纳）：
  1. **师生匹配精准度**（推的是不是他真喜欢的老师）—— 信任断裂第一要素
  2. **破冰/过渡是否做好**
  3. **教师质量**（语法、发音、教学，AI 分析维度）
  4. **定级错误**（体验课 vs 付费课级别落差大）
  5. **口音与风格**
  6. **临时排课**：课前 6→2 小时及更临近约的，退费率显著更高；提前 2 天约的退费率最低
  7. **各端未联动**：运营、业务、外教端各自为战

## 二、关键数据发现

### 1. CC/SS 代约 vs 学员自约
- **CC/SS 代约首课的退费率 ≈ 学员自约的 2 倍**。
- 推断：学员端推荐逻辑更严格；**下一步要让学员自约逻辑与各端口径保持一致**（产研待做）。

### 2. 定级（Level）漂移
- 体验课 vs 付费课级别占比变化大：level S、L0 变少，L1/2/3 变多 → 学员要么被调到更高级别，要么不再上课。
- 国内/海外都集中在 **L0–L3**；国内 level S 退费占比达 **12.4%**（占比 7–8% 却退费 12.4%，是危险预警值）。
- **根因**：CC 在体验课后可调级别；且去年产研只针对 FT 做开发，**FT 的 level 与正式课 level 已不是一回事**（level gap），寄望 Cocos 上线后对齐。
- **共识**：定级问题属渠道/曲老师 + Cocos 范畴，外教侧**不折腾**。

## 三、核心方案（王韬 propose）与「反向歧视」思路

### 王东的「反向歧视」简化策略
> 好老师短期是固定数量。给 F5 学员一个**精选池**，约课时**只看到三勾/四勾的"车厘子"，二勾老师藏起来约不上**——对新生做"反向歧视"（婴儿吃营养餐，成人啃馒头）。第 6、7 节课之后再放开。

- 产品现状缺口：**目前没有"哪些老师是 F5 用"的标签，所有老师全量暴露**——这是问题根源（无需对标竞品，自身就有缺陷）。

### 曲建菲（Jeffrey）的反驳（贯穿全场的主线分歧）
1. **推荐逻辑解决不了**：临近上课好老师已被约完，只能"萝卜矬子里拔将军"。真正该改的是**销售运营流程/SOP**——首课必须学员自己看完老师后点选，而非销售硬约。
2. **F5 不能定位成外教战役/战役三能"偷偷解决"的事**：它本质是**公司级退费优化项目**，涉及定级、CC 销售操作流程，外教匹配能撬动的空间很小。
3. **量级测算**：总退费率 ~1.x%，去掉 25% 未开课 → 剩 ~0.75–0.8%，其中销售问题约一半 → 师资匹配真正能解决的也就 **0.4% 左右**，"千万别指着外教匹配在 F5 起决定性作用"。
4. **反对单独建池/单独激励/单独标签**：会与体验课老师池重叠、新池老师照样固定不了，陷入死循环；且全人工标准与"四化"矛盾。
5. **政策互相打架**：一边侦测"频繁换老师=高风险"、一边现行政策鼓励前期多换几个老师多匹配；一边要 F5 固定关系、一边老邵/陈杨磊也要固定关系——多个事互相矛盾。

### 曹海璇（Shayne）补充
- 不赞成单独画池子（与体验课直约老师本质冲突，还要重算利用率等规则）。
- 不认可小龙基于课程回放的 AI 退费原因分析（战役上 AI 质检从没准过）。
- **真正缺的数据**：哪些老师退费率高、这些高退费老师的共同特征 → 才能做屏蔽逻辑。王韬承认"**这个数据我们现在没有**"（退费由最后一个老师触发，但未必是该老师的原因，难以归因到具体老师）。

## 四、收敛后的方向（外教侧能做 + 需产研支持）

外教侧聚焦四个维度（曲建菲基本接受为"信息已 get，会帮你们想怎么在外教侧发力"）：

1. **相似受众智能匹配（Lookalike）**：参考画像相近的付费在读学员喜欢的老师类型，给新学员推荐（类抖音/Amazon 推荐），减少人工猜测、突破"收藏夹只看得见 1% 老师"的黑盒限制。
2. **高风险自动拦截/预警**：屏蔽设备差、网络差、缺席率高、被投诉/拉黑、未认证的老师；对缺课多的高风险学员触发人工干预 SOP（需联动 SI/业务端）。
3. **F5 专项**：双认证（设备认证 + 培训认证）→ 打 F5 标签；前五节课**全部 QA**（贴近 FT 标准的 rubric）；实时设备数据过滤。
4. **激励驱动**：教师运营侧设对应激励（曲建菲明确反对单独激励）。

### 两个池子"会不会撞车"——本场最大悬而未决判断
- **车 A**：F5 蜜月专属池（纵切，今天 propose）。
- **车 B**：618 之前要上的「FTX 体验课老师可上付费课」(横切，老邵强推，老板支持)。
- 王东定调：**两个车都先拿手里，明天早上开会评估能否合并成一辆车**。
  - 若 PK：老邵铁定选 618 那辆 → 要打架。
  - 若能找到 50–80% synergy：自然帮到 F5 概念，皆大欢喜。
- **王韬的对齐论证**：FT 老师本就是 F5 培训优先对象 → 老师 ready 后只是"开不开放"的产品改动；FTX 只需把 tag 从 FX 改成 FTE 即可开 TTP（当前只有 FX 不能开 TTP，其余 FT 类型都能开）。**结论：不做 F5 专属功能，只做 F5 标签优先 + 系统屏蔽高风险老师**（类比 FT 屏蔽逻辑）。

### 标签 vs 认证之争（最终倾向）
- 曲建菲：**不建独立池、不打人工标签**，而是让老师考 **F5 认证（Learning Hub 证书）+ 设备分（装新 AC 检测）**，综合判断是否适合推给新生；"给老师造更多数据，才是精准推荐的唯一性理由"。
- 王东折中：**不用人工打标签**，用培训数据流 + 出席数据 + 设备分让算法自动筛 → 等效于标签。
- 共识落点：**精力聚焦在「培训 + 装 AC」**；这些信息全部喂进推荐/屏蔽算法。

## 六、判断要点（给 Leon）

1. **本场是典型"紧急 vs 重要"+"战役边界"之争的延续**：F5（KPI3 退费）外教侧能撬动的盘子很小（Jeffrey 测算 ~0.4%），真正杠杆在销售 SOP 和定级（公司级），外教战役不能背全责——这一点曲建菲、曹海璇高度一致，需要在对外叙事上**主动降预期**，别把 F5 说成战役三的决定性成果。
2. **数据归因缺口是硬伤**：没有"高退费老师特征"数据，屏蔽逻辑和 AI 质检都站不稳，决策依据不足。曹海璇这一刀很准。
3. **真正可落地的最优解 = 把两辆车合并**：F5 标签优先 + 屏蔽高风险（纵切）若能寄生在 618 FTX→付费课（横切）上，资源与政治成本最低；明天的会是关键节点。
4. **方法论上王东延续了"反向歧视/精选池"+"数据投喂引擎"思路**，与 5/26 师生匹配会的火山引擎逻辑一脉相承；曲建菲的"不建池、靠数据造证"反而更符合四化方向，值得采纳。
