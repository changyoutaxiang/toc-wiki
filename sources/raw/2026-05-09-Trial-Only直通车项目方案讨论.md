# 会议结论

Trial Only 是直通车项目从“好老师出清”进入“绑定业务转化”的落地形态：不是单纯给体验课换更好老师，而是把高潜 leads、最会卖的销售、可被包装的 A/B+ 老师和可锁定的常规课档期捆成一个成交机制。

核心杀手锏不是“老师绝对碾压”，而是 **所见即所得 + 当场锁定**：家长体验课喜欢某位老师后，CC 立刻能为其锁定未来一个月常规课排期，消除“体验课老师和常规课老师割裂”的最大抗性。

# 背景与目标

- 小红书直播渠道 M0 转化率已从 4% 提升到 6.4%。
- Q2 底线目标是拉平 Poly，M0 转化率需达到 8%。
- 5 月业务侧计划把合肥 4999 元小课包“小船模式”复制到上海 7000 元以上“大船”，高客单与跨区复制会放大转化压力。
- 合肥团队对 Trial Only 需求最强、反馈频次最高，也最适合作为 MVP 场。

# 核心判断

## 1. Trial Only 是“掐尖 + 强强联合”

小规模试点时，应把最有脑子的销售、最优质 leads、筛出的优质老师集中匹配。高基础转化率场景里，每提升 10% 带来的绝对点数更大；这比在低转化、低意向池里平均撒资源更有效。

## 2. 试点期允许“积极作弊”

MVP 容量小，可以人为加料：课前深度备课、课后 CC 高频介入、老师/CC 针对单个学生做更强反馈。这不是长期模型，但可以帮助验证机制上限，把转化率再拔高 0.5–1 个点。

## 3. 家长买的是确定性，不是 5 分老师差异

65 分和 60 分老师的体感差异未必足够让家长立刻买单；但“我喜欢这个老师，后面还能一直约到他/她”是强确定性，能直接转化为成交理由。

# MVP 方案

## 试点场景

- 优先合肥团队 / “锦州之战”项目组。
- 先跑单点闭环，不急于做严谨渠道 A/B。
- 已知对照：相同小红书渠道，合肥约 6.31%，上海约 3.02%；MVP 先在更成熟、更愿意配合的合肥环境里验证机制。

## 师资范围与筛选

- 只做青少儿 ESL（听口、词汇语法、自然拼读），暂不做成人。
- 目标老师：现有池子里未被充分利用的 A / B+ 老师。
- 硬指标：发音、形象是基础，网络和设备必须过关；未来 4–5 个月硬件会成为老师能力的“阶级鸿沟”。
- 包装物料：专业自我介绍视频（含教学片段）、形象照、教学经验/证书，以链接形式给 CC 转发家长。

## 教师排课与生命周期

- 系统标签：FDR (Regular)。
- 产能要求：核心高峰 18:00–20:30，每周不低于 30 slots。
- 可见性：FDR slots 只对合肥试点销售团队隔离可见。
- 周期：暂定 8 周；动态看转化率、出席率，不达标淘汰；表现好且课表排满后回归常规池，并可升级为项目培训师。

# 销售端打法

- 放弃“课前 2 分钟随机分配体验课老师”的开盲盒模式。
- 采用人工“销售代约制”：CC 作为媒婆，同时盯高潜家长和 FDR 专属 slots。
- 体验课后当场锁定未来一个月常规课排期，例如一周两次。
- 引入直播间稀缺话术：优质外教是稀缺商品，“今天不占坑，明天档期就没了”。

# 教学与业务闭环

- 黄荣Sophia（Sophie） 负责输出强标准化教学 SOP，例如核心词汇带读次数等关键动作必须明确。
- 教学 SOP 要二次加工成《教师手册》/销售武器，让 CC 先谈专业、再谈价格。
- 课后 Feedback 不只是给家长评语，还要给 CC 具体转化线索，服务成交。

# 协作原则

黄荣Sophia（Sophie） 在教学标准和项目模型上是专家，但对 51Talk 现有系统分配机制和基建限制不熟。业务、运营、产研对接时必须直接暴露系统限制、历史坑点和不可行边界，不要默认对方懂，避免项目设计落在“纸面正确、系统跑不动”。
