# 当前判断

招聘战役在 Q1 的首要任务是恢复供给安全，到了 Q2 已经进入“保量基础上重塑关键抓手”的阶段。  
当前最重要的突破点不是继续零散修漏斗，而是优先抓基础设施和组织 owner。
2026-04-23 补入海外侧下标逻辑澄清后，招聘目标这条线的主要问题也从“缺输入”切换成“如何把国内 / 海外压成同一张管理口径图”。
2026-04-24 的 Tammi / 王慧沟通又补了一层：漏斗关键卡点正在继续下沉到 CE 末端，且 CE 链路的组织拆分本身已成为效率问题。
2026-04-25 公司进一步把 cost per launch 目标从 2000 比索压到 1500 比索，意味着招聘战役的渠道策略要从“缩洪水 + 做 KOL / Referral 试验”进一步切到“更坚决收缩外部投放，把资源优先压到 Referral”。

## 当前状态

- 3 月招聘量已达到 2000，数量上回到正轨
- 资料提交率与初筛通过率已基本回归正常
- 培训参与率与通过相关环节仍是最后卡点
- Referral、Website owner、沟通矩阵等结构问题尚未彻底解决
- 本周进一步确认 Marketing-CN 要收缩到高 ROI 渠道，停止洪水，并把漏斗纪律抬到更高要求
- 同时出现更强倾向：Q2 市场资源的 80% 转向 KOL，减少买 leads 对主漏斗制造的洪水
- 2026-04-25 新信号进一步覆盖了上述倾向：公司要求把 cost per launch 从 2000 比索压到 1500 比索，因此 MKT 与 KOL 都进入更坚决的收缩范围，Referral 成为更优先的资源承接方向
- CE 问题近期显著抬头，当前至少包括数量不足、slots 供需不匹配、以及通过率偏低但归因未定三类问题
- 招聘漏斗、国内 CE 审核、海外 CE 审核分散在不同 owner 链路上，组织协同成本偏高
- Leon 已开始削弱战役推进中的层级顾虑，改为按项目结果直接调度项目负责人，并以直接调度群作为新入口

## Q2 关键突破点

- 入门期薪酬倾斜，提升新招好老师占比
- 沟通阵地 / 沟通矩阵建设，横跨漏斗和渠道
- Referral owner 明确，形成端到端执行链条
- 把创新动作优先放在市场测试渠道验证
- 停止洪水后，用更高纪律要求守住缩量后的 leads 跟踪与节点清零
- 用 KOL 承接更高质量 leads 与品牌背书，而不是继续放大买量洪水
- 把 CE 末端卡点拆成数量、slots、通过率三类问题单独管理，而不是继续混成一个漏斗黑箱
- 推动招聘漏斗、国内 CE 审核、海外 CE 审核三段链路收敛成更短的协同结构
- 对 CE redemo 与 NTT→CE→自动化衔接这类高摩擦链路，优先采用 Leon 直接穿透和硬推的方式，而不是继续等待复杂三方协商

## 当前关键项目

- 沟通阵地四大金刚 / WhatsApp 收敛
- 招聘漏斗修复
- Referral 引擎重启
- Center 模式扩张与新手大礼包
- 漏斗分流策略
- Website owner 明确
- 招聘评分标准 baseline
- MyStudent 分析口径修正
