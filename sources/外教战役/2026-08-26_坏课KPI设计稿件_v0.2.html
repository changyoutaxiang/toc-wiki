3设计原则：四条不变量

原则含义对应正本
P1 客户可感知只统计学生真实经历到的「承诺未兑现」——坏课必须直接对应客户体验，不统计内部便利项基本法第 1 条
P2 可影响只放老师/系统动作能改变的项（纪律可治理、设备可准入、红线可培训），不放不可归因项8/25 会议「定义盒子」
P3 可测量每个事件有客观数据源/信号，可复核、可回放；无信号不硬造（当前无正式基线=先测后挂）FT-RISK-003（不造假口径）
P4 防 Goodhart指标服务客户结果，不是报表装饰；配量/分母护栏，防「为了降率而少开课」「为好看而缩口径」「主观项被操纵」四化宪法第 7 条

4定义盒子：四大类（Leon 输入重构）

定义盒子是坏课 KPI 的唯一事实源（对齐 HR/Lily/数据侧后冻结，发一张废一片）。按 Leon 输入分为四大类，每类标注客观性梯度与主要挑战点——这是设计「能测什么、怎么测」的出发点。

🔗 与坏课治理原子小队（曹海璇）事件范围的关系——KPI 口径 ≠ 小队事件口径
  • 小队首期定义极窄：只做「课中老师缺席（no-notice absence）」一种事件，明确排除网络/设备、迟到早退、口音、长期教师评价或所有"坏课"类型（八要素备案 v0.1 §2.2；00_HUB 范围与非目标）。
  • KPI 盒子更宽：四大类——因为战役指标需覆盖用户投诉 70–80% 的交付不稳定主因（缺席 + 设备网络）+ 红线行为 + 待议的学生反馈。
  • 两者共用测量合同：分子去重（课程/约课唯一 ID）、事件触发 → 人工确认 → 改判 → 申诉全链，完全复用小队已建成的测量合同与基线方法。
  • 对接方式：纪律类中的「课中缺席」直接复用小队成果（构成分子）；稳定类/行为类作为 KPI 独立事件族先行测量，待小队按事件合同扩容后纳入同一执行闭环。
  • 防误读：不得以「KPI 盒子宽」推断小队在执行范围内失职，也不得以「小队只做课中缺席」推断 KPI 不应含其他类别——两层口径各有用途，用同一套测量合同连接。
⚠️ 口径边界（会议遗留，必须与 HR/数据侧对齐）
①「坏课」只指当前治理的场景（四大类盒）还是全部问题课？建议一期=盒内，后续按事件合同扩容；② 与 HR 对齐定义（HR 现从 Lily 拿数，两方必须同源）；③ 新师 vs 存量分开归因，避免训练营期新师拖高整体率。

5学生反馈类：Open 重点讨论（是否纳入坏课范畴）

🔮 本类保持 Open——Leon 明确：是否纳入坏课范畴预计有争议，是重点讨论部分

学生反馈类 = 学员产生的投诉、拉黑、差评。它是「客观的主观类」：事件本身客观存在（确实发生了投诉），但内容是否成立、反映什么问题需要核验。本节的选项、利弊与推荐路径供讨论，不在 v0.2 闭合。

5.1 纳入 vs 不纳入：两面的真实权衡

✅ 支持纳入
  • 客户价值北极星：客户说不好就是不好，无需替客户解释
  • 与 H2 好老师客户尺（学生投票）同源，口径连贯
  • 能捕获前三类未覆盖的体验问题（如教学态度、冷场、敷衍）
🚫 反对纳入
  • 主观性：口味、期望、心情差异大；同一行为不同客户结论不同
  • 可操纵：恶意差评、老师刷好评/刷分
  • 重复计数：多数投诉是对纪律/稳定类事件的表达（"老师没来""又断线了"），纳入会双计
  • 样本偏：评价率仅 30–40%，不评价的多数被忽略
  • 分配污染：好老师前置到更优流量会天然抬高其客户指标（H2 已标测量悖论），拉黑/差评率会被曝光分配扭曲
  • 稀释坏课率「客观、可复核」的核心价值

5.2 不纳入时的处理路径（推荐讨论方向）

如果一期不把学生反馈类并入坏课率分子，不等于丢弃它——而是给它三个更准确的位子：

处理位子做法
① 独立负向指标（并行监控） 投诉率 / 拉黑率 / 差评率作为独立的学生反馈指标与坏课率并行呈现——对应 6/29 三块指标中的「学生投票」块（收藏/好评/rebook 为正向，投诉/拉黑/差评为负向）。坏课率管「交付可靠性」，反馈指标管「客户主观体验」，两把尺各管一段。
② 事件发现与核验线索 投诉/差评 → 触发核验 → 若对应①②③类客观事件（缺席/断连/红线行为）→ 核验成立则计入对应类别的分子（按课程 ID 去重，不重复计数）。即学生反馈是「发现机制 + 归因管道」，不是「分子本体」——呼应会议原话"系统应该告诉我们发生了什么，而不是等学生投诉"。
③ 纯主观性反馈走客户尺 与纪律/稳定/行为无关的体验反馈（口音不喜欢、教学风格不合、级别错配）→ 不进坏课率，归 H2 好老师客户尺（学生投票维度）与师生匹配（级别错配调整匹配而非淘汰）。
📌 COO 推荐（供讨论，不闭合）
一期不纳入坏课率分子，按 5.2 的三条路径处理（独立指标 + 核验归因管道 + 归客户尺）；Q4 初复评「是否把经核验的严重投诉并入」。理由：坏课率的立身之本是客观可复核，主观项并入会稀释它；且 6/29 设计本就是坏课率 / 学生投票 / 合规三块并行，学生反馈天然属于「学生投票」块。此为本稿件 Open 问题 #1，需与 Jennifer / 数据侧 / HR 讨论后定。

6数学口径：分子 · 分母 · 分市场 · 千分位

坏课率 = 坏课课次（盒内事件，按课程/约课唯一 ID 去重） ÷ 应交付约课课次
分母 = 开课窗口内未取消、老师承担交付责任的课次；不是完课数——缺席课次必须留在分母里，否则率被稀释
决策点选项推荐
率 vs 量 A. 只看率；B. 只看量；C. 双轨 推荐 C 战役层看率（千分位），原子小队/运营层看量（绝对课次 + rebook）。曲建菲提示：率从总量看太小、降 0.1–0.2% 不敏感——率用于对外与目标，量用于内部驱动。
分市场 A. combined；B. split 已确认 B domestic / overseas（可选中东）拆分。理由（Leon 输入）：不同地区的「严重程度」与「可干预程度」不同——合并口径会掩盖结构差异。对外叙事用变化量："坏课率从 X‰ 降到 Y‰"。
千分位呈现 百分比 / 千分位 / 万分位 已确认千分位 率太低时万分位辅助；周度滚动 + 月度冻结值，附量（绝对课次）防失真。
分母定义 总约课 / 完课数 / 应交付课次 推荐应交付课次 学生取消、未进入交付窗口的课次不计入；老师侧承担交付责任的课次全数入分母。
粒度与去重 课程/约课唯一 ID 一行一课 对齐原子小队测量合同 同一课次多事件（迟到且黑屏、缺席且断线）计 1 节坏课，不重复计数；但各事件类型分别留痕（供归因与治理定位）。
类别分率 只出总率 / 按类别出分率 总率 + 分类率双出 总率用于战役 KPI；分类率（纪律 / 稳定 / 行为各自）用于定位杠杆与责任，防止混合后无法行动。
📌 与好老师客户尺的时滞差异（必须明确各自用途）
坏课率是近实时指标（次日可出数），好老师客户尺是 30 天 cohort 指标（30+ 天才出第一读数）。坏课率用于月度经营节奏与现场动作驱动，客户尺用于战果验收——两把尺不混用、不互相替代。
