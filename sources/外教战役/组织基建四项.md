# 当前判断

Q2 的很多问题已经不再是策略不清，而是组织骨架不够。  
“组织基建四项”是当前战役治理层最关键的一组动作，解决不好，量、质、匹配三线都会持续彼此掣肘。

## 状态卡片

- owner: Leon
- status: active
- priority: p0
- decision_state: aligned
- blockers: 四项虽已进入管理层正式叙事，但仍未全部拆到逐项 owner / 时间表；KPI 与 Launch 对齐仍未完全落地；国内外运营决策权边界仍待固化
- next step: 把四项拆成 owner、里程碑和验证信号，并纳入季度会议后的跟进清单，避免停在“管理层已听过”的表达层
- next review: 2026-04-24
- last signal: 2026-04-23
- human loop: leon_followup
- Leon 下一步: 逐项点清 owner、时间点和验证信号，避免继续停在“都重要”的共识层
- Agent 下一步: 后续 ingest 时持续把四项的落地信号折回这张页，而不是散落在会议和任务页

## 四项内容

1. 招聘侧端到端负责人设立
2. 转介绍负责人补位
3. KPI 向 Launch 最终结果对齐
4. 国内外教运营决策权统一

## 为什么它重要

- Q1 已经证明：Register 翻倍不等于 Launch 能起来
- 没有人真正对 Launch 结果负责时，大家都会忙，但系统不会收敛
- 最重要的渠道和最关键的决策，如果长期没有 owner 或仲裁权，问题会一再重演

## 当前状态

- 招聘侧端到端负责人问题已开始出现明确落地动作
- 转介绍负责人缺位半年，伤害已被数据证明
- KPI 仍存在“有人管 leads、有人管转化、但 launch 担子太轻”的结构问题
- 国内 / 海外 / 菲律宾之间的运营判断仍可能出现三方角力

## 当前已知进展

- 2026-04-15 会议材料把组织基建四项正式提升为 Q2 必须解决的问题
- 同日材料已出现两条偏落地信号：
  - Jen 本人亲自负责菲律宾招聘端到端
  - Leon 统筹中国侧国内与海外两边教师运营

## 接下来要做什么

- 把四项分别拆成 owner、时间表和验证信号
- 明确哪些已经进入落地、哪些仍停留在共识层
- 把组织动作与 KPI、周会、资源配置真正挂上钩
