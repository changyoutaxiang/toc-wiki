## 核心结论

技术侧已拉取老师设备分数评估，分成四档（A/B/C/D），目标是将设备分数线对应成老师上岗综合评价的加分项。

## 设备分分级

| 等级 | 定义 |
|------|------|
| A | 能运行 cocos |
| B | 能运行 H5 |
| C | 能运行 PDF |
| D | 不满足最低要求 |

## 三个目标

### 目标 1：精确掌握设备分值
- 通过设备分，引导高设备分老师获得更高通过率
- 勉强通过的老师如果是低设备分，则不通过
- **核心逻辑**：设备分作为通过/不通过的调节因子

### 目标 2：找到光谱下限
- 目前技术划定的分数线更像是"中位数"
- 共识为"一个光谱"
- 海豹需要找到：**"关闭其他软件和浏览器情况下，可以运行 cocos 并进行基本操作"的光谱下限**对应的设备分
- **核心逻辑**：不是"平均能跑"，而是"最低条件下能跑"的边界

### 目标 3：分数映射
- 黄荣收到设备分分级后，进行老师评价的分数映射
- 将设备分纳入 CE 三维度评分体系（CE 分 + 设备分 + 观感分）
- **核心逻辑**：设备分从技术指标变成管理工具

## 与现有体系的衔接

- 已有 CE 三维度评分方向：CE 分（不变）+ 设备分 + 观感分
- 设备分在 CE demo 入口不达标时的处理规则待定
- 合并方式：Leon 主张加值制（基础分 + 设备加分 + 观感加分）

## 后续动作

- 海豹：找到 cocos 光谱下限对应的设备分
- 黄荣：收到设备分分级后，产出老师评价分数映射
- Leon：推动周三 CEO 会议拍板三维度评分方向
