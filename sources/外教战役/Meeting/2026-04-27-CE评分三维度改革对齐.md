# 会议摘要

Leon 与黄荣对齐 CE 评分体系改革方向：从"一张卷子"改为"三张卷子"。

## 核心决议

### 三维度评分体系（方向已对齐）

| 维度 | 内容 | 状态 |
|------|------|------|
| CE 分 | 现有教学 demo 评分体系，完全不变 | ✅ 不动 |
| 设备分 | 硬件检测打分（CPU/内存/硬盘/网络等），技术侧已有系统（蔡老板/杜良鹏），两次检测取最新 | ✅ 确定 |
| 观感分 | CE demo 时对老师外在形象/环境的主观评价 | 🔲 评分细则待定 |

### 合并方式（Leon 初步主张，待高层拍板）

- **加值制**：CE 基础分 + 设备加分 + 观感加分 = 总分
- 总分影响最终定级（A / B+ / B）
- 具体权重/合并公式今天不定，先把两套新卷子 propose 出来
- Leon 举例：CE 百分制 → 设备给 0-30 分加值，观感给 0-30 分加值

### 设备检测规则

- 检测两次：tech check（初始）+ CE demo 入口（二次）
- 以最新结果为准
- CE demo 入口设备不达标：Sophia 团队讨论具体处理方式（fail/先做再判），Leon 委托 Sophia 定

### 观感评分

- Leon 委托 Sophia 出专业 input
- 可能是三档（优/良/中）或百分制
- Sophia 表达了"主观性强、难以标准化"的顾虑
- Leon 回应：这件事交到 Sophia 手上比交到自己手上靠谱

### 治理框架

- Leon 明确："众议院 propose，参议院拍"
- 专家做提案，有权力的人来拍
- 改动标准需要高层同意，不是 Leon 和黄荣可以直接定的
- 周三（4/30）CEO 会议上推动方向性拍板

## 下一步

| 动作 | Owner | 时间 |
|------|-------|------|
| 产出"三张卷子"提案草稿（含观感评分标准专业 input） | Sophia | 周一/周二（4/27-28） |
| 周三 CEO 会议推动方向性拍板 | Leon | 4/30 |
| 拍板后再细化落地细节（权重、合并公式、设备不达标处理） | Leon + Sophia | 拍板后 |

## 对战役脑的影响

- B+老师标准页面需新增"三维度评分"方向
- 与 4/24 CE demo 重新对齐会议的结论直接衔接：标准改革进入具体卷子设计阶段
- 4/25 Leon 发给黄荣的 CE demo 2.0 结构化草稿现在有了更具体的骨架
