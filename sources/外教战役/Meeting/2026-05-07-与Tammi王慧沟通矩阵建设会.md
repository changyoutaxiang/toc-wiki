# 与Tammi王慧沟通矩阵建设会（raw）

这次沟通主要围绕“外教触达（Reach）与管理机制建设”展开，核心是把触达从单纯沟通工具，升级为支持外教质量管理的底层基础设施。

1. 战略背景
- 今年战役主线是提升教师质量（Better Teacher）
- 招聘侧的人才池已经基本建立，管理重心开始从“前端招募”转向“存量外教的质量管控与提升”
- 触达本身不直接提升教学，但它是后续标准传达、考核落地、反馈闭环的基建
- 需要把在岗好老师标准、平台规范、考核口径和收益规则传达给一线老师

2. 渠道矩阵
- 体制内：App 内消息推送、App 内语音呼叫，是首选主阵地，零成本且可控
- 体制外：WhatsApp 触达率高，但有封号风控和 API 成本，不能作为唯一底层方案
- 兜底：短信 / 邮件作为最底层防御体系
- DingTalk 可作为远景规划，但不适合作为当前切入点

3. 蜜月期压强打法
- 不追求“大而全”平均铺开，而是把压强集中到“蜜月期”
- 蜜月期指新学生和外教刚开始配合的前几节课 / 第一个月
- 该阶段直接影响学生和家长的第一印象，对退费率和升级 / 续费率影响最强
- 对蜜月期课程要做：
  - 课前强提醒：App、WhatsApp、短信等多通道覆盖
  - 课中异常立即介入：迟到 / 旷课要快速电话干预
  - 课后纠偏：背景噪音、光线等瑕疵要第一时间提醒
  - 课后表扬：表现好的老师要即时给正反馈，增强成就感和归属感

4. 系统落地
- 业务数据系统（CRM）和沟通触达系统需要打通
- 触达系统要能读取 CRM 标签，自动识别是否为蜜月期课程
- 需要产品 + 后端的精简敏捷小队快速梳理接口，先把闭环跑通，再泛化到常规课程

5. 分步推进
- 阶段一：先跑通“体制内 App 主导 + WhatsApp 辅助”的蜜月期触达闭环
- 阶段二：验证效果后，再泛化到所有常规课程，并进一步考虑更重型的企业工具
