# 当前判断

这次会没有直接拍出 CE demo 终版标准，但把标准工作的方向明显往前推进了一大步：
目标不再只是内部自洽地定义 B / B+ / A，而是要在五一后某次高管会上，把整套 CE demo 标准、分数线和解释口径真正 sell 给管理层。  
围绕这件事，本次会形成了几条关键判断：一是需要同时与管理层和 Polly 这类直接竞品对齐；二是“金主”可以参与的是权重对齐，而不是改动核心科目；三是现行 CE 标准可能过于按“全才交集”去筛，后续应更认真考虑单项打分、标签化、分流与更可解释的老师池设计。

## 本次新增信息

- CE demo 标准工作的短期目标，被明确为：在五一后某次高管会上，把 B / B+ / A 的考卷、分数线和解释体系讲清并卖出去
- 当前管理层对 B+ / A 的评分项、权重和高低边界几乎无法复述，内部 sell 不足已被明确视为真实 gap
- 为避免“自己当裁判又当运动员”的质疑，后续需要把 demo 视频、卷子和结果留痕留档，形成可回看证据链
- Sophia 补充：此前 NTT 与 CE demo AI 上线版本其实做过一轮标准拉齐，但可以再对一次，并共享国内 demo fail 占比分析
- 对 Polly 的理解进一步具体化：其招聘流程更短，AI 更像减分制，发音会人工再筛；NTT/onboarding 环节大量 redo；整体标准并非更严，而是“掐尖 + 放入更多人再靠自然淘汰”
- Polly 当前 B 的准入标准被感知为低于我方 CE 的 B 标准，尤其在发音上更松
- Tina 提出：我方 CE 之所以更严，是因为老师上线后同时承接青少和成人；如果想真正做分流，青少和成人业务流也要一起分流
- 会上浮现的新方向不是让业务改科目，而是允许不同区域/人群在共同科目下调权重；专业侧守住科目，业务侧可在限定范围内调权重
- 会上浮现的新方向还包括：不要继续只用“全才交集”筛老师，应更认真考虑用单项分、标签和老师池去服务不同需求，比如发音、energy、硬件、适配人群等
- 会上还把硬件/网络进一步抬升为“好老师标准”的组成部分之一，而不只是上线前门槛
- 另一个敏感但真实的信号是：观感 / professionalism 维度被明确提上桌面，虽然不适合粗暴写成显性歧视项，但会进入实际评估设计讨论
- Leon 在会后进一步把这组判断压缩成五条：标准必须与 Polly 形成互动、必须与业务需求形成互动、必须考虑好老师候选人体验、必须提升设备网络评分地位、以及必须把好老师标准做成能被业务负责人倒背如流的内部销售产品

## 初步共识

- 与管理层对齐时，核心是对齐“权重”与可解释性，而不是让管理层直接改专业科目
- 与 Polly 对齐时，核心不是机械抄作业，而是把竞品标准、流程长度与取舍逻辑正式纳入我方策略思考
- 如果继续用单一全才标准筛所有老师，会把自己卡死；标签化和分流值得进入下一版草稿
- 但共同底线仍要守住，尤其活跃度等项不应因为分流就被彻底放掉
- 候选人体验，尤其是好老师候选人的体验，应该进入下一版标准与流程设计，而不只看筛选端专业逻辑

## 会议产出 / 下一步

- Sophia 与 Tina 快速商量后，在下周一 / 周二前产出一版 `CE 标准 2.0` 草稿
- 草稿至少要把会上的共识表达进去：观感、硬件、专业技能等维度，以及更可解释的标准结构
- Leon 会拉小群持续收口问题和分歧，并准备拿着草稿继续去和管理层对齐
- Leon 会后进一步明确，黄荣起草时至少要覆盖五个母题：Polly互动、业务互动/tag、候选人体验、设备网络地位提升、以及内部销售表达
