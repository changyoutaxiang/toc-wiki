# 当前判断

这次会的意义，不是简单把 Referral 再讲一遍，而是第一次把 Referral 的 Q2 爆发打法拆成了“基础设施 + Q2 重点打法 + 可选加速器”三层结构。  
会议形成了几个重要变化：Referral 不再只是继续加码的渠道，而是被进一步当成量、质、流程改造和组织创新的综合抓手；同时，系统 readiness、激励机制、数据可视化和 targeting 被明确成基础前提，而 fast track、mentor 化 referral 和 guarantee pay 被抬成可能决定 Q2 上限的候选杠杆。

## 关键共识

### 1. Referral Q2 先分三层看

- Foundation：A-to-B 基础体验、分享链路、PC / app 支撑、激励机制、visibility / dashboard / kanban
- Focus：Q2 真正要打的是 target group + targeted campaign，而不是平推所有老师
- Chance / Accelerator：fast track、mentor 型 referral、guarantee pay 等可能带来超预期贡献的机制

### 2. 基础设施必须先补，不然上层打法跑不起来

- 第一版 PC 分享能力目标是 4 月底前上线
- posters / social sharing 素材预计 5 月或更晚才能更完整上线
- teacher app 端改造节奏慢，当前判断最早可能到 6 月，不能作为 Q2 爆发的唯一前提
- 需要把 visibility 做成类似 dashboard / kanban，继续采用“看数 - drill down - action”的管理方式

### 3. Q2 Referral 不走平推，而走 20/80 targeting

- 不对所有老师平均发力
- 重点找最可能贡献 80% 结果的少数人群
- target group 讨论维度包括 tenure、当前收入状态、活跃度和影响力
- 新老师里“刚开始赚到钱的人”被认为是下一波最容易被激活的 referral 人群之一

### 4. campaign 要围绕目标人群来设计

- campaign 不是泛活动，而是给特定目标人群的 program / tools
- 会上提到的例子包括 beat the heat、Instagram / TikTok 分享、share referral link 等
- rich game / 积分式机制可作为 accelerator，但最好自动化，手工跑会太重

### 5. Referral 被要求承担一部分 Q2 质量目标压力

- 会议反复回到 15% B+ / A 目标
- 仅靠现有一次性 referral incentive 不足以对质量形成硬杠杆
- 会上明确讨论：是否在 Q2 的 5-6 月，针对 B+ / A referral 做更强激励，甚至临时提高到 3000 等级别，以换取更可控的质量结果
- 也讨论了把一次性奖励改成持续型收益，让推荐人继续 coaching 被推荐老师

### 6. 出现了两类不同 referral 模型

- 普通 referral：推荐 1-2 个老师，拿一次性奖励，后续不深度介入
- mentor / virtual TP cap 型 referral：推荐人持续带、持续 coaching、持续从被推荐老师的 lesson / earnings 中获得小比例收益

会议进一步认为：
- 这两类人不是同一种人群，不能用同一套策略管理
- 前者适合普通 incentive 和 targeted campaign
- 后者更接近虚拟 TP cap / captain / 合伙人机制，应该单独成专题，而不是混在普通 referral 里

### 7. fast track 被进一步抬升成 Referral 的强加速器

- 对 top referrer / high-trust referral candidate，可尝试 human fast track 或半人工 fast track
- 核心价值不是简单提速，而是减少好老师在招聘流程中被折磨、失去耐心
- 会上明确提到：当前招聘流程对好老师体验很差，Referral 候选人尤其值得走更短流程
- 已提到 video demo / NTT video / 简化点击流程等可能成为 fast track 的落点

## 半结论

- Referral 在 Q2 的爆发，不应再被理解成“再加一点激励、再做一点宣传”
- 正确结构更像：
  1. 先补基础设施
  2. 再打 20/80 targeting 和 targeted campaign
  3. 同时试一到两个 accelerator（fast track / mentor 型 referral / stronger B+ incentive）
- 其中最值得继续深挖的两个方向是：
  - fast track + better candidate experience
  - mentor / virtual TP cap 型 referral 机制

## 这次会议改变了什么

- Referral 从“值得加码的渠道”进一步变成“可同时承担量、质、流程改造和组织创新”的主战场
- 会议首次把打法结构拆成 foundation / focus / accelerator 三层，便于后续 PM 推进
- teacher app 节奏偏慢被明确暴露，因此 Q2 不应把爆发希望押在 app fully ready 上
- 20/80 targeting 被正式抬成主打法，而不是平推式 campaign
- mentor 型 referral 被单独识别出来，后续应与普通 referral 分开设计
- fast track 被明确视为 Referral 上限的重要放大器
