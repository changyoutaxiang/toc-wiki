# 会议摘要

这次短会的核心不是再讨论“要不要重视设备”，而是把结论收敛成一条很明确的判断：**设备是老师质量提升和教学产品升级的最大杠杆**。

## 核心共识

1. **设备是最大杠杆**
   - 如果老师的设备能稳定运行 Q3 上线的 cocos 新版教材，老师质量的下限会被直接抬高
   - 设备不再只是后勤成本，而是直接决定教学产品能否落地的质量变量

2. **技术团队出准入标准**
   - 下周先拿出务实的准入标准
   - 同时要看主要竞争对手的硬件标准，别只看自己内部舒适区

3. **战役团队坚决执行**
   - 外教战役团队拿到确认后的标准后，要从新老师入口端严格执行
   - 准入线不是建议线，而是硬门槛

4. **设备分进入招聘质控**
   - 设备分要成为新老师招聘的新质量控制点
   - 新打分标准一旦定义完成，就进入周会监控

## 管理含义

- 教学产品升级，不是等教材上线后再补设备，而是要把设备标准前置
- 招聘端、质控端、产品端要用同一套准入语言
- 设备分会从“背景变量”变成“前置筛选条件”

## 与现有战役的关系

- 与 `Center模式`：Center 的硬件和环境优势会被进一步强化
- 与 `老师质量提升飞轮`：硬件不再只是门槛，而是质量飞轮的一环
- 与 `新老师蜜月期课程优化`：蜜月期课程的五害里，设备问题会被更强势地纳入前置治理
