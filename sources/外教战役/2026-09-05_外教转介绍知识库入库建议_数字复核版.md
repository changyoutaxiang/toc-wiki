# 外教转介绍知识库入库建议｜数字复核版

## 结论

**不要把 Jovic 的整份报告原样放进外教知识库。**

正确做法是拆成两层：

1. **现在可入库**：一张带来源、日期和冲突状态的“证据／缺口页”，让 Agent 知道有哪些材料、哪些数字不能直接回答。
2. **Jovic 或数据 Owner 核口径后再入库**：业务地图、渠道机制、Champions 运行机制、内容与激励机制、2026 年 1—8 月数据快照。

当前材料最适合进入“80-冲突与缺口”，状态应为 “CONFLICT + GAP”，**不能成为 CURRENT ANSWER**。

## 1. 这次重新核对了什么

复核对象：

- 2026 Referral Recruitment Executive Summary
- Referral Pipeline
- Referral Source Performance
- Referral Performance by Region
- Referral Link Performance
- Referral Champions Contribution
- Teacher Stories
- 51Talk Reels
- Referral Girly、Reels Theme、Toki Gems 等机制图

复核方法：

- 逐图读取原始数字；
- 对月度数字重新求和；
- 用分子／分母反算转化率；
- 区分“图上直接可见”“可由图内数字算出”“报告自己的解释”。

- 4 月参与率最高，为 14.8%。
- 5 月 Referral 最高，为 11,002；人均 Referral 最高，为 4.20。

- Champions 的 Launch Share 从 1 月 2.82% 升到 8 月 12.57%，但 8 月总盘可能未完结。

- 8 月 Reels 的参与教师从 105 降至 51，Reels 数从 388 增至 522；只能说明产出更集中，不能说明社区更健康。

## 3. 哪些内容适合进入外教知识库

### A. 适合优先入库：稳定结构与运行机制

| 候选知识页 | 应放内容 | 入库前最小核验 |
|---|---|---|
| **外教转介绍｜业务地图与术语** | Referrer → Referral／Lead → Register → Pre-screen → PSO → Tech Check → NTT → Demo → Onboarding → Launch 的链路 | Jovic／招聘数据 Owner 为每个词写一句定义；确认是否同一 cohort |
| **外教转介绍｜渠道分类** | Referral Link、Teacher App Links Sharing、MyPage Signup、Applicant Referral、MyPage Links Sharing、Employee Referral、Recovery Leads、Talent Scout | 确认渠道是否仍在用、是否互斥、归因规则 |
| **Referral Champions｜运行机制** | 候选标准：影响力／粉丝、既有 Reels 内容质量；内容主题；基础脚本 → Champion 增强 → Referral Team 审批 → 发布 | 确认当前 Owner、准入／退出条件、审核 SLA |
| **Referral Girly｜直播与内容机制** | 工作日直播；经验分享、转介绍技巧、促销、奖励；短视频参与路径 | 复核当前直播时间与渠道，不把 2026-08 海报当永久排期 |
| **教师 UGC 内容指南** | A Day in My Life、Student Moments、Classroom Highlights、Teacher Tips、Before & After、Teacher Success Stories、Fun Friday、Behind the Scenes、Teacher Motivation；字幕、灯光、标签等制作提示 | 品牌／合规审核；Reels 主题图写 15—30 秒，Referral Girly 海报写 15—60 秒，需统一 |
| **Toki Gems｜激励机制说明** | 奖励品类、兑换目录、适用对象、发放与兑换流程 | 必须补获取规则、兑换率、预算 Owner、有效期、库存与反作弊 |

这些内容回答的是“这个系统怎么运转”，比某个月的漂亮数字更耐久，更适合知识库。

### B. 适合入库，但只能做“带日期的证据快照”

| 候选快照页 | 可放内容 | 必须带的标签 |
|---|---|---|
| **2026-01—08 转介绍月度盘面** | Target、Actual Launch、Referral、参与率、人均 Referral、成本、激励占比 | snapshot_date、source、CONFLICT、review_at |
| **2026-01—08 Referral Pipeline** | 51,199 → 14,182 → 12,024 → 9,667 → 6,666 → 4,318 → 4,077 → 3,792 | cohort_definition: GAP |
| **Champions 月度贡献快照** | 5,408 Leads、304 Launch、月度 Share | attribution_rule: GAP |
| **Referral Link 流量快照** | 923,626 Views；月度 Active Users 合计 516,281；27 秒平均互动 | year_conflict: 2024 vs 2026 |
| **地区表现快照** | Region IX、X、VII 的相对领先信号 | 总量定义未解前，不放“全国总数” |

快照页的作用是保留历史证据，不是让 Agent 用旧数字回答“现在是多少”。

### C. 适合进入“冲突与缺口”区

直接放入：

1. Actual Launch、Referral、Cost、Incentive Launches、Active Users 的汇总冲突。
2. Executive、Source、Pipeline、Region 四套 Launch 分母不一致。
3. 8 月是否完整月、刷新时间是否一致。
4. Referral、Lead、Register、Referrer、Participant 是否是不同对象。
5. Region 卡片总数与月度加总不一致。
6. Link Analytics 标注 2024。
7. 缺少 Launch 后 10／30 天开课、留存、坏课、学生体验，无法证明“高质量获客”。

这页本身有知识价值：它能阻止 Agent 把错误总数包装成答案。

## 4. 哪些内容不适合入库

| 不入内容 | 原因 |
|---|---|
| “4,880 Actual Launch、101% 达成、55,847 Referral、6.11M Cost”作为正式结论 | 已被同页明细击穿 |
| Executive Scorecard 的星级与“Very Strong”等判断 | 没有评分标准，属于汇报包装 |
| “激励驱动增长”“内容导致 Launch”等因果结论 | 没有对照组、同期组和反事实 |
| “8 月业务失速” | 8 月是否完整月未知 |
| 个别教师的头像、个人排名、Facebook 表现榜 | 低耐久、含个人信息；只保留来源链接或匿名化案例 |
| 海报、口号、奖品图作为知识正文 | 只能作证据附件，不能替代规则 |
| 当前直播时间、奖品兑换价直接写成长期规则 | 会变化，必须有 Owner、有效期和复核日 |
| 全国平均值直接指导地区动作 | 地区结构高度不均，且地区总量口径冲突 |

## 6. 发给 Jovic／数据 Owner 的最小核对清单

只需要对方逐项给出“正确值 + 定义 + 数据表链接”：

1. Actual Launch 总数到底是 **3,880 还是 4,880**？
2. Referral Count 到底是 **51,847 还是 55,847**？
3. Actual Cost 到底是 **5.110M 还是 6.11M**？
4. Incentive Launches 到底是 **1,931 还是 2,231**？
5. Referral Link Active Users 到底是 **516,281 还是 616,281**？
6. Executive／Source／Pipeline／Region 的 Launch 为什么分别是 3,880／4,488／3,792／1,894？
7. Region 总卡片是“去重人数”、月度标签是“人次”，还是报表错误？
8. 8 月数据截止到哪一天？所有图是否同一刷新时间？
9. Referral、Lead、Register、Referrer、Participant 的精确定义是什么？
10. 哪一个表是唯一经营正本？谁负责维护？

## 7. 入库 Gate

满足下面条件后，才能把候选页升级为业务答案：

- 口径 Owner 明确；
- 来源表可回读；
- 指标分子、分母、时间窗、cohort 明确；
- 冲突项逐一关闭或保留为 CONFLICT；
- 当前机制有生效日期、复核日期和退出条件；
- 数据快照与长期机制分开；
- 不用 Referral、Views、Reels、激励量替代真实教师质量和学生结果。

**主权影响：因「客户价值、系统化交付与 AI 驱动」，本次从“把增长汇报搬进知识库”改为“先保留证据与冲突，再用 Launch 后质量结果决定能否成为经营知识”。**
