3设计原则：坏课第一准则 + 四条不变量

P0 · 坏课第一准则（Leon 主张 · 已定）
「坏」必须是客观有标准且可侦测的坏。
反例：老师上课无精打采——很难纳入坏课范畴，因为很难有标准，也不容易准确侦测。不符合「客观有标准 + 可准确侦测」的，一律不进入坏课盒子；先过 P0 这一关，再谈其他。
原则含义对应正本
P0 客观有标准且可侦测坏课准入门槛（Leon 主张）：每个事件必须有明确判定标准 + 可靠侦测手段；无标准或难侦测的（无精打采、态度冷场等）不进入盒子Leon 2026-08-26 主张
P1 客户可感知只统计学生真实经历到的「承诺未兑现」——坏课必须直接对应客户体验，不统计内部便利项基本法第 1 条
P2 可影响只放老师/系统动作能改变的项（纪律可治理、设备可准入、红线可培训），不放不可归因项8/25 会议「定义盒子」
P3 可测量每个事件有客观数据源/信号，可复核、可回放；无信号不硬造（当前无正式基线=先测后挂）FT-RISK-003（不造假口径）
P4 防 Goodhart指标服务客户结果，不是报表装饰；配量/分母护栏，防「为了降率而少开课」「为好看而缩口径」四化宪法第 7 条

🔗 与坏课治理原子小队（曹海璇）事件范围的关系——KPI 口径 ≠ 小队事件口径
  • 小队首期定义极窄：只做「课中老师缺席（no-notice absence）」一种事件，明确排除网络/设备、迟到早退、口音、长期教师评价或所有"坏课"类型（八要素备案 v0.1 §2.2；00_HUB 范围与非目标）。
  • KPI 盒子更宽：①②③三类——因为战役指标需覆盖用户投诉 70–80% 的交付不稳定主因（缺席 + 设备网络）+ 红线行为。
  • 两者共用测量合同：分子去重（课程/约课唯一 ID）、事件触发 → 人工确认 → 改判 → 申诉全链，完全复用小队已建成的测量合同与基线方法。
  • 对接方式：纪律类中的「课中缺席」直接复用小队成果（构成分子）；稳定类/行为类作为 KPI 独立事件族先行测量，待小队按事件合同扩容后纳入同一执行闭环。
  • 防误读：不得以「KPI 盒子宽」推断小队在执行范围内失职，也不得以「小队只做课中缺席」推断 KPI 不应含其他类别——两层口径各有用途，用同一套测量合同连接。
⚠️ 口径边界（会议遗留，必须与 HR/数据侧对齐）
①「坏课」只指当前治理的场景（①②③类盒）还是全部问题课？建议一期=盒内，后续按事件合同扩容；② 与 HR 对齐定义（HR 现从 Lily 拿数，两方必须同源）；③ 新师 vs 存量分开归因，避免训练营期新师拖高整体率。

5学生反馈类：Leon 主张不纳入，定位为「探针 + 质检触发」

Leon 主张 · 已定：客户主观反馈不纳入坏课
投诉、拉黑、差评——不进坏课。它是很好的探针：让我们对「客户对什么不满」保持持续洞察；它可以触发质检；但它不应该放入坏课。
三条理由（Leon）：① 它是客户主观的；② 它不均匀（评价率仅 30–40%、样本偏）；③ 它有被干预的可能（恶意差评 / 刷分 / 曝光分配污染）

5.1 为什么主观反馈不能进坏课（P0 的必然推论）

坏课第一准则要求「客观有标准且可侦测」。学生反馈类本质是「客观的主观类」——事件客观发生（确实有人投诉），但内容是否成立、反映什么问题需要核验：

  • 主观：口味、期望、心情差异大；同一行为不同客户结论不同——无法形成统一标准
  • 不均匀：评价率仅 30–40%，不评价的多数被忽略；拉黑/差评分布受曝光分配影响（好老师前置到更优流量会天然抬高其客户指标——H2 已标测量悖论）
  • 可被干预：恶意差评、老师刷好评/刷分——一旦进 KPI 就有操纵动机

5.2 探针与质检触发的落地机制（替代「纳入坏课」）

位子做法
① 探针：持续洞察 投诉 / 拉黑 / 差评的主题聚类与趋势作为经营洞察看板——回答"客户最近对什么不满"（缺席？设备？态度？级别错配？），驱动治理方向与产品改进。不进入坏课率分子，但坏课率复盘必须对照探针看（坏课率降了、探针说客户仍不满 → 说明口径没打到真问题）。
② 质检触发 投诉/差评 → 触发质检/人工复核 → 若核验成立且对应①②③类客观事件（缺席/断连/红线行为）→ 该课次按①②③类正常计入对应类别分子（按课程 ID 去重，不重复计数）。即主观反馈是发现机制，不是分子本体——呼应会议原话"系统应该告诉我们发生了什么，而不是等学生投诉"。
③ 归 H2 客户尺 与纪律/稳定/行为无关的体验反馈（口音不喜欢、教学风格不合、级别错配）→ 不进坏课率，归 H2 好老师客户尺（用户反馈维度）与师生匹配（级别错配调整匹配而非淘汰）。
📌 一句话总结
坏课率管「客观的坏」；学生反馈管「客户的不满」——前者是 KPI，后者是探针。两者对照使用：坏课率下降而探针仍亮，说明有口径外的问题；探针触发质检后，把客观证据回填进坏课率。这条已按 Leon 主张定稿，不再作为 Open 项。

6数学口径：分子 · 分母 · 分市场 · 千分位

坏课率 = 坏课课次（①②③类盒内事件，按课程/约课唯一 ID 去重） ÷ 应交付约课课次
分母 = 开课窗口内未取消、老师承担交付责任的课次；不是完课数——缺席课次必须留在分母里，否则率被稀释
决策点选项推荐
率 vs 量 A. 只看率；B. 只看量；C. 双轨 推荐 C 战役层看率（千分位），原子小队/运营层看量（绝对课次 + rebook）。曲建菲提示：率从总量看太小、降 0.1–0.2% 不敏感——率用于对外与目标，量用于内部驱动。
分市场 A. combined；B. split 已确认 B domestic / overseas（可选中东）拆分。理由（Leon 输入）：不同地区的「严重程度」与「可干预程度」不同——合并口径会掩盖结构差异。对外叙事用变化量："坏课率从 X‰ 降到 Y‰"。
千分位呈现 百分比 / 千分位 / 万分位 已确认千分位 率太低时万分位辅助；周度滚动 + 月度冻结值，附量（绝对课次）防失真。
分母定义 总约课 / 完课数 / 应交付课次 推荐应交付课次 学生取消、未进入交付窗口的课次不计入；老师侧承担交付责任的课次全数入分母。
粒度与去重 课程/约课唯一 ID 一行一课 对齐原子小队测量合同 同一课次多事件（迟到且黑屏、缺席且断线）计 1 节坏课，不重复计数；但各事件类型分别留痕（供归因与治理定位）。
类别分率 只出总率 / 按类别出分率 总率 + 分类率双出 总率用于战役 KPI；分类率（纪律 / 稳定 / 行为各自）用于定位杠杆与责任，防止混合后无法行动。
📌 与好老师客户尺的时滞差异（必须明确各自用途）
坏课率是近实时指标（次日可出数），好老师客户尺是 30 天 cohort 指标（30+ 天才出第一读数）。坏课率用于月度经营节奏与现场动作驱动，客户尺用于战果验收——两把尺不混用、不互相替代。
