# 当前判断

这是 **H2 外教质量提升之战的宪法级总指示**——CEO（Jack）给两位主帅 Jennifer、王东的书面指示，来源于 2026 年中战略会系列（7/8、7/10 收口）。它不是又一条战术调整，而是**把整场战役的胜利标准、打法结构、验收口径和组织责任一次性重定义**。

**一句话总纲（verbatim）**：

> 下半年外教战役只有一个总目标：建立一套**由客户定义、能够真实验证、可以持续训练和激励、能够被业务稳定使用的好老师系统**。

配套四句箴言（verbatim）：

> **把尺子交给客户，把价值送到前线，把老师做成产品，把组织建成蜂群。**

核心动作：把老师从"后台库存"→客户**看得见、选得到、信得过、愿意持续跟随**的产品；把外教管理从人盯人/考试/低频培训→**数据、AI、反馈驱动的教师生命周期系统**。

---

## 一、胜利标准改掉（核心指标升级）

*   **不再以**招聘人数 / Launch 数 / B+·A 占比 / 系统上线为最终战果。B+/A 只能作**入门尺**，不能代表**客户尺**。
    
*   **核心指标升级为（verbatim）**：经过 **30 天真实授课和客户反馈验证，并能持续创造客户价值的好老师数量及占比**。
    
*   好老师须同时满足四条件：①客户喜欢并愿意继续约 ②教学与纪律稳定 ③能被系统持续匹配消化 ④能通过反馈与训练继续进步。
    
*   围绕核心指标看：复约 / 收藏 / 固定 / 30 天持续上课 / 投诉 / 拉黑 / 退费 / 课堂稳定 / 网络设备 / 教学行为 / 业务使用结果。
    
*   **权重由业务与客户事实共同定义，不能由外教团队自己给自己打分**；不同市场可不同权重。

## 三、CEO 的六类验收结果（他明说"不只看招聘量和评级占比"）

1.  **验证结果**：30 天验证的好老师数量/占比、不同 cohort 质量变化。
    
2.  **客户结果**：复约/收藏/固定/30 天持续/投诉/拉黑/退费/满意度。
    
3.  **前置结果**：好老师在体验课/前 5 节/续费节点的覆盖，体验老师→正式课延续比例。
    
4.  **课堂结果**：迟到/缺席/网络设备/课堂异常/高质量完课/问题闭环时长。
    
5.  **系统结果**：推荐系统真实使用率/旧入口退役/Agent 介入率/人工介入率/问题复发率。
    
6.  **投入结果**：涨薪/招聘渠道/训练投入是否真带来客户与业务价值（而非只带成本）。
    

> ⏳ **硬 deadline：战役团队一周内（~2026-07-20）完成指标基线、区域权重、下半年目标和 owner。** 国内与中东可不同尺子，但必须同一套教师生命周期框架 + 可比数据语言。

## 四、双主帅分工（组织责任）

*   **Jennifer 牵引**：外教运营、教师供给、试用训练、评价激励、教师生命周期。

*   **共担**：共同对最终客户结果负责，**分工可不同、最终责任不可分割**。

## COO 二读增量（2026-07-13 晚·逐字核回原文后补）

1.  **反英雄条款（原文收尾、首版吸收漏记）**：CEO 明写"这套能力不依赖某个高手，而依赖一套会感知、会反馈、会学习的系统"。这既是给四化路线的最高背书，也是一条验收暗线——H2 结束时若关键环节仍系于 Jennifer 的运营手感或 Leon 本人的亲推，即使数字达标也不算赢。
    
2.  **权重定义权条款抬高了 07-20 四件套的真实成本**："权重必须由业务和客户事实共同定义，不能由外教团队自己给自己打分"+ §四"国内、中东和海外业务负责人必须共同定义客户尺子"——区域权重不是战役团队关起门写完交差的桌面作业，是一周内要完成的**跨部门共签**。四件套的隐性关键路径 = 约齐三地业务负责人，这件事应最先启动。
    
3.  **测量悖论（指标基线必须现在设计对照，否则 H2 结果不可解释）**：硬任务 #2 要求把好老师前置到体验课/前 5 节（改变曝光分配），核心指标又用客户结果（复约/收藏/固定）度量老师——前置分配会自然推高被曝光老师的客户指标，**分配效应会污染质量效应**。基线设计必须内置 cohort 对照/曝光校正，否则明年复盘时"老师变好了"与"好位置给了他们"无法区分。此即四化宪法第 7 条（防 Goodhart）在总指示上的第一个具体应用点。
    
4.  **30 天 cohort 的时滞账**：核心指标每个 cohort 进入后 30+ 天才出第一读数；H2 战果实际取决于 ~11 月底前入职的 cohort。指标基线须立即定义 cohort 窗口与读数节奏，12 月才能有完整证据链。
    
5.  **每周五问中"哪个旧入口/旧流程被关掉"是常设砍杀指标**：每周都要有一个退役答案，意味着现在就该建"待关停清单"（旧入口/旧报表/旧人工流程），否则第 2 周汇报这一栏就会开天窗。
    
6.  **沉默流失条款**："客户沉默离开，不能再成为我们看不见问题的理由"——六验收 #2 的投诉/拉黑/退费都是**出声信号**，CEO 额外要求对**不出声的流失**建观测。这是数据治理待建项清单里应单列的一条（预流失/静默不续约的主动发现）。
