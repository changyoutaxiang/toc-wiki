## 3. 工具层（继承执行包 v0.1，按 06-07 事实勘误）

### 3.1 数据化地基（对齐公司数据治理五层框架，2026-06-06 公司口径）

**坐标系（基石）**：数据化地基的公司级物理落点 = 五层框架 **L3 官方数据集**。责任口诀：**定义权 L3、验收权 L5、否决权 L4、问责穿透 L2、L1 不碰**。正本见 `wiki/concepts/数据治理五层框架与一号位责任.md`。

逐层角色边界（06-07 截图口径）：

| 层 | Leon 角色 | 一句话边界 |
|---|---|---|
| L3 数据资产 | **主责（定义权）** | 哪些算官方数据集、对象怎么切、口径怎么定、字段含义、owner——只有你有资格拍；**做不好责任在你，不在数分** |
| L5 业务使用 | **主责（验收面）** | 看板/日报/复盘是否唯一口径；**L5 打架 = L3 没做完** |
| L4 数据服务 | 约束方（守门不干活） | 有权有责要求：本域一切数据服务只引用 L3，不许从 L2 私拉野口径 |
| L2 数仓 | 合作方（问责穿透） | 懂到能判断"问题在哪层、该在哪层修"（中东时区活体案例）；定位到层是你的事，修是数仓的事 |
| L1 同步 | 不是你的 | 只确认外教域该接入的源（CRM/通话/课程等）无缺口 |

**L3 主责五件事 = 定清单、拍口径、写说明、钉人头、踩刹车。** 数据不用你搬（L1/L2），报表不用你做（L4/L5），你管的是外教业务的"字典"；你是外教域总 owner，但每个数据集必须往下钉到具体人。

## 5. 基本假设层（防伪转型层）

### 5.1 四条信念迁移（战役语境）

价值在定义而非执行 / AI 是可调度执行能力但不是责任主体 / 经验必须显性化 / 结构性产出优于工时但不否定探索期。

### 5.2 事前可证伪指标（每月自查 + 周会观察）

1. 团队**主动**交出的 skill / 标准卡数量（非被要求），以及被非作者复用、进入流程、降低重复救火成本的比例
2. 是否有人砍掉过自己强撑的环节
3. 汇报中讲结构/资产 vs 讲苦劳的占比变化
4. 压力时刻第一反应：查系统还是找强人（**压力时刻才暴露基本假设，平时只能看到宣称**）

### 5.3 伪转型自检（每月对照三层论 v0.3 第 3、4 条）

- 禁止用标准卡数量 / 工具覆盖率 / 资产库条目数当转型进度
- 禁止考核激励未动就宣称制度层完成
- 听到"四化是好工具，但开会/考核方式不用变"→ 防火墙话术，当场点破

### 5.4 体验设计（信念只被体验改变，不被说服改变）

刻意制造"查系统比问强人快"的时刻：凡有人问 Leon 口径，回答"在 X 卡 X 字段"而非直接给答案。06-05 已验证此姿势有效（"不谈数字直接毙掉发言权、逼问答案能否被 AI 读懂"）。
