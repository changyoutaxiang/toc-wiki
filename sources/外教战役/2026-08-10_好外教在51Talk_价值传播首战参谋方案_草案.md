# 好外教在 51Talk｜价值传播首战参谋方案（草案）

## 一句话结论

这不是一场“把好老师讲得更响”的品牌战，而是一场**帮家长在关键时刻放心选对老师，并让这份放心在前五节课里被兑现**的决策战。

首战不要从“大叙事”或大直播开始。先只打一处：

> **一个市场里，已完成测评、正要首次选老师或进入前五节课的新家长。**
>
> 给他们一个可兑现的承诺：**我们会让你在订课前看懂这位老师为什么适合孩子、什么时候能上；订课后优先保障连续体验；发现不合适，有明确的支持与调整办法。**

这不是现成的对外文案，而是一个待事实验证的首战主张。只有真实可约、稳定交付和问题处理都具备时，才可以对该人群说这句话。

---

## 一、先把原骨架调成一套真正能打仗的顺序

Leon 提出的骨架是对的：

> 责任域 → 责任人 → “好外教在 51Talk”的完整叙事 → 产品化、系统化的宣传机器。

但它还少了两段承重结构：**可核验的事实**与**客户得到的结果**。没有它们，叙事越完整，越可能放大未来的失望。

首战采用下面的顺序：

```text
能核验的老师事实
        ↓
对特定家长的一句价值主张
        ↓
销售与家长真正作决定的时刻
        ↓
家长是否选择、老师是否如约交付
        ↓
把不一致找出来，改事实、改说法或暂停承诺
```

这条顺序与 H2 总指示一致：好老师必须在体验课和前五节课被客户看见、选择、信任并持续使用；30 天真实授课和客户反馈才是最后的尺子。它也避免把“有视频、有素材、有曝光”误当成胜利。

### 这场仗的三条硬判断

1. **“好外教”不是一个形容词，而是一份对具体家长的可兑现说明。**
   不能泛称“我们的老师都很棒”；只能说明“对这一类孩子，在这个时段，这位老师有哪些已核验的能力、可用时段与连续学习条件”。

2. **先把老师变成“可选择的产品”，再把故事变成内容。**
   老师照片、短视频、课堂片段、资质、家长反馈、可约时段、适合的孩子、连续方案与问题处理方式，缺一项都可能让客户仍然只能“听声音盲选”。

3. **宣传必须有刹车。**
   若老师不可约、首次体验与承诺不同、连续上课受阻，或问题得不到支持，就停止扩大该主张；这不是宣传失败，而是保护家长信任。

## 二、从 Polly 应该学什么、不该学什么

这份逐字稿是机器转写，姓名、数字和具体教学主张都未经校对。因此它只能作为**对手表达方式的观察样本**，不能把其中任何事实当作我们要反驳或照抄的依据。

### 值得学的，是“帮助做决定”的结构

Polly 直播的核心动作不是单纯夸外教，而是反复把家长带进一个咨询过程：

- 先用测评和提问定位孩子情况，再解释为什么不同孩子要选不同路径；
- 把 25 分钟外教课放进一套“学习方案”里，而不是孤立卖一节课；
- 主播公开讲选择中的取舍，例如固定班级与灵活约课分别解决什么问题；
- 遇到“老师不合适怎么办”的问题，不回避，而是讲换老师、留言、寻求专属支持的办法；
- 每一段解释都落在一个明确下一步：测评、看报告、预约，而不是只让人记住一句口号。

其竞争力不在于直播间说得多，而在于它让家长觉得：**有人听懂我的孩子，并能告诉我下一步怎么选。**

### 不该照搬的，有四件事

- 不照搬未经验证的教学结论、年龄分段、效果承诺或对同业的评价；
- 不把“名师 / 外教 / 口音”当成适用于所有孩子的万能答案；
- 不先把流量拉大，再补老师供给、时段和服务支持；
- 不用强主播替代真实的选师信息和履约能力。

**我们的反攻不应是“找一个更能说的主播”。**

应该是：在家长真正要选老师时，让 51Talk 给出更清楚、更诚实、更能兑现的答案。

## 三、首战怎么选：一群人、一个时刻、一句主张

### 推荐战场

| 要素 | 首战选择 | 为什么这样选 |
|---|---|---|
| 人群 | 已完成测评、即将首次订课的新家长 | 需求刚形成，仍会认真比较，且尚未被随意分配固化体验 |
| 时刻 | 测评结果出来后，到首节 / 前五节课的选师与连续约课时刻 | 正是“看见—选择—跟随”最容易形成或失去的地方 |
| 供给范围 | 仅一个具备真实可约产能和支持能力的市场、一个小队 | 先保证说到做到，避免全量承诺把局部问题放大 |
| 一句主张 | “不只是给孩子安排一位老师；我们会说明为什么这位老师适合、何时能稳定上课，以及不合适时怎么调整。” | 家长听得懂，销售说得出，也能被真实结果检验 |

这句主张刻意不使用“最好”“全部”“保证”“顶级”等词。它卖的不是一张虚高的老师排名，而是**减少家长第一次选师的不确定感**。

### 首战不做什么

- 不先做全品牌“好外教在 51Talk”大宣发；
- 不在老师事实、可约时段、问题支持不清楚的情况下，让销售背统一口号；
- 不以播放量、素材数、直播场次作为赢的证据；
- 不为了看起来完整，把国内、海外、所有年龄段、所有课程一次卷进来。

## 四、责任怎么摆：不是“一个人背全责”，而是“一处有总负责人、每句话有人作证”

“外教价值传播”应作为 O3 市场教师价值实现的一项战役责任：市场对客户选择与实际使用负责；TOC / 质量侧对老师事实与适用边界负责；产品、匹配和 CRM 对决策时刻是否真的能承接负责。

首战需要一个临时的**价值传播主理人**，只对这次试点的完整运行负责；但不能把他变成所有事实的替身。

| 角色 | 必须交付什么 | 有权叫停什么 |
|---|---|---|
| 价值传播主理人（首战总负责人） | 选定人群、主张、材料、销售使用与每日问题清单；召集复盘 | 事实卡不完整、承诺无法兑现时，暂停该主张 |
| 市场业务负责人 | 试点客群、销售/服务承接、客户选择和连续上课结果 | 触点不真实、销售不愿用、客户看不懂时，要求重做 |
| 老师事实负责人（TOC / 质量侧） | 老师资格、近期履约、适用边界、可用时段的核验 | 任何超出真实能力或供应边界的说法 |
| 匹配 / 产品 / CRM 负责人 | 在正确时刻展示正确信息；记录家长看了什么、选了什么、后来发生什么 | 信息与实际预约、可用时段不一致 |
| 服务与问题支持负责人 | “不适合 / 约不到 / 上得不顺”时的可执行处理办法及处理时效 | 没有接住客户问题却仍扩大曝光 |

启动会只需要冻结五个空格：**市场、试点小队、价值传播主理人、事实负责人、问题支持负责人**。当前材料不能证明具体人选已确定，所以本方案不替任何人点名。

## 五、把“宣传”做成四张简单卡，而不是一堆素材

### 1. 老师事实卡：什么是真的

一位可被首战使用的老师，至少有以下项目，而且每项都能找到来源与核验人：

| 项目 | 需要写清楚 | 不能用什么替代 |
|---|---|---|
| 适合谁 | 年龄 / 学习阶段 / 课堂目标 / 可支持的时段 | 笼统的“很受欢迎” |
| 课堂证据 | 经允许的片段、近期课堂表现、已核验资质或评价 | 一次面试或单张高分标签 |
| 真实可约 | 当前可约时段、容量、有效日期 | 过期排班、理想产能 |
| 连续体验 | 前五节课如何安排；老师不可用时的替代方案 | “后续再协调” |
| 不适合什么 | 哪些需求、时段或目标不建议推荐 | 假装人人都匹配 |
| 问题处理 | 谁接、多久回应、能提供哪些选择 | 模糊的“联系客服” |

### 2. 家长主张卡：这一位老师为什么适合我的孩子

每次展示只回答四个问题，不把信息堆成履历表：

1. 你的孩子现在最需要什么？（来自测评与家长需求）
2. 为什么推荐这位老师？（只用事实卡内的证据）
3. 这周和前五节课怎么上，是否能连续？
4. 如果不喜欢或不适合，下一步怎么处理？

可用表达示例：

> “基于孩子刚完成的测评与您希望加强的___，我们推荐 ___。这位老师近期可约的时段是 ___，前五节课会先围绕 ___ 展开。您可以先看 30 秒课堂片段和介绍；如果首节后觉得不适合，我们会在 ___ 内协助您选择下一位合适老师。”

空格必须填入真实内容；填不上，就不展示。

### 3. 前线使用卡：销售和服务怎么说、怎么做

给前线的不是一份长培训，而是 30 秒能说清的四句：

1. “先确认孩子的情况和您最在意的事。”
2. “我推荐这位老师，是因为 ___。”
3. “您现在能约到 ___；前五节课的连续安排是 ___。”
4. “如果实际体验和预期不同，您可以 ___，我们会 ___。”

只有当销售愿意自然使用、客户能复述“为什么是这位老师”，它才算进入真实决策时刻。

### 4. 结果卡：承诺有没有被兑现

每个试点家庭只记录必要事实：看到了哪张主张卡、是否选择、是否实际约到、首节和前五节是否连续、是否收藏/复约/固定、问题是什么、如何处理。

这张卡的用途不是追责话术人员，而是找出：**哪一句说多了、哪一个时段供给不足、哪类孩子根本不该被这样推荐。**

## 六、首战的 14 天作战节奏

| 时间 | 要做的事 | 产出 / 过关标准 |
|---|---|---|
| 第 0 天 | 冻结一个市场、一个小队、一个人群、一个时刻、一个主张；明确五个角色 | 一页战场卡；未定人或事实不清，不开战 |
| 第 1–2 天 | 从真实可约老师中挑首批候选；逐位完成老师事实卡；核对课程、时段、支持能力 | 每项都有来源、有效期和核验人；缺项的老师不进首战 |
| 第 3 天 | 做三件最小材料：家长主张卡、30 秒前线使用卡、问题处理说明 | 不做大海报、不拍大广告；先能让家长做决定 |
| 第 4 天 | 用 5 个非正式案例演练：销售、预约、首节、老师不可用、家长不喜欢 | 演练中任何承诺接不住，就改材料或缩小范围 |
| 第 5–12 天 | 在一个小客群中真实使用；同一老师池、同一时段尽量保留现有流程作比较 | 每个家庭有结果卡；同时记录“不选”“约不到”“不满意” |
| 第 13–14 天 | 看结果，作三选一：保留并扩大 / 改说法后再测 / 暂停 | 复盘只回答：客户是否看懂、是否选得更坚定、实际是否更连续 |

### 比较必须公平

如果要判断主张是否有效，不能让“展示组”天然拿到更好老师、更好时段，再把差异都算给宣传。至少记录并尽量控制：老师池、时段、客户来源、测评结果、价格/优惠、销售人员与可约容量。

条件允许时，在同一批合格老师与相近时段中，让一部分家庭使用“说明为什么适合 + 连续方案”的新方式，另一部分走现有方式；否则只把它当探索，不能得出“宣传已显著提升转化”的结论。

### 首战看什么数字

启动前先从当前业务正本拉出基线，不在这份方案里编造目标数。首轮只看六类：

| 层次 | 要问的结果 |
|---|---|
| 前线是否使用 | 销售是否主动拿出主张卡；不用的原因是什么 |
| 家长是否理解 | 家长能否说出“为什么推荐这位老师”和“有问题怎么办” |
| 是否真正选到 | 展示后是否预约成功；约到的是否就是所展示的老师或明确的替代方案 |
| 是否连续体验 | 首节到前五节的出席、改期、换师、固定与复约情况 |
| 客户是否认可 | 收藏、主动指定、正向反馈，以及负面反馈的具体原因 |
| 信任有没有受损 | 承诺不一致、投诉、屏蔽、退款、沉默流失是否上升 |

**30 天后的真实上课与客户反馈，才决定是否把主张推广。**前两周最多证明“这个动作有人愿意用、信息能到达、承诺有机会被兑现”。

## 七、三条防错线：让宣传不跑在交付前面

### 防错线一：没有事实卡，不许讲故事

所有对外表达都要能追溯到老师事实卡。素材好看但时段已满、课堂片段不代表当前能力、评价没有时间范围，都不能上线。

### 防错线二：遇到不一致，先改承诺，再谈放大

出现以下任一情况，暂停对应老师、时段或主张：

- 展示后频繁约不到；
- 首节体验和展示内容明显不一致；
- 连续上课安排无法兑现；
- 家长听懂了主张却仍普遍不选择，或选择后快速后悔；
- 同类问题没有明确的人接住。

暂停不是掩盖问题。要区分是老师事实变了、供给不足、推荐不合适、表达让人误解，还是服务没有接住，然后分别修正。

### 防错线三：先赢一次，再谈“机器”

只有首战在一个小队完整跑过，并且第二位非原作者在第二个场景（例如“家长想换老师”）也能照着四张卡跑通，才把它沉淀为可复制的做法。

可复制的不是一套文案，而是：**核验事实、写清适用对象、进入真实决策时刻、记录实际结果、按结果改说法。**

## 八、对“好外教在 51Talk”完整叙事的建议

大叙事仍然需要，但它应当从首战中长出来，而不是先于首战规定事实。

可以逐步形成这样的叙事：

> **好外教，不是一个遥远的标签。**
> 在 51Talk，它首先是一位你能看见、能理解为什么适合孩子、能约到并能持续学习的老师；
> 背后是一套对老师真实表现负责、对家长疑问有回应、发现不适合就愿意调整的做法。

这段话只有在下面三件事都真实成立时才能公开放大：

1. 家长在关键时刻确实看见了有用信息；
2. 前五节课多数情况下确实拿到了相称的体验；
3. 少数不一致的情况确实有人接住，并且系统据此改变了推荐、供给或表达。

## 九、需要在启动会当场回答的五个问题

1. 首战到底选哪个市场、哪类新家长、哪一个选师时刻？
2. 现在哪一批老师同时满足“可核验、真实可约、可连续支持”？
3. 谁担任价值传播主理人；谁为老师事实、客户结果和问题支持签字？
4. 当前流程里，家长和销售在哪一个页面、话术或动作上真正做出选择？
5. 启动前的基线是什么；出现哪些负面信号就停，而不是继续加预算和曝光？

这五个问题不答清，先不要拍片、直播或全员动员。答清以后，14 天足够看出这是不是一场有客户价值的宣传首战。

## 参谋判断

原来的“责任域 → 责任人 → 完整叙事 → 宣传机器”不是错，而是更像组织建设的视角。真正的战役入口应当倒过来从一个家长的选择开始：

> **这个孩子现在需要什么？这位老师为什么适合？我今天能不能约到？上了以后不对怎么办？**

能连续回答好这四句，才有资格讲“好外教在 51Talk”。

反过来，若答案只有“我们有很多好老师、很多素材、很多直播”，那不是宣传战，只是在放大信息不对称；短期可能热闹，长期会积累信任负债。

## 参考与口径提醒
