1执行摘要（结论先行）

推荐 KPI 形态（一句话）
Q3/Q4 将「坏课率」确立为外教战役级交付可靠性指标（战役成败指标，非个人 KPI）：
坏课率 = 坏课课次 ÷ 应交付约课课次，定义盒子聚焦「老师可影响 + 系统可测量」的交付失败事件（缺席族 + 设备网络族），分市场呈现，Q3 冻结定义与基线、Q4 挂目标，千分位展示。
取代：B+/A 老师占比（已降为入门尺）｜性质：与 H2 好老师客户尺（30 天验证）同源互补、不打架

为什么是坏课率：各市场结论一致，用户投诉/不满最大来源是交付不稳定（老师缺席 + 电脑/网络设备两类，约 70–80%）；坏课率客观、可测量、客户价值直接相关（"bad lesson is customer value"）；而好老师数量客观性存疑、难影响（"good teacher is not something we can do"）。当前主要工作——坏课治理原子小队（海璇）、王韬的 initiative、TIDE 防坏老师——全部围绕坏课，KPI 必须呼应战场。

设计要点推荐方案
指标形态坏课率（战役看率）+ 坏课量（小队/运营看量）双轨，率用千分位
定义盒子（一期）缺席族（no-show / 课中缺席 / 迟到早退）+ 设备网络族（黑屏 / 无声 / 断连）；教学行为类暂不纳入
分子定义盒子内事件，按课程/约课唯一 ID 去重后的坏课课次
分母应交付约课课次（开课窗口内未取消、老师承担交付责任的课次）——不是完课数，避免缺席课次逃逸分母
分市场domestic / overseas 拆分呈现（可选中东），合并口径会掩盖结构差异
节奏9 月（Q3 尾）冻结定义 + 冻结基线 → Q4 初按「两个 lie」框架定目标值挂 KPI
前置红线无正式基线不可挂目标；数据 owner 须给有覆盖证明的源表（当前 Hive 预检 0 行、7 月 1.5 万节为口头未核验）

2背景与共识：为什么换尺

2.1 昨天（8/25）与 Jen 的会议共识

在「Teacher event and KPI」会上（参与者：王东 / Jennifer / Katherine / 曲建菲），Q3/Q4 教师侧 KPI 重构形成共识：用 bad lesson rate 替代 A/B+ 老师数量。Q3 已结束但 KPI 未定稿（HR 在催），新教师培训营 9 月（Q4）开始计入。王东澄清：这不是个人 KPI，是整个战役衡量成败的量和率。

换尺理由会议原话/依据
① 与当前工作一致海璇原子小队坏课项目、王韬 initiative、TIDE 防坏老师——都在打坏课，KPI 需呼应
② 客户价值直接各市场一致：用户投诉/不满最大来源是交付不稳定（缺席 + 设备网络，约 70–80%）
③ 客观可测量"bad lesson is customer value"；好老师数量不客观、难影响
④ 两三个月可做很多坏课可快速影响；好老师（口音/评级）难在短周期改变

2.2 历史沿革（为什么旧尺走不下去）

  • 6/29 KPI Catch-up 决策：放弃 B+/A 作为核心 KPI（Jack 曾定 35% B+A 干不出来）；确立三块可感知指标——坏课率 + 学生投票 + 合规。坏课定义初版：四害（迟到/早退/缺勤/黑屏）+ 设备 + 网络。
  • 7/13 CEO H2 总纲：最终战果 = 经 30 天真实授课与客户反馈验证、持续创造客户价值的好老师数量及占比；B+/A 降为入门尺（非废除）。权重须由业务与客户事实共同定义，不能外教团队自己给自己打分。
  • 7/28 五维设计定稿：好老师五维 = 用户反馈 / 可靠性 / 硬件质量 / 有效供给 / 成长任务。其中「可靠性」「硬件质量」两维正是坏课率覆盖的战场。
  • 8/14 坏课治理原子小队备案：DRI 曹海璇，首期只做「课中老师缺席」的实时客户保护；测量合同（课程 ID 去重、事件定义、恢复窗口）已成型，是坏课 KPI 分子口径的最佳起点。

3设计原则：四条不变量

原则含义对应四化宪法/正本
P1 客户可感知只统计学生真实经历到的「承诺未兑现」——坏课必须直接对应客户体验，不统计内部便利项基本法第 1 条
P2 可影响只放老师/系统动作能改变的项（缺席可治理、设备可准入），不放不可归因项（学生侧问题、超挑剔客户）8/25 会议「定义盒子」
P3 可测量每个事件有客观数据源/信号，可复核、可回放；无信号不硬造（当前无正式基线=先测后挂）FT-RISK-003（不造假口径）
P4 防 Goodhart指标服务客户结果，不是报表装饰；配量/分母护栏，防「为了降率而少开课」「为好看而缩口径」四化宪法第 7 条

4定义盒子：坏课装什么、不装什么

定义盒子是坏课 KPI 的唯一事实源（对齐 HR/Lily/数据侧后冻结，发一张废一片）。建议一期只装「交付可靠性」两族，教学行为类以观察项暂缓。

✅ 装进盒子（一期，可影响 + 可测量）
族事件信号源（候选）
缺席族no-show（未请假缺席）课程状态 / AC
课中缺席（开课后离开/不出现）鹰眼（开发中）/ 人工核验
迟到（超阈值，建议 >5 分钟）课程状态 / AC
早退课程状态 / AC
设备网络族黑屏 / 无画面设备指标 / AC
无声音设备指标 / AC
断连中断（无法正常授课）网络指标 / AC
🚫 不装（一期）
  • 教学行为质量（口音/TPR/互动）——属「好老师」客户尺范畴，且无统一 QA 标准（X2.3 GAP、FT-RISK-003），不进交付可靠性盒
  • 学生侧问题（学生迟到/设备/取消）——不可归因老师
  • 已兑现承诺：老师提前请假 + 代课成功、客户已获完整交付或保护 → 不算坏课
  • 新师训练营（9 月启动）单独归因，避免与存量混算
📌 例外与改判
  • 极端情况（停电但即时恢复、平台侧故障）→ 事件改判规则，不自动计数
  • 对齐原子小队测量合同：事件触发 → 人工确认 → 改判 → 申诉全链可复核
🔗 与坏课治理原子小队（曹海璇）事件范围的关系——KPI 口径 ≠ 小队事件口径
  • 小队首期定义极窄：只做「课中老师缺席（no-notice absence）」一种事件，明确排除网络/设备、迟到早退、口音、长期教师评价或所有"坏课"类型（八要素备案 v0.1 §2.2；00_HUB 范围与非目标）。
  • KPI 一期盒子更宽：缺席族 + 设备网络族——因为战役指标需覆盖用户投诉 70–80% 的交付不稳定主因（缺席 + 设备网络）。
  • 两者共用测量合同：分子去重（课程/约课唯一 ID）、事件触发 → 人工确认 → 改判 → 申诉全链，完全复用小队已建成的测量合同与基线方法。
  • 对接方式：KPI 盒子先按「缺席族」与小队对齐（小队成果直接构成缺席族分子）；设备网络族作为 KPI 独立事件族先行测量，待小队按事件合同扩容后纳入同一执行闭环。教学行为类永不进交付可靠性盒。
  • 防误读：不得以「KPI 盒子宽」推断小队在执行范围内失职，也不得以「小队只做课中缺席」推断 KPI 不应含设备网络——两层口径各有用途，用同一套测量合同连接。
⚠️ 口径边界（会议遗留，必须与 HR/数据侧对齐）
①「坏课」只指当前治理的场景（交付可靠性盒）还是全部问题课？建议一期=盒内，后续按事件合同扩容；② 与 HR 对齐定义（HR 现从 Lily 拿数，两方必须同源）；③ 新师 vs 存量分开归因，避免训练营期新师拖高整体率。

5数学口径：分子 · 分母 · 率量双轨 · 分市场

坏课率 = 坏课课次（盒内事件，按课程/约课唯一 ID 去重） ÷ 应交付约课课次
分母 = 开课窗口内未取消、老师承担交付责任的课次；不是完课数——缺席课次必须留在分母里，否则率被稀释
决策点选项推荐
率 vs 量 A. 只看率（千分位）；B. 只看量；C. 双轨 推荐 C 战役层看率（千分位，如 1.2‰），原子小队/运营层看量（绝对课次 + rebook）。曲建菲提示：率从总量看太小、降 0.1–0.2% 不敏感——率用于对外与目标，量用于内部驱动。
combined vs split A. 合并；B. 分市场 推荐 B domestic / overseas 拆分（可选中东），合并口径掩盖结构差异（历史教训：前置指标分市场看）。对外叙事用变化量："坏课率从 X‰ 降到 Y‰"。
分母定义 总约课 / 完课数 / 应交付课次 推荐应交付课次 学生取消、未进入交付窗口的课次不计入；老师侧承担交付责任的课次全数入分母。
粒度与去重 课程/约课唯一 ID 一行一课 对齐原子小队测量合同 同一课次多事件（迟到且黑屏）计 1 节坏课，不重复计数。
呈现 百分比 / 千分位 / 万分位 千分位为主 率太低时万分位辅助；周度滚动 + 月度冻结值，附量（绝对课次）防失真。
📌 与好老师客户尺的时滞差异（必须明确各自用途）
坏课率是近实时指标（次日可出数），好老师客户尺是 30 天 cohort 指标（30+ 天才出第一读数）。坏课率用于月度经营节奏与现场动作驱动，客户尺用于战果验收——两把尺不混用、不互相替代。

📌 目标协商框架：「两个 lie」
  • lie 1 = 上层的期望（通常偏乐观）
  • lie 2 = 我们影响杠杆的置信度（通常偏保守）
  • 目标定在两者之间是健康协商（会议原话："point 0.2 as a target score, that's a healthy negotiation"）
  • 表述建议："坏课率从基线 X‰ 降至 Y‰"——用变化量，不拍无基线的绝对数

当前已知的影响杠杆（目标设定的现实依据）：

8与 H2 好老师标准 / B+/A 的关系

尺口径角色与坏课率的关系
H2 好老师客户尺（FT-STD-002） 30 天真实授课 + 客户反馈验证、持续创造客户价值的好老师数量及占比（五维：用户反馈/可靠性/硬件质量/有效供给/成长任务） 最终战果验收尺 坏课率 = 五维中「可靠性 + 硬件质量」两维的战役级聚合——同源互补，不是替代
B+/A 老师占比（旧 KPI） 招聘评级 B+/A 占比（Jack 曾定 35%） 已降为入门尺 本次切换：从 B+/A 占比 KPI → 坏课率 KPI，旧尺退役；符合「当最终结果尺变化，旧过程指标必须降格」（GBrain playbook：KPI 向业务结果对齐）
坏课率（本稿件） 坏课课次 ÷ 应交付约课课次（盒内事件） 战役成败指标（非个人 KPI） 补上 FT-RISK-003「在岗老师质量无直接指标」缺口；近实时、可影响、客户可感知
⚠️ 双主帅边界与共签约束
CEO H2 总纲明确：权重须由业务与客户事实共同定义，不能由外教团队自己给自己打分；国内/中东/海外业务负责人必须共同定义客户尺子。坏课率口径虽以「客观事件」为主（相对好老师客户尺争议小），但正式发布前仍需与 Jennifer（双主帅之一）对齐，涉及范围/权重的部分按跨部门共签路径走，不由战役团队单方宣布。
