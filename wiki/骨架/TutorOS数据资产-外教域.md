# Tutor OS 数据资产｜外教域

本页是骨架的**数据资产专题页**，是本地知识库的**数据操作层入口**：判断仍在 [D 域页](TutorOS第二层经营地图.md)，本页只回答"这个数去哪查、按什么口径查、查回来能说到哪一步"。它是跨域输入页（当前主要服务 [D02 教师获取与准入](TutorOS%E7%BB%8F%E8%90%A5%E5%9F%9F-D02-%E6%95%99%E5%B8%88%E8%8E%B7%E5%8F%96%E4%B8%8E%E5%87%86%E5%85%A5.md)、[D04 产能与供需配置](TutorOS%E7%BB%8F%E8%90%A5%E5%9F%9F-D04-%E4%BA%A7%E8%83%BD%E4%B8%8E%E4%BE%9B%E9%9C%80%E9%85%8D%E7%BD%AE.md)、[D14 事实标准与协同执行](TutorOS%E7%BB%8F%E8%90%A5%E5%9F%9F-D14-%E4%BA%8B%E5%AE%9E%E6%A0%87%E5%87%86%E4%B8%8E%E5%8D%8F%E5%90%8C%E6%89%A7%E8%A1%8C.md)），同 [Polly 竞品情报](TutorOS%E7%AB%9E%E5%93%81%E6%83%85%E6%8A%A5-Polly.md) 先例，不设 D 编号、不替代任何域页的现行判断。

## 一、定位与三层路由

数据是第二大脑获得更强能力的前置条件；本地库的目标是「思考 → 数据验证」闭环（判断 → 假设 → 取数 → 写回）。按问题类型路由，不把操作层知识混进判断流：

| 问题类型 | 去哪里 | 说明 |
|---|---|---|
| **判断型问题**（该不该、为什么、怎样才算好） | 既有 [D 域页](TutorOS第二层经营地图.md)（本库二层十五域） | 判断与审级语义一律以域页为准，本页不承载 |
| **查数操作**（指标口径、表结构、SQL） | **Wilson 编译层**（SRC-03）：老师域数据资产目录约 701 篇 + SQL 原子指标库 132 张卡 | 留镜像不逐页进判断流；口径冲突以页内更新日期较新者为准；指标卡含粒度、口径定义与可执行 SQL |
| **资产定义与验收状态**（这份资产是什么、能不能用） | **Jenny 正本层**（SRC-04）：资产说明书 19 篇 + 资产 SOP | 回源层（同 SRC-02 先例）：不全量吸收，用前回源核对定义与验收状态 |
| **直连取数** | company-hive MCP（SELECT-only 网关）+ Jenny 外教招聘 skill（现成 agent 取数技能） | skill 自带范围纪律：只做招聘、只查 `app_ba`／`ovs_app_ba` 两库 |

## 二、三条使用纪律（写死，引用本类目任何资产时适用）

1. **引用任何资产必带其验收状态。** Wilson/Jenny 自述**无一份已验收**（建设中／待联合验收／设计中／待确认）；「建设中／设计中」的资产字段定义可参考，**数值结论需谨慎**，引用时一并注明状态。
2. **比对前先对齐三件事**：①地域（`ovs_` 前缀=海外表，不带=国内表；跨地域先做口径映射）②课型／口径（如同为"开放量"，月表 `opened_lesson_num`=全课型，日宽表 `reserved_slots_cnt`=常规课）③粒度（月 vs 日 vs 教师×天）。三件事不一致，比出来的差异都是假差异。
3. **时间锚点先与业务确认**：申请量按 `reapply_time`、节点通过按 `{node}_pass_time`、Launch 按 `status_on_date`——同一问题换锚点结果完全不同。**事件口径 ≠ 队列口径**：跨月比较时最后 1~2 个月的队列还没跑完，转化率会系统性偏低。

配套判据（Wilson 总览原话）：**发现「反常」时，先检查自己是否漏了一条口径前提，再宣布发现冲突。**

## 边界与明确不做

- **不逐页进判断流**：Wilson 834 篇、Jenny 71 文件留镜像，只按具体缺口按页引用；不为数据资产开 Jev 批量判定轮（操作型知识，worth 问法不适配，SRC-03 已实证 inc=0）。
- **不转水位常驻**：SRC-03／SRC-04 活跃度未评估，是否常驻监测待 Leon 议。
- **审计结论不越界使用**：本库审计结论「主原料地图未显示总体因果优势／零因果级证据」不因本类目建立而改变——数据资产层提供的是**验证用的口径与取数路径**，本类目不会自动给出因果结论；因果判断仍走域页的人审判断流。
- 数值引用三重前提：资产验收状态 + 口径对齐 + 时间锚点确认（见第二节纪律）。
