## 1. NOW｜现在怎么看

**核心问题：** 在某个市场、课程和时段，怎样让需要上课的孩子约到真正能承接的老师，并在不破坏已有承诺的情况下配置供给？

**当前判断：** 产能不是教师总人数，而是符合任务资格、条件可用、愿意开课、未被占用且真正可约的时间。发现缺口后，要定位卡在哪一环，再决定招聘、训练、调整条件或修正规则；同一老师同一时段不能向多个市场重复承诺。[E02][] [E03][] [E07][]

**当前重点：** 接续9月15日已批准的供给规则方向，区分“决定要怎么改”和“系统实际怎么运行”。先解释表面有老师却约不到的原因，同时保护已排课和真实教学质量。[E01][]

| 对象 | 已明确的决定或原则 | 仍未知的部分 |
|---|---|---|
| **D04-D01｜统筹方向** | 供给规则整体交统筹智能体（中央大脑），Shayne推进；Leon明确拒绝继续由人解黑箱。**优先保护客户体验，再追求内部公平合理。**[E01][] | 方向获批不等于统筹系统已完成、规则已经全量解释和接管。 |
| **D04-D02｜两条护栏** | **已排课不回收；国内外同等紧张，靠新招聘配额拉平。**不能为一端腾供给而收走另一端既有承诺。[E01][] | 当前各端实际紧张程度、配额与兑现结果另核。 |
| **D04-D03｜第一刀** | 放开TP CAP新师前10节屏蔽，观察一周；**HBT暂不放**；屏蔽先复核、有罪才关。[E01][] | 10节还是6节的后续阈值由智能体计算、尚未定；放开动作与一周结果本轮没有回执。 |
| **D04-D04｜规则可知** | 9月16日确认规则生效需让受影响双方知晓，先修不可见。[E06][] | 代课误杀的当时窗口无修复结论，不能写成已修好。 |
| **D04-D05｜中心配置顺序** | 9月16日决定：先建中心评分系统（分级方式参考teacher的TIDE），再谈把新生前几节课优先分配给中心——顺序不能反；没有评分就分配，等于把新生的第一印象交给未验证的中心。[E08][] | 评分系统的责任人与口径未定；分配动作尚未发生，不构成执行回执。 |

这些供给决定不能被新的经营假设降格，也不意味着取消教师公平、合理所得和申诉边界。居家与中心仍平行经营，特定TP CAP动作不外推为全部模式统一放开。

## 2. MODEL｜价值怎样产生

**用一个场景进入（诊断示例）：** 招聘表上有一批新老师，但今晚8点找不到合适代课。可能是老师尚未准备好、没有开该时段、被规则屏蔽、课位已被另一市场占用，或客户只接受熟悉老师。继续加招聘人数，只能解决其中一部分；把所有屏蔽取消，也可能让孩子承担新风险。[E01][] [E02][] [E03][]

### 一名老师要经过哪些环节，才能成为一节可兑现的课

```text
在册／上岗 → 资格与授课条件就绪 → 愿意且开放目标时段 → 未受不适用的屏蔽 → 可见、可约且无冲突 → 预约／预占 → 实际交付
                                                                                         │
                       真实需求、失约原因、教师负担与后续质量 ←─────────────────────────┘
```

| 环节 | 有用的核对 | 不能相互替代的口径 |
|---|---|---|
| 招聘与准备 | 这批人何时能承担哪种课，需要什么训练与条件 | 入职人数、launch人数、可授课人数 |
| 时间与意愿 | 实际开放何时、已承担哪些项目、是否持续愿意 | 理论可开时长、已开时段、剩余时段 |
| 规则与可见性 | 适用资格、屏蔽原因、解除条件、谁知道变化 | 在池、被展示、能被特定客户预约 |
| 占用与承诺 | 谁占了哪一课位、到何时释放、冲突怎样处理 | 预占、已约、未消耗余额、真正空闲 |
| 兑现与回流 | 原老师是否兑现、替代是否接受、课堂与成本怎样 | 预约成功、恢复成功、好课与长期供给 |

产能预测可以从预约需要反推时段、活跃天数、活跃教师与流失，再形成补充需要。4月23日材料特别区分模型缺口与业务前置招聘：招聘量可以包含提前准备，不能直接当作当月缺口。Returning（返聘）当时没有稳定放进模型，也不能因此把真实返聘算成零。[E02][]

预测应保留版本、时间、前提与责任，并与实际交付回看；这是本域的建模要求，不宣称目前已有一张全公司统一且可信的表。8月21日讨论已提醒，固定师生比和招聘人数讲不清真实产能；半自动流程仍要有人承担预测、例外和解释责任。[E03][]

> **补证引用（2026-09-21 登记，不改上方判断）：** SRC-01 团队库存有 8 月 Launch 差距分析中的产能口径甄别：CE Interview Slots（当前上游产能，决定每天产生多少 CE Pass 和 Launch）与 Teacher Teaching Slots（Launch 后有效供给，决定真实可预约课量）是两类 Slots，必须分列管理，不得用单一 90% 假设倒推，也不得把 1 个未 Launch 教师 1:1 换算成固定数量的教学 Slots 缺口；新增有效教学 Slots 应按"Launch × 激活率 × 开 Slot 率 × 人均有效 Slots"估算并按市场与课型拆分——见 [AugustLaunchGap 补证件](../../sources/supplement/团队知识库-SRC01/AugustLaunchGap-口径甄别补证.md)（团队知识库 SRC-01，截至2026-08-11；本地资料，钉钉／GitHub未提供）。口径甄别为方法论判断；其中进度快照为截至 2026-08-11 过程记录，9 月以后继为准。本页产能判断不变。

> **补证引用（2026-09-21 登记，不改上方判断）：** SRC-04 Jenny 数据资产库《外教招聘skill（00-SKILL 入口）》提醒跨月比较的口径前提：通过率分**事件口径**（月度通过量）与**同批队列口径**两种，各节点月度通过量不能逐层相除当漏斗（事件口径跨批次混合，会出现 Onboarding > Demo 的倒挂），算真实转化必须用同批队列；**跨月比较时最后 1~2 个月的队列还没跑完，转化率会系统性偏低**——月末看队列数据先校准这一条，再判断供给是否真的变差——见 [时间锚点与队列口径补证](../../sources/supplement/团队知识库-SRC04-Jenny数据/招聘漏斗时间锚点与队列口径补证.md)（团队知识库 SRC-04 · Jenny 数据集资产库，截至 2026-09-21，资产状态=建设中；本地资料，钉钉／GitHub未提供）。取数纪律类方法论，长期有效；不改本页任何产能判断。

### 三种取舍，不能用一个“利用率”解答

**先救当前缺口，还是保留已承诺的课？** 9月15日已决定已排课不回收，国内外同等紧张用招聘配额拉平。市场切换只有在不破坏既有承诺且符合资格、时间和客户选择时才有意义。内部配置效率须服务客户体验，不能靠把失约藏到另一市场实现。[E01][]

**放开限制，还是保护第一批真实课堂？** 应先说明每条限制挡的是什么风险、是否适用于这个老师。TP CAP第一刀是有范围的决定；HBT暂不放、后续10／6节未定仍须保留。不能把一次放开推成“所有规则都无用”，也不能仅因过去曾发生问题就永久屏蔽。[E01][] [E06][]

**满负荷经营，还是保留可用余量？** 备用老师只有在合适、可联系、条件可用且客户接受时才真能兜底。预留余量可能付出成本与机会损失；一味填满又会使故障无处承接。需要看具体时段与风险，而非要求全体老师无偿待命。专项教师非高峰已排满时，低高峰占比也不能直接读成低贡献。[E04][] [E05][]

## 3. BELIEFS｜哪些判断仍待检验

<a id="d04-h01"></a>
### D04-H01｜先找到不可用的环节，常比只增加招聘人数更快解决缺口

**判断：** 如果缺口来自已有老师的资格、时段、屏蔽、可见性或占用，针对该环节处理可能更有效；如果合格时段确已充分使用，真实新增供给就不可替代。[E01][] [E02][] [E03][]

- **支撑与权重：** 原料多次指出在册到可约之间的断点；9月15日给出了明确放开方向。对“卡点存在”的支撑较强，对具体动作能释放多少安全产能，仍缺执行与课堂结果。
- **会怎样改判：** 环节核对后不存在可释放余量，或放开只让可见数增加而实际兑现不增、坏课或教师负担上升，就不能称为有效改善。
- **下一份有用证据：** 选一个缺口时段，把同一批老师从被挡原因追到实际预约与完课，保留另一市场原承诺、学习质量和原有支持投入。

<a id="d04-h02"></a>
### D04-H02｜合适且可承担成本的余量，可能提高恢复能力

**判断：** 故障和临时变化不可完全避免，有条件的备用能力可能减少孩子没课上。但余量只有能被实际调用并被客户接受，才具有价值。[E04][] [E07][]
- **市场边界：** 9月4日听记记录了当时的既有边界：国内学生大量关闭代课、“不要别人替代”（don’t want anyone else），海外相对接受替代安排；因此备用余量能否兜底的讨论至多在海外市场成立，不能外推到国内。[E10][]

- **支撑与权重：** 预占、双占和高峰冲突材料提供机制线索；没有完整成本和跨时段比较，不能下统一比例结论。
- **观察窗判读：** 本假设与H01共享同一观察窗、同一份数据（第一刀即压缩隐蔽余量）；判读标准已于2026年9月18日在页外冻结（本地治理档案，钉钉／GitHub未提供），读数按冻结标准判，不事后两头认领。[E09][]
- **会怎样改判：** 留出的老师不匹配、联系不到，或多数替代不被接受；留量成本和老师机会损失超过被避免的损害，都应缩小或改变安排。
- **下一份有用证据：** 比较具体事件中“有候选备用”和“真正接上课”的差别，记录等待、恢复质量、客户接受、教师所得与完整成本。

## 4. FRONTIER｜接下来想弄清什么

<a id="d04-q01"></a>
### D04-Q01｜为什么看上去老师很多，真正要代课时却找不到人？

**为什么好奇：** 总数很容易遮住资格、时段与关系限制。**当前认识：** 供给链上任何一环不可用，都可能出现这类矛盾；并非每次都该加招聘。**值得继续看：** 从一节未能恢复的真实课倒查当时可用名单，分别看没有候选、没有合适候选、联系不到和客户不接受，保留未成功的尝试。[E02][] [E03][] [E07][]

<a id="d04-q02"></a>
### D04-Q02｜什么条件能让老师持续愿意供给我们需要的时段？

**为什么好奇：** 一次打开课表并不代表长期愿意持续。**当前认识：** 收入、课程结构、已有专项安排、工作条件和规则可解释性都可能影响选择。9月4日转写的专项案例提醒，非高峰已被安排满不能简单再判高峰贡献不足。**值得继续看：** 对照老师实际承担的全部任务与净所得，听其时段选择理由；既看成功动员，也看合理拒绝，避免将安排问题读成态度问题。[E05][] [E06][]
