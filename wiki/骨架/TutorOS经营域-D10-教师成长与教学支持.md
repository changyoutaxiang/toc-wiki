# D10｜教师成长与教学支持

> 老师收到帮助后，下一次遇到相似教学问题，能更好地帮助孩子；时间久了，还能把学到的方法带到新任务、新学生，或帮助另一位老师进步。

## 1. NOW｜现在怎么看

**核心问题：** 怎样让新老师、成熟老师和带教者得到真正能用的帮助，使课堂持续变好，而不把培训出勤、任务完成或晋级当成成长本身？

**当前判断：** **成长要从真实课堂的困难出发，经过理解、练习、实际应用，再回到后续课堂看变化。** 一份清楚的建议、一个正确示范或导师当场协助，都可能有价值，但材料收到不等于掌握，演练通过不等于真实应用，一次表现变好也不等于能力已迁移。[E01][] [E03][] [E07][]

D03 负责新师从进入到早期站稳的过渡，本域负责跨阶段的持续成长。当前来源中的真实建设多发生在新师训练线，不能因此假定成熟教师和导师培养已有同等强度的效果证据。[E02][] [E06][]

**当前重点：** 把“一个具体困难—适合的帮助—下一课实际变化”说清楚，并保留没有用出来的原因。9 月 16 日已将好课定义定为相关建设的唯一硬 P0，个性化任务部署等被点名的新建设后置；这不等于停止既有正常教学支持。委员会主持人和标准完成状态仍未定，不能用宪法旧阶段路线绕过现行闸门。[E10][]

## 2. MODEL｜价值怎样产生

### 从老师下一次遇见同类困难看起

设想一位老师总在孩子停顿时马上给答案。一次支持先让他看见这段课堂，再用短示范练习“等一等、缩小问题、让孩子重试”。下一课他真的用了，孩子能更独立表达，这是一次有意义的变化。若另一次只在导师实时提示下用出来，课堂仍可能受益，但还不能认定老师已独立掌握。这是机制示例，不是已完成试验。[E01][]

### 每一步都服务真实应用

| 过程 | 要发生的变化 | 还不够的证据 |
|---|---|---|
| 看清困难 | 区分教学动作、任务不适配、准备不足与设备条件 | 统一贴上“老师能力差” |
| 选少数重点 | 老师理解为何改、下一课能具体做什么 | 发一份包罗万象的长报告 |
| 示范与练习 | 方法正确，老师有机会试、得到反馈并修正 | 视频已发、培训已参加 |
| 在真实课上应用 | 在对应孩子和任务下使用得当 | 只在模拟课堂过关 |
| 看后续变化 | 相近课堂反复改善，并观察新条件下能否迁移 | 用一节成功课、积分或任务完成证明长期成长 |
| 让方法可复用 | 别的老师也能理解并使用，成本可持续 | 明星导师一直代替老师判断和操作 |

课程支持、导师支持和工作条件共同影响表现。**在正常、可持续的支持下把课上好，本身就是客户价值；能否脱离具体提示迁移，是另一个判断。** 不必为了证明“独立能力”撤掉有用支持，也不能把所有由支持带来的改善都记成老师个人能力提升。[E01][]

### 成立条件、其他解释与取舍

帮助必须赶得上实际课堂。资料到达太晚、老师没时间准备、课临时取消或换了内容，都会使“已经提供培训”无法转化为应用。早期资料提出备课材料触发设想，并同时暴露预约时长、取消和覆盖的未知，不能直接认定自动支持已运行有效。[E07][]

短期培养要选择能改变的高频痛点，设备自救或初见体验也可能值得做；这不是放弃教学，更不能把一种适合幼儿的呈现包装机械套到高年级。学生层次、课程目标、可练习机会和支持成本必须进入判断。[E08][]

**先把少数关键帮助做对、做到能用，再增加任务数量。** 紧急上新时“先顺下来”的阶段闸门有其价值，长期仍要回到真实教学；老师暂时没有足够课堂、退出或材料缺失时，也不能把无法观察的成长填成失败或成功。[E03][] [E04][]

## 3. BELIEFS｜哪些判断仍待检验

<a id="d10-h01"></a>
### D10-H01｜围绕真实困难、少量且可执行的反馈，比泛化培训更容易改善下一课

- **为什么值得相信：** 具体困难能连接示范、练习与真实任务，减少“听懂但不知道怎么用”的断裂。[E01][] [E03][]
- **现在有什么证据：** 有训练设计、示范复核要求和系统建设状态，尚不足以证明这类反馈已比其他方法更有效。[E05][] [E06][]
- **什么会改变判断：** 老师理解却无法应用，反馈把负担转给老师却不改善课堂，或改进只发生在原本更容易的学生上。
- **下一份值得看的证据：** 同一老师相近问题的前后连续课、帮助实际使用情况与失败原因；保留支持强度、课量、退出和缺失，不只挑完成训练的人。

<a id="d10-h02"></a>
### D10-H02｜优秀教学与有效带教是两种相连但不同的能力

- **为什么值得相信：** 自己能教好，未必能解释方法、识别别人的困难并帮助对方练会。导师价值最终应体现在被带教者的真实课堂。[E01][]
- **现在有什么证据：** 设计明确了导师支持边界；本组材料未提供成熟的导师效果对比或带教后迁移验收。
- **什么会改变判断：** 导师帮助只对个别老师有效、主要靠替人完成任务，或成本与依赖程度无法持续。
- **下一份值得看的证据：** 多位被带教者在后续课堂中的变化、失败与迁移，以及导师投入；保留教师求助和纠正通道，不把导师判断变成不可挑战的结论。

## 4. FRONTIER｜接下来想弄清什么

<a id="d10-q01"></a>
### D10-Q01｜老师看懂建议却没在下一课用出来，中间缺了什么？

可能缺练习、时间、合适任务，也可能建议本身不对。当前材料已分出资料触达、备课与真实应用；值得追踪同一个案例在哪一步断开，连同临时换课和取消一起看，不能默认老师不愿改。[E03][] [E07][]

<a id="d10-q02"></a>
### D10-Q02｜怎样的老师，既能自己教好，也能帮助别人教好？

名师示范容易看见，带教者是否能诊断、解释并适时退出更难确认。现在只有方向与边界，值得看受助老师在没有导师当场代办时能否用出方法，以及不同导师、不同受助者间的差异。[E01][]

<a id="d10-q03"></a>
### D10-Q03｜已经稳定授课的老师，在什么经历之后再次明显进步？

成熟老师可能需要更难的学生、更具体的同伴反馈或新课程挑战，未必适合重复新师培训。现有来源中新师建设更丰富，成熟教师的连续成长样本仍不足。值得先看真实转折案例，理解改变发生的条件；不能拿升降级积分方案代替成长证据。[E02][] [E09][]
