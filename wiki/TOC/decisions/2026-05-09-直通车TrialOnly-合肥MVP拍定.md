# 直通车转向在库好老师运营出清 · Trial Only 合肥 MVP 拍定

> 编译自 2026-05-08 直通车讨论要点摘要 + 2026-05-09 Trial Only 方案讨论。直通车立项拍板见 04-15 总纲（[[2026-04-15-Q2战役总纲与三标收敛]]）与 [[直通车项目]]；本页记录其「从供给侧入库转向在库出清」的方向拍板与 Trial Only MVP 机制。

## 背景

4 月新老师利用率仅 8.5%–14%，问题从「老师不够」转为「好老师卖不出去、利用率太低」——直通车不再只是招聘通道，进入「在库好老师加速出清」阶段。

## 决策内容（05-08 方向 + 05-09 机制）

1. **直通车三段式框架**：① 重塑好老师黄金标准（底座，先讲清楚 A/B+ 判定标准）；② 招聘 Fast Track 流程轻改造（建议轻做，更多交给菲律宾供应链团队落地）；③ **A/B+ 新老师运营出清 = 当前最核心优先级**。
2. **运营出清打法**：产品端 App 内单独分区 +「新上线老师」专区 + 标准化自我介绍视频包装（老师自己卖自己）；渠道端按「谁更饥渴」先启动哪边、业务端需求不强就绕开对接全平台家长；运营端定期新老师推荐直播 + 教学理念宣讲 + 盯蜜月期体验（先小范围 5000 节课验证再放大）。先打「锦州」：手头囤货好老师快速出清、老师尽快满约。
3. **Trial Only 落地形态（05-09 拍定）**：把高潜 leads + 最会卖的 CC + 可包装的 A/B+ 老师 + 可锁定常规课档期捆成成交机制；**杀手锏 = 所见即所得 + 当场锁定**（家长体验课喜欢某位老师后，CC 立刻锁定未来一个月常规课排期，消除「体验课老师和常规课老师割裂」的最大抗性）；**Q2 底线目标 M0 转化达 8% 拉平 Polly**（小红书直播渠道已从 4% 提到 6.4%）。
4. **MVP 场 = 合肥**（「锦州之战」项目组）：需求最强、反馈频次最高；对照：相同小红书渠道合肥约 6.31% vs 上海约 3.02%；先跑单点闭环不急于严谨渠道 A/B。
5. **师资与排课**：只做青少儿 ESL（听口/词汇语法/自然拼读），暂不做成人；用未被充分利用的 A/B+ 老师（发音/形象/网络/设备硬指标）；**FDR (Regular) 系统标签**，核心高峰 18:00–20:30 每周 ≥30 slots，FDR slots 只对合肥试点销售团队隔离可见；周期暂定 8 周，动态看转化率/出席率、不达标淘汰，表现好课表排满后回归常规池并可升级项目培训师。
6. **销售端**：放弃「课前 2 分钟随机分配体验课老师」的开盲盒模式，改人工「销售代约制」（CC 盯高潜家长 + FDR 专属 slots）；引入直播间稀缺话术。
7. **试点期允许「积极作弊」**（人为加料验证机制上限：课前深度备课、课后 CC 高频介入、针对性反馈），不是长期模型。
