# 坏课KPI设计稿

坏课 KPI 设计稿（Q3/Q4 教师侧战役指标，替代 B+/A 老师占比）——同一设计稿的 4 个版本（v0.1~v0.4），**以 v0.4（中英双语）为当前版本**编译主体口径；本页内容全部为设计稿观点，**非生效 KPI**。

- 起草：COO（Leon 侧）· 2026-08-26 · 对齐对象：Jennifer / Katherine / 海璇 / Lily / HR / 双主帅
- 状态：讨论稿（v0.4 已定项 + 少量 Open），需 Leon 拍板 + 与 Jennifer（双主帅之一）、Lily（数据源）、HR（现口径）对齐后方可向公司提议

## 设计目标（为什么换尺）

Q3/Q4 将「坏课率」确立为**外教战役级交付可靠性指标**（战役成败指标，**非个人 KPI**）：

> 坏课率 = 坏课课次 ÷ 应交付约课课次；定义盒子只装「客观有标准且可侦测的坏」——①老师纪律 ②课堂稳定 ③教学行为（只抓可侦测的 P0）；学生反馈类不纳入、定位为探针；分市场呈现；Q3 冻结定义与基线、Q4 挂目标；千分位展示。

取代 **B+/A 老师占比**（已降为入门尺，非废除）；与 H2 好老师客户尺（30 天验证）**同源互补、不打架**。

**换尺四理由**（2026-08-25「Teacher event and KPI」会议共识，参与者：王东 / Jennifer / Katherine / 曲建菲）：

| # | 理由 | 依据 |
|---|---|---|
| ① | 与当前工作一致 | 海璇原子小队坏课项目、王韬 initiative、TIDE 防坏老师——都在打坏课，KPI 需呼应 |
| ② | 客户价值直接 | 各市场一致：用户投诉/不满最大来源是交付不稳定（老师缺席 + 电脑/网络设备两类，约 **70–80%**） |
| ③ | 客观可测量 | "bad lesson is customer value"；好老师数量不客观、难影响 |
| ④ | 两三个月可做很多 | 坏课可快速影响；好老师（口音/评级）难在短周期改变 |

**历史沿革**（为什么旧尺走不下去）：

- **6/29 KPI Catch-up 决策**：放弃 B+/A 作为核心 KPI（Jack 曾定 35% B+A 干不出来）；确立三块可感知指标——坏课率 + 学生投票 + 合规。坏课定义初版：**四害（迟到/早退/缺勤/黑屏）+ 设备 + 网络**。
- **7/13 CEO H2 总纲**（[[2026-07-13-CEO下半年外教战役指示-双主帅H2总纲]]）：最终战果 = 经 30 天真实授课与客户反馈验证、持续创造客户价值的好老师数量及占比；B+/A 降为入门尺。权重须由业务与客户事实共同定义，不能外教团队自己给自己打分。
- **7/28 五维设计定稿**（[[好老师生命周期]]）：好老师五维 = 用户反馈 / 可靠性 / 硬件质量 / 有效供给 / 成长任务。「可靠性」「硬件质量」两维正是坏课率覆盖的战场。
- **8/14 坏课治理原子小队备案**（DRI 曹海璇，待建）：首期只做「课中老师缺席（no-notice absence）」的实时客户保护；测量合同（课程 ID 去重、事件定义、恢复窗口）已成型，是坏课 KPI 分子口径的最佳起点。
- **8/26 Leon 输入与主张**：定义盒子重构为四大类（v0.2）→ P0 准则 + 学生反馈不纳入（v0.3）→ ③类只抓可侦测的 P0（v0.4）。

## 指标口径（以 v0.4 当前版为准）

### P0 坏课第一准则（Leon 主张 · 已定）

> **「坏」必须是客观有标准且可侦测的坏。**

反例：老师上课无精打采——很难纳入坏课范畴，因为很难有标准，也不容易准确侦测。不符合「客观有标准 + 可准确侦测」的，一律不进入坏课盒子；先过 P0 这一关，再谈其他。

设计原则共五条：P0 客观有标准且可侦测（准入门槛）+ P1 客户可感知（基本法第 1 条）+ P2 可影响（只放老师/系统动作能改变的项）+ P3 可测量（无信号不硬造，FT-RISK-003）+ P4 防 Goodhart（四化宪法第 7 条）。

### 定义盒子：三大类 + 反馈探针

定义盒子是坏课 KPI 的**唯一事实源**（对齐 HR/Lily/数据侧后冻结，发一张废一片）。按 P0 过滤后一期为三大类：

| 类别 | 事件（候选） | 客观性 / P0 符合度 | 挑战点 | 一期状态 |
|---|---|---|---|---|
| ① 老师纪律类（Attendance / Discipline） | 缺席（no-show）、课中缺席、迟到、早退（⚠️ 假早退：TOC-16 已裁须并入，事件表未改） | 纯客观，完全符合 P0（标准明确=时间戳、侦测可靠=AC/课程状态） | 阈值定义（**迟到 >5 分钟？**）；⚠️ **旁注（已裁·不整表升冻结）**：TOC-15＝迟到起算 **1 分钟**；TOC-16 假早退须并入——正式改表另批（TOC-92）；事件确认（人工/自动）；改判（平台故障 vs 老师责任）；课中缺席复用原子小队测量合同 | 一期纳入 |
| ② 课堂稳定类（Classroom Stability） | 黑屏/无画面、无声、断连中断、严重卡顿 | 客观，符合 P0，但标准阈值待冻结 | 多严重算坏课（**断连 >X 秒？黑屏 >X 分钟？**）；**设备分 3500 是准入线**、课中动态问题是另一套口径；信号归属（设备 vs 网络 vs 平台 vs 学生侧） | 一期纳入，标准待冻结 |
| ③ 教学行为类（Red-line Behavior） | **只抓可侦测的 P0**：AI 视觉/音频可侦测的红线行为（裸露、吃东西等）；**不纳入**：打哈欠、无精打采等标准模糊/难侦测的行为 | 偏客观，以 AI 侦测能力为边界（Leon：现在 AI 有视觉能力，不少问题能侦测） | 误报漏报；隐私与合规边界；人工复核比例；行为清单以「可侦测」为准逐项过筛，不是"想抓什么抓什么" | 一期纳入（可侦测 P0 子集），清单待 AI 侧评估 |
| ④ 学生反馈类（Student Feedback） | 投诉、拉黑、差评 | **主观**，不符合 P0（主观、不均匀、可被干预） | ——不纳入坏课；定位为探针 + 质检触发 | 不纳入（已定） |

**口径边界（与 HR/数据侧对齐）**：①「坏课」= ①②③类盒内事件，后续按事件合同扩容；② 与 HR 对齐定义（HR 现从 Lily 拿数，两方必须同源）；③ 新师 vs 存量分开归因，避免训练营期新师拖高整体率。

### 数学口径

- **分子**：①②③类盒内事件，按课程/约课唯一 ID 去重后的坏课课次（同一课次多事件——迟到且黑屏、缺席且断线——计 1 节坏课，不重复计数；但各事件类型分别留痕，供归因与治理定位）。
- **分母**：**应交付约课课次**（开课窗口内未取消、老师承担交付责任的课次）——不是完课数，缺席课次必须留在分母里，否则率被稀释。学生取消、未进入交付窗口的课次不计入。
- **率 vs 量双轨**：战役层看率（千分位，如 1.2‰），原子小队/运营层看量（绝对课次 + rebook）。曲建菲提示：率从总量看太小、降 0.1–0.2% 不敏感——率用于对外与目标，量用于内部驱动。
- **分市场**（已确认）：domestic / overseas 拆分（可选中东）——不同地区「严重程度」与「可干预程度」不同，合并口径掩盖结构差异。对外叙事用变化量："坏课率从 X‰ 降到 Y‰"。
- **呈现**（已确认）：千分位为主，率太低时万分位辅助；周度滚动 + 月度冻结值，附量（绝对课次）防失真。
- **类别分率**：总率 + 分类率双出——总率用于战役 KPI，分类率（纪律/稳定/行为各自）用于定位杠杆与责任。

### 学生反馈类：探针 + 质检触发（Leon 主张 · 已定）

投诉、拉黑、差评**不进坏课**——它是很好的探针（持续洞察「客户对什么不满」），可以触发质检，但不放入坏课。三条理由（Leon）：① 它是客户主观的；② 它不均匀（**评价率仅 30–40%**、样本偏）；③ 它有被干预的可能（恶意差评 / 刷分 / 曝光分配污染——好老师前置到更优流量会天然抬高其客户指标，H2 已标测量悖论）。

落地机制：① **探针**——投诉/拉黑/差评的主题聚类与趋势作经营洞察看板，坏课率复盘必须对照探针看（率降了但客户仍不满 → 口径没打到真问题）；② **质检触发**——投诉/差评 → 触发质检/人工复核 → 核验成立且对应①②③类客观事件 → 该课次按对应类别正常计入分子（按课程 ID 去重）。即主观反馈是**发现机制，不是分子本体**——呼应会议原话"系统应该告诉我们发生了什么，而不是等学生投诉"；③ **归 H2 客户尺**——与纪律/稳定/行为无关的体验反馈（口音、风格、级别错配）归 H2 好老师客户尺（用户反馈维）与师生匹配。

一句话：**坏课率管「客观的坏」；学生反馈管「客户的不满」——前者是 KPI，后者是探针。**

### 与坏课治理原子小队（曹海璇）口径的关系——KPI 口径 ≠ 小队事件口径

- 小队首期定义极窄：只做「课中老师缺席（no-notice absence）」一种事件，明确排除网络/设备、迟到早退等（八要素备案 v0.1 §2.2）。
- KPI 盒子更宽（①②③类）——战役指标需覆盖用户投诉 70–80% 的交付不稳定主因。
- **两者共用测量合同**：分子去重（课程/约课唯一 ID）、事件触发 → 人工确认 → 改判 → 申诉全链，完全复用小队已建成的测量合同与基线方法。
- 防误读：不得以「KPI 盒子宽」推断小队失职，也不得以「小队只做课中缺席」推断 KPI 不应含其他类别。

### 与好老师客户尺的时滞差异

坏课率是**近实时指标（次日可出数）**，好老师客户尺是 **30 天 cohort 指标（30+ 天才出第一读数）**。坏课率用于月度经营节奏与现场动作驱动，客户尺用于战果验收——两把尺不混用、不互相替代。坏课率①②③类 = 五维中「可靠性 + 硬件质量 + 行为红线」的战役级聚合；学生反馈天然归 H2「用户反馈」维——职责分明。

## 已拍板 / 待拍板 / Open 问题（v0.4 状态）

**已拍板（Leon 主张 / 确认）**：① P0 坏课第一准则（坏 = 客观有标准且可侦测）；② ③类范围 = 只抓可侦测的 P0（AI 视觉能力可侦测的红线行为），抓不了的（打哈欠/无精打采）不纳入；③ 学生反馈类不纳入（探针 + 质检触发，核验成立的客观事件回填①②③类分子）；④ 分市场 split（domestic / overseas，可选中东）；⑤ 千分位为主、万分位辅助。

**待 Leon 拍板（v0.4 剩余 7 项）**：① 三类盒子是否全部一期纳入（推荐：①②③ 纳入，③行为类侦测未就绪可先影子测量）；② ③类可侦测 P0 清单（Open #1，待 AI 侧准确率评估）；③ 率 vs 量（推荐 C 双轨）；④ 分母定义（推荐应交付课次，缺席课次不逃逸分母）；⑤ 节奏（推荐 Q3 冻结定义+基线、Q4 挂目标，无基线不挂目标）；⑥ 目标值协商（推荐两个 lie 框架定变化量）；⑦ 对齐路径（推荐双主帅 + Lily/HR 对齐后发布，CEO 约束跨部门共签）。

**Open 问题（讨论稿显式保留）**：O1 ③类可侦测 P0 清单（9 月第 1–2 周）；O2 ②稳定类「多严重算坏课」阈值——断连/黑屏时长、卡顿标准（待数据侧信号分布，9 月第 1–2 周）；O3 分市场是否各自定目标（同盒不同尺，Q4 初）；O4 新师 vs 存量的归因与权重（9 月训练营规则定稿时）。
