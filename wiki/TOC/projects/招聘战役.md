# 招聘战役

> 编译自《招聘战役.md》（源 frontmatter：type `initiative` · status `active` · priority `p0` · owner `Jen` · decision_state `aligned` · updated_at 2026-04-25 · confidence `medium` · workstream `招聘战役`）。
> **时点语义**：本页为截至 2026-04-25 的招聘战役状态记录（Q1/Q2 时点），非当前状态。2026-07-13 H2 总纲（[[2026-07-13-CEO下半年外教战役指示-双主帅H2总纲]]）换尺后，招聘战役的「保量」成为 H2 供给底线，质量相关由五项硬任务承接（30 天试用训练、好老师价值前置、客户反馈闭环等）。

## 当前判断

招聘战役 Q1 的首要任务是恢复供给安全，Q2 已进入「保量基础上重塑关键抓手」阶段：最重要的突破点不是继续零散修漏斗，而是**优先抓基础设施和组织 owner**。

- 2026-04-23 补入海外侧下标逻辑澄清后，招聘目标这条线的主要问题从「缺输入」切换成「如何把国内 / 海外压成同一张管理口径图」。
- 2026-04-24 Tammi / 王慧沟通：漏斗关键卡点继续下沉到 CE 末端，且 CE 链路的组织拆分本身已成为效率问题。
- 2026-04-25 公司把 cost per launch 从 2000 比索压到 1500 比索：渠道策略从「缩洪水 + 做 KOL / Referral 试验」进一步切到「更坚决收缩外部投放，把资源优先压到 Referral」。

## 状态卡片（截至 2026-04-25）

- owner：Jen；status：active；priority：p0；decision_state：aligned。
- blockers：培训参与率与通过链路仍是末端卡点；Referral 与 Website owner gap 尚未补齐；沟通矩阵 rollout 未完全收敛为统一执行链；国内 / 海外招聘目标统一管理口径未压成一张规则；Marketing-CN 缩量后的漏斗纪律与跟踪及时性需强执行；Referral readiness 未证明足以承接 MKT / KOL 回流资源；菲律宾负面雇主品牌资产与外部渠道收缩后的替代路径未完全治理；CE 数量不足、slots 供需预估不匹配与通过率偏低正把卡点推到 CE 末端；招聘漏斗/国内 CE 审核/海外 CE 审核分属不同 owner 链路、沟通成本高。
- next step：按 1500 比索约束继续高 ROI 渠道收缩与漏斗纪律，资源重心从 MKT / KOL 切向 Referral；统一国内 / 海外招聘目标为一张管理口径图；补齐 Referral readiness、体验修复与承接测算；把 CE 末端问题拆成数量 / slots / 通过率三类管理项；Leon 以直接调度群为入口对关键项目负责人直接编排，并对 CE redemo 与 NTT→CE→自动化衔接链路亲自硬推。

## 当前状态（截至 2026-04-25）

- 3 月招聘量达 2000，数量上回到正轨。
- 资料提交率与初筛通过率基本回归正常；培训参与率与通过相关环节仍是最后卡点。
- Marketing-CN 收缩到高 ROI 渠道、停止洪水，漏斗纪律抬到更高要求。
- 05-11 前倾向「Q2 市场资源 80% 转向 KOL」；04-25 后 MKT 与 KOL 都进入更坚决收缩范围，Referral 成为更优先的资源承接方向。
- CE 问题近期显著抬头：数量不足、slots 供需不匹配、通过率偏低但归因未定三类。
- Leon 已按「一号位思维」改为按项目结果直接调度负责人，以直接调度群为新入口。

## Q2 关键突破点

- 入门期薪酬倾斜（[[入门期薪酬倾斜]]），提升新招好老师占比。
- 沟通阵地 / 沟通矩阵建设（[[沟通矩阵建设]]），横跨漏斗和渠道。
- Referral owner 明确，形成端到端执行链条（见 [[Referral重启]]）。
- 创新动作优先放在市场测试渠道验证。
- 停止洪水后用更高纪律守住缩量后的 leads 跟踪与节点清零。
- 用 KOL 承接更高质量 leads 与品牌背书，而不是继续放大买量洪水。
- 把 CE 末端卡点拆成数量、slots、通过率三类问题单独管理。
- 推动招聘漏斗、国内 CE 审核、海外 CE 审核三段链路收敛成更短的协同结构。
- 对 CE redemo 与 NTT→CE→自动化衔接这类高摩擦链路，Leon 直接穿透和硬推。

## 当前关键项目（截至 2026-04-25）
