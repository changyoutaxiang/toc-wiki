## 顶层定义

完整对象应定义为**教师运营系统体系**——一个共享使命和共同事实的「系统之系统」，不是一套由 TOC 包办全部动作、审批和结果的超级系统。使命：

> 持续把教师产能转化为客户学习价值、教师长期价值（即教师价值）和健康经营结果，并让每轮运行提高下一轮的系统能力。

本稿采用 **zero-based thinking**：不从现有部门和现有功能出发，而从最终价值、受控对象、完整反馈回路和责权对称出发划分系统。

## 二、什么才值得叫一级系统

一级系统必须同时满足五个条件：**独立结果**（为谁创造什么结果）、**受控对象**（控制什么对象及其状态变化）、**完整闭环**（感知、判断、行动、反馈、改进）、**责权对称**（主 owner 对结果负责并拥有相称决定权）、**失败可见**（能识别未完成、超时、冲突、数据断流和结果恶化）。

不满足五项的对象不硬叫一级系统：只提供共同事实的 → 公共平台；只承担某一段动作的 → 系统模块；横跨两个独立 owner 的 → 跨系统契约；需 HR、财务、法务承担不可转移专业责任的 → 受保护 Gate。这条判据防止把「有部门、有流程、有软件页面」误当成「有系统」。

## 三、四个经营系统要点

**O1 全球供需与组合控制系统**（owner: TOC）：受控对象 = 教师产能单元（教师 × 市场 × 课程／产品 × 时段 × 可用状态 × 质量／资格状态），不把「培训人数、打标人数、名单人数」直接当作产能。核心判断：各市场需要多少、什么类型、什么时段；缺口应通过招聘、训练、激活、调度还是需求降速解决；跨市场冲突时怎样分配并保护长期价值。输出：唯一供需账、分市场/课程/时段的产能合同、缺口/风险/升级清单、对 O2 的供给任务、对 O3 的可使用产能边界。成立判据：700／730／1200／1500／2000 等数字各有唯一对象、分母和用途；供给缺口能自动暴露；Leon 不催，供需周期仍按节奏运行。

**O2 菲律宾教师供给制造与本地服务系统**（owner: 菲律宾本地运营）：包含渠道和招聘漏斗、全球硬门槛下的本地准入、Orientation/Practice/训练交付、教师激活与档期、Routine 触达与本地服务、Center/设备/网络/考勤/灾备、教师侧事实核验/申诉/整改执行。**允许本地自治**：渠道组合、运营节奏、本地沟通方式、硬门槛内局部试验。**不允许本地静默修改**：全球 Teacher ID 和生命周期状态、全球纪律/设备/出勤/合规硬底线、对外已承诺的资格和产能定义、影响教师收入/流量/停课/退出的正式 Gate。成立判据：产能承诺能回到具体教师、档期、资格和证据；Routine 不再依赖逐人催办；新开 Center 或更换管理者后仍可复制运行。

**O3 市场教师价值实现系统**（owner: 国内／对应海外市场业务负责人）：一套共同架构、多个区域实例（O3-D / O3-O）。包含教师产品化与信任资产、市场库存预约释放、匹配推荐曝光课量分配、新教师冷启动与双保护、课堂交付协调、客户问题受理补救关闭、区域实验与回滚。**市场可自治**：偏好权重、包装展示、匹配推荐曝光策略、客户补救方式、边界内可逆实验。**市场不可各自为政**：不另造 Teacher ID 和生命周期状态、不静默改变全球硬门槛、不把区域偏好冒充全球质量标准、不通过私下名单和人工关系绕过共同供给与资格状态。成立判据：教师质量提升能同步体现为真实使用和客户结果提升；放量有基线、对照、停机线和回滚；客户关闭与教师根因消除不再被混为一个状态。

**O4 全球教师辨识、成长与治理系统**（owner: TOC）：包含招聘后 30 天持续辨识、巡航期质量感知、评价线（统计画像与长期判断）、干预线（事件及时响应）、训练支持复核、同因复发与根因预防、受保护权益 Gate、教师解释申诉更正回滚。**四条硬边界**：① 全球硬门槛统一，区域权重可以不同；② 评价与干预分离——一次事件可以立即响应，不等于立即给教师定性；③ 客户反馈是传感器，不是未经校正的最终裁决；④ 总分不能直接改变教师生计。成立判据：任意判断可以回到事实、时间窗、样本量和规则版本；观察、干预、资格和权益动作分层；教师知道为什么、还差什么、怎样申诉。

## 四、两个公共平台要点

**P0 教师事实与证据平台**：让所有系统始终在说同一个教师、同一个状态、同一个事实。只负责事实（Teacher ID、生命周期状态、课程/档期/设备/网络/纪律事实、教学/客户反馈/任务/权益动作证据、来源时间口径版本刷新状态可信度），**不直接负责裁决**（是不是好教师、是否加流量、是否降薪停课退出——属于 O4 和受保护 Gate）。成立判据：一个 Teacher ID 可串起完整生命周期；每个指标可回到来源、时间、粒度和口径版本；三地不再长期依赖人工 Excel 对账。

**P1 经营编排与系统学习平台**：让四个经营系统能被共同观察、编排、审计和持续改进。公共能力：信号识别、任务创建分配、owner/状态/截止/升级、Routine 自动执行、异常转人工、Agent 建议执行监控、数据断流/任务失败/接口异常告警、规则流程 Skill Eval 版本管理、旧入口旧报表旧人工交接退役、运行结果回放和学习复用。**不持有的权力**：不替 O1—O4 定义经营目标、不替区域决定客户策略、不替 HR/财务/法务作专业裁决、不因 Agent 置信度高就自动执行高风险权益动作。成立判据：任意任务都有来源、owner、状态、期限和结果；异常主动暴露而不是等强人发现；高频人工动作持续沉淀为规则/Skill/系统能力；每个经营周期都有旧路径真实退出。

## 五、三份跨系统契约要点

**C1 需求—产能契约**（O3 ↔ O1 ↔ O2）：必须写清需求对象和预测窗口、数量质量课程市场时段、供给状态定义（名单/培训/打标/质检/可约/稳定交付）、供给承诺确认节奏和变更窗口、缺口阈值预警时点和升级责任、调度优先级/客户保护/其他市场影响、成本失约补救复盘规则。失败状态：需求无口径、供给数字混层、临时需求绕过统一账、供给失约未预警、调度伤害其他市场却不可见。

**C2 教师产品—客户结果契约**（O2 ↔ O4/P0 ↔ O3）：必须写清教师产品最低字段和展示资产、资格质量档期设备风险状态、全球硬门槛与市场权重分界、市场可使用/不可使用/需人工复核状态、匹配曝光预约连续性结果、复约收藏固定投诉拉黑退费沉默流失回传、结果回传时效可信度和失败告警。失败状态：好教师标签停留在招聘端未进入市场使用、市场私下维护不可比较名单、客户结果不回流、曝光变化污染质量判断却没有对照、市场偏好被冒充为全球标准。

**C3 事件—整改—权益契约**（O3 ↔ O4 ↔ O2 ↔ HR/财务/法务/专业系统）：必须写清事件唯一入口和分类、原始事实/客户影响/教师影响/证据、客户补救 owner 时效和关闭条件、教师事实核验/整改 owner 和完成条件、评价线与干预线、同因复发和根因消除判据、权益动作的证据共签生效解释申诉回滚、各状态升级条件。**必须保留两个独立状态**：① 客户问题是否已回复、补救和关闭；② 教师侧根因是否已整改并验证不再复发。失败状态：客户回复完成被当作根因消除、菲律宾整改完成但市场仍持续受损、一个总分直接触发流量/收入/停课/退出、申诉更正回滚没有入口、工单关闭率掩盖同因复发。

## 六、TIDE 与未来一年双主轴

**TIDE 是 Leon 八月最重要、最高优先级的 P0**：TOC 成立后的第一仗、目标中的全公司第一个蜂巢／日心说成功试点、外教运营系统化的第一站。八月完成经受生产环境考验、具备扩量条件的试点；九月铺到全部新老师。（术语消歧：「八月 P0」是工作优先级；「P0 教师事实与证据平台」是架构编号，两者不是同一个概念。）**TIDE 不是第五个经营系统，也不等于 P1 平台本身**——它是第一条跨系统生产纵切面：由 P0 提供可信可追溯数据燃料，由 P1 承接任务状态反馈学习闭环，贯穿 O2（新师训练交付）与 O4（持续辨识成长资格治理），最终必须接回 O3 的客户使用与真实结果，否则只能证明内部系统运行，不能证明教师价值。

**TOC 未来一年双主轴**（Leon 将 TIDE 与直通车定为 2026 年 8 月起未来一年的两项根本性改革）：① **TIDE 新师营 → 老师管理彻底系统化、AI 化**；② **直通车 → 供应模式根本转型**（客户从「被系统分配老师」走向「看见、选择、体验并能继续跟随同一老师」，倒逼 O1 供需规划与 C1、C2 契约真正运行）。合成回路：O2／O4 经 TIDE 生产老师与可信证据 → O1 形成可售产能 → O3 经直通车让客户看见、选择、锁定并持续使用 → 客户与经营结果回流 P0／P1 和 O4 → 下一轮训练、治理与供给调整。长期终局不是粗暴合并体验课池与付费课池，而是**一个统一教师供给底座 + 各市场／课程／场景的动态分配策略**。

## 七、系统责任清单

| 一级对象 | 系统 owner | 不应承担 |
|---|---|---|
| O1 全球供需与组合控制 | TOC | 菲律宾日常招聘、市场客户策略 |
| O2 菲律宾供给制造与本地服务 | 菲律宾本地运营 | 全球调度、区域客户经营 |
| O3-D / O3-O 市场价值实现 | 国内／对应海外市场业务 | 菲律宾本地管理、全球质量定义 |
| O4 全球辨识、成长与治理 | TOC | 未经责任链自动改变教师生计 |
| P0 教师事实与证据平台 | TOC 持业务语义 | 替业务作价值裁决 |
| P1 经营编排与系统学习平台 | TOC 持业务编排 | 成为所有业务判断的超级老板 |

**必须全球统一**：Teacher ID 和生命周期状态；供需与有效产能语言；全球纪律/设备/出勤/合规硬门槛；数据来源时间粒度和口径追溯；事件状态和跨系统升级语言；权益动作的证据共签解释申诉回滚要求；系统运行与学习的最低验收标准。**必须触发升级**：全球硬门槛与区域经营冲突、一个市场调度伤害其他市场或客户承诺、供给无法兑现且超契约阈值、数据断流/事实冲突/关键口径漂移、涉及教师收入流量暂停停课退出、客户伤害/教师公平/合规/生产安全风险、局部经验拟上升为全球规则。

## 八、反人治验收

每个一级系统和平台都必须通过八问：换一批人还能否按共同事实和规则运行？Leon 不参加能否完成一个完整经营周期？异常会主动暴露还是等熟人发现催办？每个判断能否回到来源、口径、规则版本和责任人？动作是否有状态、截止、完成条件和结果回写？跨系统失败是否按契约升级而不是临时拉群找人？每轮运行是否沉淀数据、标准、流程、Skill、Eval 或系统能力？是否有旧表格、旧入口、旧报表或旧人工交接真实退出？

四个总检验：**客户价值**（客户是否更容易获得并持续使用合适教师）、**教师价值**（教师是否获得清晰、公平、及时且可申诉的成长与治理）、**经营价值**（有效供给、履约、匹配和单位经济性是否改善）、**反英雄**（第二个人能否独立运行，Leon 退出日常路由后系统不失速）。

## 九、当前待确认项（截至 2026-08-03）

1. O2 是否由菲律宾本地运营整体持有，还是招聘、训练、Center 已存在不可合并的独立权责边界；
2. O3 的海外实例按「全球海外」还是按市场分别设系统 owner；
3. TOC 对 O1、O4 是否已有相称的人员、预算、规则和跨部门仲裁权；
4. 教师产品化在 O3 由市场持有后，TOC 保留哪些全球共同字段和供给保护权；
5. O4 权益 Gate 中，评级、流量、课量、薪酬、暂停、退出分别由谁共签；
6. P0 的 Teacher Master、持续摄入、质量 SLA 和异常告警当前真实成熟度；
7. TIDE 已作为首条生产纵切面进入八月 P0；P1 最终复用哪些 TIDE 能力、哪些只视为候选实现，仍须用生产证据判断。

**下一版应逐系统补齐**：具体系统 owner／第二负责人／核心指标／输入输出合同／源系统／标准卡／流程卡／异常升级／人工 Gate／旧路径退役／首个真实验收场景。建议顺序：先列 O1—O4 具体人名和授权差距 → 再把 C1—C3 写成可签署可回放的接口合同 → 选一个最小但完整的真实闭环做样板 → 最后决定哪些模块需要软件、Agent、Skill 或组织调整。

## 2026-09-10 组织专场补充：自动化瓶颈已从动作延伸到数据链和费用分类
