# 数据治理重心转向「给 Agent 用」，前置瓶颈是指标字典

## 认识

数据治理重心明确**从「给人看」转向「给 Agent 用」**。取数 Agent 是真正价值点：MCP 已能对自然语言问题给出与 BI 完全一致的结果且带推理，「它把数分这个手艺活 Agent 化了」；推论是过去的运营能力约等于数据分析能力。硬约束：**MCP 指标名必须与看板指标名完全一致才能命中**（「现在都要暗号」）；解法是**一次性做出口径字典喂给各 Agent**，让 AI 做模糊匹配。外教侧已产出草案：约 59 个看板、1000 多个指标，定位「给机器读的口径说明书」。**反向约束同时成立**：高频且结果明确的指标仍固化在看板，只有复杂探索性分析才交给 AI。

## 背景与证据

三条治理线拉平：中东数据集 11 个、进度 95%、9 月底交技术验收文档；外教侧 Q3 预计 24 个数据集、完整交付 12 个；菲律宾本月 8 个、交付 6 个核验中。泰国侧靠取数 Agent 直接追平港澳，是当前唯一能力对标证据。

## 边界

单域样例+单一使用者体验，无规模化结果证据；字典「万级」为估算、外教侧草案仍是草案；反向约束未成文、与重心转向的分界未定。用法：资源投向先问数据产品「给人看还是给 Agent 用」（不等价）；Agent 上线前置清单=指标字典，否则只能「对暗号」。
