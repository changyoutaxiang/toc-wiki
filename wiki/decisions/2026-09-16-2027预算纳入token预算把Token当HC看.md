# 2027 预算纳入 token 预算（把 Token 当 HC 看）

> 编译自钉钉「51 高管群」（09-16 15:39，话题 #把Token当HC看#）+ 单聊采集，与 Leon 日结确认稿（RCL-2026-09-16-v1，MEM-12）。

## 口径内容

各部门 2027 预算须新增 **token 预算账户**。Leon 原话要点：「今年大部分部门没有这个『账户』」「调研团队用量骨干，今天骨干的用量大概率就是明年平均用量」「未来人力预算与 Token 预算占比，后者会越来越大，相当于『智能员工的工资』」。

**推导**：既然"骨干用量＝明年平均用量"，基数应按骨干定，不按全员当前平均——否则第一年必然不够。

**TOC 27 年预算已按此落地**：HC 不变、兼职人工成本减半、差旅大幅增加、办公费含 AI 0.2w ＋ 服务器 0.15w（美金/月）。

**背景现实**：同日 token 已成个人与部门级阻塞——Leon 的 Codex 额度用完、Lili 反映 ICODE/CODEX 余额不足、WorkBuddy 采购卡在人数与范围。额度不是福利，是产能。

## 边界

口径为群内建议，**未见制度文件或审批链**；"骨干用量＝明年平均用量"是估算假设，未验证。与 09-15 确立的"团队 AI 用量看 token 总量与对话总轮次"口径（该认识存于 GBrain 库，TOC wiki 未收）同向互撑。
