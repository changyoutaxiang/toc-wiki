# 上线决策矩阵与原子小队工作方式修复

> 时点：截至 2026-08-25。本页从 2026-08-25 Weekly Meeting（外教战役坏课治理线跨区域周会，专题诊断「原子小队上线 feature 引发的教师/运营冲击」）提取。源为会议纪要，无已审标记，`review: 记录`。

## 背景

某原子小队 feature（缺席/坏课治理相关）确实显著降低了缺席，但因未提前同步导致菲律宾运营侧与 2 万老师受影响、投诉上升、社交媒体嘈杂。王东在本会给出系统性诊断与修复方向（诊断性质，非单个功能问题）。

## 决策内容

1. **根因诊断：三大工作方式 gap（信息/规则/标准），不是某个功能的问题**：
   - 信息 gap：原子小队 DRI 不汇报、无同步系统；
   - 规则 gap：上线决策矩阵缺失；
   - 标准 gap：缺席/no show 的完整管理标准缺失，出现「迟到 30 秒被冷血处理」的 CEO 反馈。
2. **任务制方向确认**：公司从层级/岗位制走向任务制（customer value oriented organization），原子小队是「everywhere 的工作方式」，本轮为 pilot；王东明确「不会有岗位，只会有原子小队」；北京先行，菲律宾等区域跟进讨论中。生产力（AI 写码、SIV 等）飞得太快、工作方式落后是 gap 的总根因（"productivity is flying, way of working is behind"）。
3. **修复方案一（信息）：build in public**——钉钉知识库/群文档（英文+中文）+ AI/bot 读取并汇报 + 每个原子小队设 notice board（下周三上线什么、影响、范围）+ AI 生成周报（不再人工写 PPT/周报）；「没人需要汇报，但所有人通过 AI 知道一切」；本周从两个 pilot 原子小队开始做。
4. **修复方案二（规则）：上线决策矩阵（影响范围 × 后果可逆性四象限）**：
   - ①小范围 + 后果小/可逆（如群发通知）→ DRI 全权决策直接 go；
   - ②小范围 + 不可逆后果 → 提前告知、运营侧可叫停；
   - ③全范围 + 后果可逆 → 必须走灰度（灰→深灰），**proof（数据/事实/AB test）是决策者**，DRI 必须提供证明、不能说「我有信心」就全量；
   - ④全范围 + 严重后果（钱、合同等）→ 必须先经 Jane 与王东确认。
   - 王东强调该框架「今早刚生出来、会随实践生长」，目标是成为共同语言（common language）；点名「曾经 overnight 全量上线 1-2 次是坏 discipline/bad SOP」。
5. **修复方案三（标准）：零容忍缺席 ≠ 一刀切规则**——缺席治理需要完整规则集（什么是缺席、无通知的标准、态度与英文口径、老师体验/能力/实施成本/反噬都要考虑）；「make rules 容易，governance 需要智慧」。
6. **原子小队双产出标准（确立）**：customer value outcome + asset outcome（工作方式/系统沉淀）——资产产出让下一个小队不用重踩同样的坑；小队解散前必须交付。
7. **Jennifer 补充共识**：原子小队类似 IT scrum，须先声明「在解决什么问题」；2 万老师与教师支持团队都不在 loop 内是本轮最大的缺失；原子小队不能 rogue，建议增加「在地/用户侧成员」（teacher support volunteer）承接信息传递；影响老师金钱的决策是大决策。

## 依据

- 上线事故复盘（feature 上线引发投诉）；王东诊断三 gap；Jennifer 反馈（2 万老师与教师支持团队不在 loop 内）；AI 主动提醒王东「零容忍缺席不应一刀切」被采纳为治理原则。
- 王韬的 domestic AB test 作为「proof 说了算」的正向案例。

## 影响范围

- 全部原子小队（含菲律宾）的上线纪律与信息透明；坏课治理小队首当其冲——2026-08-26 Bad-Class 会另以“小范围有影响、限定范围并观察”讨论授权，不能直接按本页第三象限编号套用（[2026-08-26-坏课治理双方案灰度拍板](2026-08-26-%E5%9D%8F%E8%AF%BE%E6%B2%BB%E7%90%86%E5%8F%8C%E6%96%B9%E6%A1%88%E7%81%B0%E5%BA%A6%E6%8B%8D%E6%9D%BF.md)）。
- 与 08-24 任务制定调衔接（[2026-08-24-AI-Native转型定调与任务制](2026-08-24-AI-Native%E8%BD%AC%E5%9E%8B%E5%AE%9A%E8%B0%83%E4%B8%8E%E4%BB%BB%E5%8A%A1%E5%88%B6.md)）；与 08-04「SIV 没有灰度就铺开」learning 同向（[2026-08-04-SIV恢复专项与算法owner补位](2026-08-04-SIV%E6%81%A2%E5%A4%8D%E4%B8%93%E9%A1%B9%E4%B8%8E%E7%AE%97%E6%B3%95owner%E8%A1%A5%E4%BD%8D.md)）。
- 汇报机制改造：AI 生成周报、notice board 本周起在两个 pilot 小队试行。

## 演化记录

- 2026-08-25：三 gap 诊断 + 决策矩阵首版 + 任务制确认 + 双产出标准（本页）。
- 2026-08-26：坏课治理会采用有界授权（两场会议的象限编号不同）（[2026-08-26-坏课治理双方案灰度拍板](2026-08-26-%E5%9D%8F%E8%AF%BE%E6%B2%BB%E7%90%86%E5%8F%8C%E6%96%B9%E6%A1%88%E7%81%B0%E5%BA%A6%E6%8B%8D%E6%9D%BF.md)）。
- 框架随实践迭代后定稿（未完成）。

### 8月29日后继限定：广播可见不能替代定义期参与

分享指出PH在首周承担后果却未参与规则定义；参与权三条路径尚无共识，下一步交区域方修订草案。唯一DRI不能覆盖受影响方参与，提前通知也不能自动算作共同定义。此处追加后继范围限定，保留8月25日各项决定自己的历史来源，不凭一份分享撤销全部旧条款，也不把局部试用升级为公司组织重构已经获准。（[分享原稿](../../sources/raw/2026-08-29_%E5%8E%9F%E5%AD%90%E5%B0%8F%E9%98%9F%E5%B7%A5%E4%BD%9C%E6%96%B9%E5%BC%8F_%E9%AB%98%E7%AE%A1%E5%88%86%E4%BA%AB%E5%86%B7%E8%AF%BB%E7%89%88.md) L838–872、891–944。）

## 待确认（如实列）

1. 决策矩阵为初版框架，需实践迭代后定稿；notice board/AI 周报机制在 pilot 小队落地验证。
2. 「缺席/坏课标准集」完整规则建设（定义、口径、例外、反噬评估）的明确 owner 未定。
3. 在地/用户侧成员（teacher support volunteer）角色：谁、什么职责、如何反馈未定。
4. 菲律宾侧信息流动通道（英文材料/翻译）待补。

## 2026-09-15 共同语言与真实知情

8月25日矩阵的③是全范围可逆，8月26日却称“小范围有影响”为第三象限，编号不能强并；应回到实际范围、后果与具体授权。文档、公告栏、双语材料、AI周报和在地成员是改善沟通的办法，有这些载体不代表老师已理解或结果已回传。任务制也不自动消除涉及钱、合同等严重后果的原有责任。（[8月25日纪要](../../sources/raw/2026-08-25_WeeklyMeeting%E7%BA%AA%E8%A6%81.md) L16–41；[8月26日纪要](../../sources/raw/2026-08-26_Bad-Class-Issue-Updates%E7%BA%AA%E8%A6%81.md) L19、L38–49。）
