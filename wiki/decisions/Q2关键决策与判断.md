## 背景：Q2 判断重心迁移

Q2 的关键变化不是单个项目的启动，而是战役判断的重心迁移：从「只救招聘量」转向「**在供给安全线之上，优先做更确定的质量抓手、价值传输链路和组织修复**」。

## 已确认或接近确认的判断（截至 2026-05-14）

### 资源与目标

- 资源更应投向新老师入门期课时费与收入保障，而不是优先投向易被 manipulate 的结果激励。
- 沟通矩阵建设优先级高于继续零散修漏斗。
- Referral 需要先明确 owner，否则难成为 Q2 真正增长引擎。
- 招聘创新动作优先放市场测试渠道做双轨验证。
- Website 渠道 owner 缺失是待决策组织问题。
- 预算倾向先锁定 1M，再看平均招聘成本是否降到 2000 以下（注：2000 比索口径，04-25 起被 1500 比索取代）。
- 国内与海外招聘目标基础逻辑已分别拿到输入，需收敛成同一张管理口径（需求测算、供给折损与最终拍标分层讲清），由 Leon/王东继续跟 Lily 对齐口径。
- Q2 正式战役目标倾向先收敛为三个标，`MyStudent` 暂不纳入本季度正式战役考核。
- 质量定义更倾向先用 `demo / B+` 这类硬指标做锚，不沿用旧的复杂指标组合。
- 直通车在会议中被明确「今天决定做」，进入细节研究阶段。
- Center 与 B+ 目标和供给扩张的关系要单开专题，不在长会里硬定完。

### 渠道与投放

- Facebook 等垃圾流量的退出与市场流量投资转向，应视为被进一步验证而非仅凭内部试错得出的判断。
- Referral 的战略上限应上修，但执行判断必须同时纳入「薪酬土壤差异」和「我方更大老师基数」两个前提。
- Marketing-CN 本周进入渠道收缩期，只保留高 ROI 渠道，停止洪水。
- 洪水止住后，漏斗管理切到 leads 减量场景下的「跟踪及时 + 当日节点无残留」高纪律模式。
- Q2 核心框架是「追求确定性」：冻结不确定新渠道（KOL 等），资源集中在成熟渠道（Referral 为最大引擎）。
- KOL 测试暂停，除非有额外预算；第一个已签约 KOL 待观察效果。
- 4月27日计划按1500 CPL目标安排预算：原始约3.9M→可用3.3M、缺口约600K，要求少花钱保持产出；这不证明实际已达标。计划表渠道总量、Referral预算与CPL存在具体冲突，见[1500目标的算表核对](2026-04-25-cost-per-launch下调至1500并转向Referral.md) （[A](https://alidocs.dingtalk.com/i/nodes/1DKw2zgV2Proed71svNkBzbD8B5r9YAn) · [Leon](https://alidocs.dingtalk.com/i/nodes/0eMKjyp813zoLe7nSrnZeY3nVxAZB1Gv)）。
- 五月 launch 目标 2,200（国内 1,000 + 海外 1,200），Referral 680 为最大单一渠道。
- Pipeline 策略：不做大变化，靠 leads 减量（100K→66K）+ 小步迭代 + Fast Track 自然改善。
- Q3 launch 目标 3,000，需现在开始储备 leads。
- CE 自动化先海外测试，国内暂缓，不引入不确定性。
- KOL 相关判断（04-20 ~ 04-25）：Q2 市场投放资源倾向从买 leads 明显转向 KOL，内部出现「80% 向 KOL 转」的强表达；菲律宾 KOL 路线不只是买量替代，而是「品牌背书 + 高质量 leads + 本地/总部协同」三合一渠道；菲律宾品牌/KOL 的中方一号位需被明确编排，杨福群（Felix）被拉入并倾向承担对接角色；KOL 与 KOC/Referral 必须明确拆开；当前不应再把 KOL 默认当成 lead-quality 解法，更适合作为 awareness / lead generation 实验渠道验证；在菲律宾推进 KOL 前，应并行推进负面雇主品牌搜索结果与平台口碑治理，避免放大 PR 风险。（注：04-25 cost-per-launch 下调后，MKT/KOL 进入更坚决收缩范围——见下。）

### Referral

- Referral 在 Q2 的打法正式拆成 foundation / focus / accelerator 三层：基础设施、targeted campaign、fast track / mentor 型 referral / stronger incentive 等加速器。
- teacher app 节奏偏慢，Q2 不能把 Referral 爆发押在 app fully ready 上，4 月底前的 PC 分享能力应先落地。
- 面向 top referrer / high-trust candidate 的 fast track，被抬升为 Referral 上限的重要候选杠杆。
- 5 月 Referral 政策加码的 trade-off：部分老师可能因追求 B+ 而延缓 demo；招聘量无压力时可接受，承压时则构成风险。
- 为提升确定性，针对 A 档的超额激励应取消：实际覆盖比例仅约 1~2%，distract 影响未知，保留收益不如去掉更确定。
- 围绕 15% → 25% → 33% 质量目标，不应假设已有足够 solid 的历史成功抓手；更合理打法是尽可能多打测试子弹，再按反馈收敛出真正有效的主杠杆。
- 该质量测试打法会与菲律宾团队「保证招聘量优先」的惯性大面积冲突，需 Leon 坚决主张并高频沟通，不能指望自然切换。

### cost-per-launch 1500 比索（2026-04-25 公司指令）

- 公司把外教招聘 cost per launch 财务目标从 2000 比索进一步下调到 1500 比索，渠道配置需以更严的 launch 成本门槛为约束。
- 此约束下 MKT 投放与 KOL 不再默认保留优先资源，二者都进入更坚决的收缩范围。
- Referral 从「高潜机会」升级为承接 cost per launch 压力的主方向之一，资源更明显向其集中。
- Q2 渠道判断优先级切换为：先看能否穿透 1500 比索 launch 成本，再讨论质量获客、品牌背书或 awareness 外延。

### 质量与标准（CE / 好老师定义）

- 15% B+/A 目标 4 月仅达 6%，差距巨大；5 月新 scheme（PGTM）是唯一希望。
- 15% 质量目标压成四个抓手：5 月 new scheme 饱和宣发、B+/A 标准国内海外拉通与内部宣发、直通车 kick off、Center/Referral 新流程试验。
- CE redemo 应由 Leon 自己直接负责，不再漂在多方协调链里。
- 菲律宾端 NTT→CE 以及与产品自动化的衔接，由 Leon 穿透现有指挥链按项目直接硬推。
- CE demo 标准下一步不只在专业团队内部收敛，要面向高管完成 internal sell，讲清「金主可调权重、不可改科目」边界。
- 下一版 CE 标准值得认真考虑标签化老师池、区域/人群分流、把硬件/网络纳入更完整的「好老师」定义。
- CE demo 标准还应显式考虑好老师候选人体验，避免只追内部标准闭环而牺牲优质候选人转化。
- CE评分提出从“一张卷子”改为“三张卷子”的方向：CE 分（不变）+ 设备分（硬件检测，两次取最新）+ 观感分（外在形象/环境评价），稿中仍写周三CEO会拍板，观感细则待专业输入；不能用设备已有两次检测推定整套标准获批。
- 设备分已确定：技术侧已有系统，两次检测（tech check + CE demo 入口），以最新为准。
- 观感分评分细则委托 Sophia 专业 input，Leon 不拍脑袋。
- 在教老师评价框架已搭（四维度：供给/行为/用户反馈/业务结果），但投诉集成和评价覆盖率是硬缺口。（2026-08-31 外援库补充：04-27 Good-Teacher 在岗标准讨论的四维权重为 **学生满意度 50% / 教学表现·行为 30% / QA 10% / Capacity 10%**——来源外援库自动蒸馏 `LeonWikiClean:synthesis/教师质量生命周期系统`，未经审定，与本页「供给/行为/用户反馈/业务结果」的维度对应关系待确认。）
- 「好老师」可能不是一维分数而是分维度画像，不同教师有不同优势类型。
- PGTM 必须与在教评分对齐——这是标准设计的下一个关键连接点。

### 好老师生命周期

- 「好老师」需在教期定义（ended lesson / attendance / complaints），不能只停在 onboarding 阶段。
- 「好老师」不应只按招聘上岗阶段定义；5 月起逐步补齐试用期（前 2~3 个月）与巡航期的好老师定义，把战役从前段吸引力延伸到中后段的良币压制与劣币淘汰。
- PGTM 当前更偏向生命周期前段，核心是提升招聘端对好老师的吸引力/竞争力；后两段需要新的质量与经营口径承接。

### Center / Cocos / 菲律宾

- Center 模式从「座位扩张」重新定位为「质量引擎」——先用 quality 证明价值，换来公司投资，再扩张。
- Center 扩张成本暴涨 40%（PC 翻倍 / 发电机翻倍 / CO 回收期从 6-8 月升至 18 月），CO 不愿扩张。
- Polly 高概率 6-12 个月内建菲律宾本地团队，将物理接触并抢夺 CO。
- Cocos 是教学质量 game changer，但仅 66 名 HBT 教师达标，约一半教师硬件不达标——被忽视的定时炸弹。
- CO 赢利模型需重构：从 win-lose（教师毕业 CO 亏钱）到 win-win（毕业激励 + 5% 持续分成）。
- 新 Launch Package 方向性对齐：教师 guaranteed earning + CO guaranteed pay per seat（按 quality 分级）+ 毕业分成。
- Center 是「流水线」而非「旗舰店」——没人能偷走一所大学。
- 组织能力是真正护城河，Polly 从零建团队不易。
- Cocos/AC 技术路径已从「单纯抬高招聘硬件门槛」转为「教材轻量化 + 动态适配 + 高耗能功能降级 + 招聘侧设备分前置」的组合方案；i5 8代可作为当前保证基线，I3 是否继续适配需先统计中心占比后再定。
- Teacher APP 可考虑外包或 AI 工程师临时承接，但因涉及教师敏感数据与 API 权限，必须经过权限隔离、代码 review、上线审计和长期维护 owner 设计，不能直接绕流程上线。

## 仍待明确的问题（截至 2026-05-14）

- Referral 的最终 owner 和执行链条。
- Website 由谁负责。
- 宽带薪酬与收入保障计划的最终力度。
- 直通车与体验课池子的优先级和平衡规则。
- Q2 经营结果桥梁指标最终是否只保留升舱/续费相关口径，仍需继续收敛。
- 候选人视角的招聘流程体验问题是否已成为真实的系统性流失点，需快速确认。
- KOL 在我方场景中的真实上限仍需与友商样本区分，暂不据此翻案。
- KOL 资源转向的最终比例、预算节奏和 PH 本地/总部分工还需快速收敛。
- 公司对 KOL 项目的目标究竟以 awareness、lead generation 还是 quality improvement 为主，仍需显式澄清。
- 雇主品牌口碑是否是入职率偏低的关键解释线，仍需验证。
- 国内/海外统一规则最终要用「单公式」还是「同一治理框架下的两套测算路径」，仍需最后拍板。
- Referral 承接更多资源后的 owner、机制 readiness 与体验瓶颈，是否足以支撑这轮资源迁移，仍需快速验证。

### 2026-05-11 CEO 反攻指示后的新待决策项

- 好老师「国内优先分配」的具体机制：哪些老师优先、什么标准、国内/海外比例如何定。
- 好老师供给增速是否足以支撑 4-5 个月反攻窗口，如果不够需要哪些加速动作。
- I3 设备/中心占比与 Cocos 最低配置策略：I3 占比极高则推动硬件升级而非无限降配；占比有限则招聘准入继续对齐 i5 8代基线并动态降级功能。
- Level 课程结构衔接：每个 level 约 96 节课中只有 20 节 Cocos 新内容，剩余课节如何用 Free Talk / CG5 / CZ 5.0 对标内容承接，需尽快拍板以免卡开发。
- Teacher APP 的开发资源路径：外包/AI 工程师/内部团队谁负责，安全审批、接口权限和后续维护 owner 如何设置。
- 海外市场在好老师分配倾斜后如何防止体验下滑。
- 「最好的外教在 51Talk」品牌外宣由谁牵头、与外教战役产出的衔接节奏。
- 直通车 Trial Only 是否应从 p1 提到 p0，以及与「大船换帆」的优先级关系。
- 分佣渠道的深度洞察和快速动作由谁负责。
