# TOC AI-Native 转型定调与岗位制转任务制

> 时点：截至 2026-08-24。本页从 2026-08-24 TOC 周会（听记原稿）提取。源为会议纪要，无已审标记，`review: 记录`。

## 背景

本会接续 08-17 TOC 周会「能力建设/解决问题/客户价值」三分类工作图与 08-21「新一代经营系统 + XYZ 统一语言」，把 AI Native 转型从框架讨论推进到三大发力点、XYZ 模型落地与全员 Agent 硬性指标。「老师为准客户」在 08-17 已有雏形，本场正式确立。

## 决策内容

1. **AI Native 转型三大发力点（定调）**：个人技能提升（基础前提）、组织与工作方式升级（核心差异）、场景 AI 化（业务落地）。本场目标表述为「率先成为公司第一批 AI Native 转型的部门」。
2. **岗位制 → 任务制定调（方向定调，未形成组织架构调整决定）**：不再以固定岗位绑定人员，而是围绕客户价值任务组建临时原子小队；成员需具备通才能力与 AI 辅助下快速学习能力（如 3 小时上手新领域）；参考样本为中东成人团队与订阅制项目已初步实现的按客户价值端到端负责。会议承认任务制依赖 AI 杠杆——AI 能力不足者在新组织形态中可能被边缘化，该判断指向培训与适应支持，但本场未指定对应培训资源或覆盖名单。
3. **XYZ 模型引入为统一战略语言（定调）**：X=业务战场，Y=能力段位（Y1 英雄解 → Y3 蜂巢解），Z=客户价值（Z1 接得住 → Z3 守得住）。判断团队当前多在 Y1–Y2、客户问题解决能力「顶多到 Z2」，目标是通过提高 Y 轴把 Z 轴推向 Z3；复盘与规划需显性化讨论 Y/Z 两轴，引导精力投向高 Y 高 Z 方向，摆脱「英雄主义」依赖。Y/Z 分档口径（Y1–Y3、Z1–Z3）尚未形成书面定义与评审节奏（模型本体见 [X-Y-Z三轴经营模型](../concepts/X-Y-Z%E4%B8%89%E8%BD%B4%E7%BB%8F%E8%90%A5%E6%A8%A1%E5%9E%8B.md) （[A](https://alidocs.dingtalk.com/i/nodes/0eMKjyp813zoLe7nSrk2nyeGVxAZB1Gv) · [Leon](https://alidocs.dingtalk.com/i/nodes/pGBa2Lm8aGOqaKwrSzLR0o9BVgN7R35y)））。
4. **全员个人 Agent 硬性指标**：**全员 9 月底前在 WorkBuddy 平台完成个人 Agent 搭建与上线并关联个人知识库**（钉钉待办 + 摘要确认）；Agent 需能处理基础咨询与信息查询以减少低效沟通；同时鼓励全员上传分享 Skill，形成部门级技能资产库。
5. **「燃料—肌肉—资产」个人技能框架**：燃料=舍得用高质量模型（如 So/极高）与足量 Token，会议提出连续四周用满 $100 可申请提升至 $200（口述提议，平台侧可执行性待验证），并预判未来 Token 不限量将如水电气般标配；肌肉=使用 AI 工具的专业手艺，核心是编写高质量 agent.md（角色/职能/义务）与 Prompt 技巧，被视为未来核心差异点；资产=个人记忆、知识库与 Skill 的沉淀。三者被描述为层层递进而非并列取舍。

## 依据

- 会议结论 + 钉钉待办（全员 Agent 硬指标为「摘要确认」）。
- 08-17 TOC 周会三分类工作图；08-21 菲律宾出差 agenda「新一代经营系统 + XYZ 统一语言」。
- 「任务制依赖 AI 杠杆」判断：只有具备强大 AI 技能（尤其肌肉与资产）才能胜任跨领域任务。

## 待确认（如实列）

1. 任务制的组织架构调整决定（本场仅方向定调）。
2. $100→$200 Token 提升机制的平台可执行性（口述提议）。
3. Skill 上传的准入标准、复用证据、Agent 知识库质量与查询口径均未冻结；「Y3 蜂巢解」尚无落地样例。
4. 智能体查数的数据权限粒度、Agent 回答错误的复核路径、异常接管与最终责任人未在本场定义。
