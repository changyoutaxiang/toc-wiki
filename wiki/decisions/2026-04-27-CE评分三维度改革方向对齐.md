# CE 评分三维度改革方向对齐 · 众议院 propose 参议院拍

> 编译自 2026-04-27 CE 评分三维度改革对齐会（Leon 与黄荣 ~10 分钟短会）。方向已对齐但「加值制合并公式」待高层拍板（4/30 CEO 会推动），故 review=记录、status=已调整（后续被 06-29 新基本法放弃 B+/A 核心 KPI 的更大换尺覆盖）。

## 背景

CE 现行评分「一张卷子」偏幼少儿课堂（TPR、teaching aids 权重高），对高年级/成人老师不公平；且 B+/A 评级标准与设备/呈现脱钩，无法确知新招老师有多少能上 Cocos 课。Leon 与黄荣对齐：从「一张卷子」改为「三张卷子」。

## 决策内容（方向已对齐）

1. **CE 评分拆为三维度**：**CE 分**（现有教学 demo 评分体系，完全不变）+ **设备分**（硬件检测打分：CPU/内存/硬盘/网络，技术侧已有系统，两次检测取最新）+ **观感分**（CE demo 时对老师外在形象/环境的主观评价，评分细则待定，Leon 委托 Sophia 出专业 input——三档或百分制）。
2. **合并方式 = 加值制（Leon 初步主张，待高层拍板）**：CE 基础分 + 设备加分 + 观感加分 = 总分，影响最终定级（A/B+/B）；Leon 举例：CE 百分制 → 设备给 0–30 分加值、观感给 0–30 分加值。具体权重/合并公式今天不定，先把两套新卷子 propose 出来。
3. **设备检测规则**：检测两次（tech check 初始 + CE demo 入口二次），以最新结果为准；CE demo 入口设备不达标的具体处理（fail/先做再判）委托 Sophia 团队定。
4. **治理框架（Leon 明确）**：「众议院 propose，参议院拍」——专家做提案、有权力的人来拍；改动标准需高层同意，不是 Leon 和黄荣可直接定的；4/30 CEO 会上推动方向性拍板。
