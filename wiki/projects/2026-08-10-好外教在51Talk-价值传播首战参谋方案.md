# 好外教在 51Talk｜价值传播首战参谋方案（草案）
> **2026-09-11 粗筛改判：可留待审**（BCD 提案 · Leon 批改判回 A）。


> **首行状态标注**：源文件 `status: draft`（2026-08-10，provenance：H2 总纲 + TOC 系统地图草稿 + Polly 主持人逐字稿（未校对 ASR）+ CEO Jack Agent 反馈）。页级 review 已于 2026-09-15 批量认可转已审（蒸馏忠实性）；内容仍为草案，**不得当作已生效的传播方案或对外承诺**；首战主张是「待事实验证的首战主张」，不是现成对外文案。

## 一句话结论

这不是一场「把好老师讲得更响」的品牌战，而是一场**帮家长在关键时刻放心选对老师，并让这份放心在前五节课里被兑现**的决策战。首战不要从「大叙事」或大直播开始，先只打一处：

> **一个市场里，已完成测评、正要首次选老师或进入前五节课的新家长。** 给他们一个可兑现的承诺：订课前看懂这位老师为什么适合孩子、什么时候能上；订课后优先保障连续体验；发现不合适，有明确的支持与调整办法。

只有真实可约、稳定交付和问题处理都具备时，才可以对该人群说这句话。

## 一、把原骨架调成一套真正能打仗的顺序

原骨架「责任域 → 责任人 → 完整叙事 → 宣传机器」少了两个承重结构：**可核验的事实**与**客户得到的结果**。首战顺序：

```text
能核验的老师事实 → 对特定家长的一句价值主张 → 销售与家长真正作决定的时刻 → 家长是否选择、老师是否如约交付 → 把不一致找出来，改事实、改说法或暂停承诺
```

这条顺序与 H2 总指示一致（好老师必须在体验课和前五节课被客户看见、选择、信任并持续使用；30 天真实授课和客户反馈才是最后的尺子）。

### 三条硬判断

1. **「好外教」不是一个形容词，而是一份对具体家长的可兑现说明**——不能泛称「我们的老师都很棒」；只能说明「对这一类孩子，在这个时段，这位老师有哪些已核验的能力、可用时段与连续学习条件」。
2. **先把老师变成「可选择的产品」，再把故事变成内容**——照片、短视频、课堂片段、资质、家长反馈、可约时段、适合的孩子、连续方案与问题处理方式，缺一项都可能让客户只能「听声音盲选」。
3. **宣传必须有刹车**——老师不可约、首次体验与承诺不同、连续上课受阻、问题得不到支持时，停止扩大该主张；这不是宣传失败，而是保护家长信任。

## 二、从 Polly 应该学什么、不该学什么

逐字稿是机器转写，姓名、数字和具体教学主张未经校对——只能作为**对手表达方式的观察样本**，不能把其中任何事实当作要反驳或照抄的依据。

**值得学的是「帮助做决定」的结构**：测评提问定位孩子 → 25 分钟课放进「学习方案」→ 公开讲选择中的取舍（固定班 vs 灵活约课）→ 不回避「老师不合适怎么办」→ 每段解释落在一个明确下一步（测评/看报告/预约）。其竞争力不在于直播说得多，而在于让家长觉得：**有人听懂我的孩子，并能告诉我下一步怎么选。**

**不该照搬的四件事**：不照搬未经验证的教学结论/年龄分段/效果承诺/对同业评价；不把「名师/外教/口音」当万能答案；不先拉流量再补供给；不用强主播替代真实的选师信息和履约能力。**反攻不应是「找一个更能说的主播」**，而是：在家长真正要选老师时，让 51Talk 给出更清楚、更诚实、更能兑现的答案。

## 三、首战怎么选：一群人、一个时刻、一句主张

| 要素 | 首战选择 | 为什么这样选 |
|---|---|---|
| 人群 | 已完成测评、即将首次订课的新家长 | 需求刚形成，仍会认真比较，尚未被随意分配固化体验 |
| 时刻 | 测评结果出来后，到首节/前五节课的选师与连续约课时刻 | 正是「看见—选择—跟随」最容易形成或失去的地方 |
| 供给范围 | 仅一个具备真实可约产能和支持能力的市场、一个小队 | 先保证说到做到，避免全量承诺把局部问题放大 |
| 一句主张 | 「不只是给孩子安排一位老师；我们会说明为什么这位老师适合、何时能稳定上课，以及不合适时怎么调整。」 | 家长听得懂，销售说得出，也能被真实结果检验 |

主张刻意不用「最好/全部/保证/顶级」等词。首战不做什么：不先做全品牌大宣发；不在事实不清时让销售背统一口号；不以播放量/素材数/直播场次为赢的证据；不把国内/海外/所有年龄段/所有课程一次卷进来。

## 四、责任怎么摆

「外教价值传播」应作为 O3 市场教师价值实现的一项战役责任：市场对客户选择与实际使用负责；TOC/质量侧对老师事实与适用边界负责；产品、匹配和 CRM 对决策时刻是否真的能承接负责。首战需要一个临时的**价值传播主理人**，只对这次试点完整运行负责，但不能把他变成所有事实的替身。

| 角色 | 必须交付什么 | 有权叫停什么 |
|---|---|---|
| 价值传播主理人（首战总负责人） | 选定人群、主张、材料、销售使用与每日问题清单；召集复盘 | 事实卡不完整、承诺无法兑现时暂停该主张 |
| 市场业务负责人 | 试点客群、销售/服务承接、客户选择和连续上课结果 | 触点不真实、销售不愿用、客户看不懂时要求重做 |
| 老师事实负责人（TOC/质量侧） | 老师资格、近期履约、适用边界、可用时段的核验 | 任何超出真实能力或供应边界的说法 |
| 匹配/产品/CRM 负责人 | 正确时刻展示正确信息；记录家长看了什么、选了什么、后来发生什么 | 信息与实际预约、可用时段不一致 |
| 服务与问题支持负责人 | 「不适合/约不到/上得不顺」时的可执行处理办法及处理时效 | 没接住客户问题却仍扩大曝光 |

启动会只需冻结五个空格：**市场、试点小队、价值传播主理人、事实负责人、问题支持负责人**。当前材料不能证明具体人选已确定，本方案不替任何人点名。

## 五、把「宣传」做成四张简单卡

1. **老师事实卡**（什么是真的）：适合谁 / 课堂证据（经允许的片段、近期表现、已核验资质）/ 真实可约（当前可约时段、容量、有效日期）/ 连续体验（前五节课安排、老师不可用替代方案）/ 不适合什么 / 问题处理（谁接、多久回应）。每项能找到来源与核验人；不能用「很受欢迎」、单张高分标签、过期排班、「后续再协调」、假装人人匹配、模糊的「联系客服」替代。
2. **家长主张卡**（这一位老师为什么适合我的孩子）：只回答四问——孩子现在最需要什么？为什么推荐这位老师（只用事实卡证据）？这周和前五节课怎么上、能否连续？不喜欢/不适合下一步怎么处理？空格必须填入真实内容，填不上就不展示。
3. **前线使用卡**（30 秒能说清的四句）：先确认孩子情况和最在意的事；「我推荐这位老师，是因为 ___」；「您现在能约到 ___；前五节课的连续安排是 ___」；「如果实际体验和预期不同，您可以 ___，我们会 ___」。只有销售愿意自然使用、客户能复述「为什么是这位老师」，才算进入真实决策时刻。
4. **结果卡**（承诺有没有被兑现）：每个试点家庭记录——看到了哪张主张卡、是否选择、是否实际约到、首节和前五节是否连续、是否收藏/复约/固定、问题是什么、如何处理。用途不是追责话术人员，而是找出哪句说多了、哪个时段供给不足、哪类孩子根本不该被这样推荐。

## 六、首战的 14 天作战节奏

| 时间 | 要做的事 | 产出/过关标准 |
|---|---|---|
| 第 0 天 | 冻结一个市场、一个小队、一个人群、一个时刻、一个主张；明确五个角色 | 一页战场卡；未定人或事实不清，不开战 |
| 第 1–2 天 | 从真实可约老师中挑首批候选；逐位完成老师事实卡；核对课程、时段、支持能力 | 每项都有来源、有效期和核验人；缺项老师不进首战 |
| 第 3 天 | 做三件最小材料：家长主张卡、30 秒前线使用卡、问题处理说明 | 不做大海报、不拍大广告；先能让家长做决定 |
| 第 4 天 | 用 5 个非正式案例演练：销售、预约、首节、老师不可用、家长不喜欢 | 演练中任何承诺接不住，就改材料或缩小范围 |
| 第 5–12 天 | 在一个小客群中真实使用；同一老师池、同一时段尽量保留现有流程作比较 | 每个家庭有结果卡；同时记录「不选」「约不到」「不满意」 |
| 第 13–14 天 | 看结果，三选一：保留并扩大 / 改说法后再测 / 暂停 | 复盘只回答：客户是否看懂、是否选得更坚定、实际是否更连续 |

**比较必须公平**：至少记录并尽量控制老师池、时段、客户来源、测评结果、价格/优惠、销售人员与可约容量。条件允许时在同一批合格老师与相近时段中做 A/B（一部分用「说明为什么适合+连续方案」，另一部分走现有方式）；否则只当探索，不能得出「宣传已显著提升转化」的结论。

**首战看什么数字**（启动前先从当前业务正本拉基线，不编造目标数）：前线是否使用 / 家长是否理解 / 是否真正选到 / 是否连续体验 / 客户是否认可 / 信任有没有受损（承诺不一致、投诉、屏蔽、退款、沉默流失是否上升）。**30 天后的真实上课与客户反馈，才决定是否把主张推广**——前两周最多证明「这个动作有人愿意用、信息能到达、承诺有机会被兑现」。

## 七、三条防错线

- **防错线一：没有事实卡，不许讲故事**——所有对外表达都要能追溯到老师事实卡；素材好看但时段已满、片段不代表当前能力、评价没有时间范围，都不能上线。
- **防错线二：遇到不一致，先改承诺，再谈放大**——展示后频繁约不到 / 首节体验和展示明显不一致 / 连续安排无法兑现 / 家长听懂却不选择或快速后悔 / 同类问题没人接住，任一出现即暂停对应老师、时段或主张；暂停不是掩盖，要区分事实变了/供给不足/推荐不合适/表达误解/服务没接住再分别修正。
- **防错线三：先赢一次，再谈「机器」**——只有首战在一个小队完整跑过，并且第二位非原作者在第二个场景（如「家长想换老师」）也能照四张卡跑通，才沉淀为可复制的做法。可复制的不是文案，而是：核验事实、写清适用对象、进入真实决策时刻、记录实际结果、按结果改说法。

## 八、对「好外教在 51Talk」完整叙事的建议

大叙事仍然需要，但它应当从首战中长出来，而不是先于首战规定事实。可逐步形成：**好外教，不是一个遥远的标签——在 51Talk，它首先是一位你能看见、能理解为什么适合孩子、能约到并能持续学习的老师；背后是一套对老师真实表现负责、对家长疑问有回应、发现不适合就愿意调整的做法。** 这段话只有在三件事都真实成立时才能公开放大：①家长在关键时刻确实看见了有用信息；②前五节课多数情况下确实拿到了相称的体验；③少数不一致的情况确实有人接住，并且系统据此改变了推荐、供给或表达。

## 九、启动会当场要回答的五个问题

1. 首战到底选哪个市场、哪类新家长、哪一个选师时刻？
2. 现在哪一批老师同时满足「可核验、真实可约、可连续支持」？
3. 谁担任价值传播主理人；谁为老师事实、客户结果和问题支持签字？
4. 当前流程里，家长和销售在哪一个页面、话术或动作上真正做出选择？
5. 启动前的基线是什么；出现哪些负面信号就停，而不是继续加预算和曝光？

这五个问题不答清，先不要拍片、直播或全员动员。

## 参谋判断

真正的战役入口应当倒过来从一个家长的选择开始：**这个孩子现在需要什么？这位老师为什么适合？我今天能不能约到？上了以后不对怎么办？** 能连续回答好这四句，才有资格讲「好外教在 51Talk」。若答案只有「我们有很多好老师、很多素材、很多直播」，那不是宣传战，只是在放大信息不对称；短期可能热闹，长期会积累信任负债。
