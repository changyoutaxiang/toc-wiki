# 成熟老师升降级积分方案（五维积分 · L1-L14）

> 编译自《成熟老师升降级积分方案·最终确认版（中英双语）》（2026-09-03，Leon 下发的权威文件；依据 V4.1/V1.6/V2.0/V3.12，2026-08-27 回测复算一致）。
> **时点语义（照源声明）**：机制方向已确认，**数值待冻结**（8 项 Pending），**未上线生产，不作为线上规则引用依据**。页级 review 已于 2026-09-15 批量认可转已审（蒸馏忠实性），数值冻结与上线边界照旧。

## 定位：一个主分数 + 两条辅线

外教全生命周期进入成熟阶段后，只围绕**一个主分数（周期总积分）**成长：

| 模块 | 回答的问题 | 是否改变等级 |
|---|---|---|
| **主体 · 五维积分升降级** | 老师长期成长到哪里 | 是（周期总积分唯一主分数，判定升/保/降） |
| **引导 · 推荐状态** | 近期怎样做得更好 | 否（近 30 天信号 → 优先/正常/降权/待积累 + 行动建议） |
| **保护 · A0-A4 治理** | 当前能否继续接课 | 不直接改（严重履约事件即时降权/暂停/冻结） |

**三条铁律**（源：方案 §01）：
1. 老师端唯一醒目的数字是「本周期总积分」，不展示第二个 0-100 分；
2. 升降级只依据完整周期五维总积分＋必修前置，短期推荐状态不参与；
3. 高积分不能绕过治理：A2-A4 未解除时不得恢复正常推荐或接课。

## 五维积分体系（负向矩阵 V4.1 已确认 · 分值待冻结）

五维：**产能 / 履约 / 用户反馈 / 课堂质量 / 基础任务**。长期与短期共享同一套维度与事实口径，仅时间窗口、标准化与输出不同。

| 维度 | 行为 | 积分 | 关键口径 |
|---|---|---|---|
| 产能 | 体验课完美完课 | +6/节 | 体验课权重高于付费课 |
| 产能 | 付费课完美完课 | +4/节 | 完课且无缺席/迟到/早退；同课同项只记一次 |
| 产能 | Peak 完课 | +2/节 | 可与完美完课叠加 |
| 产能 | 等级 Peak 开课底线 | 达标固定分 | 按晋升目标等级设底线，固定分待回测冻结 |
| 履约 | **NoNotification（真实课中缺席）** | **−100/次** | 严重履约事件，同时触发治理；同一事件只记一次 |
| 履约 | 开课前 24h 内自行缺席 | −10/次 | 24h 外合规请假＝0 分 |
| 履约 | 迟到 / 早退 | 各 −2/节 | 分别扣分、可累计；同课同项只记一次 |
| 用户反馈 | 4/5 分好评 | +5/次 | 真实评价有效，按老师-课程最新记录计一次 |
| 用户反馈 | 1/2 分差评 | −5/次 | 不依赖 appeal 字段；没评价≠差评 |
| 用户反馈 | **收藏 / 拉黑 / 投诉** | **0 / Pending** | **收藏暂不加分**；拉黑待观察；投诉口径未冻结不自动扣分 |
| 课堂质量 | 无质量异常完课 | +4/节 | 已完成且当前接入的质量异常均为 0 |
| 课堂质量 | QA 假早退 / 未开摄像头 / 网络 / CPU | −8/−6/−4/−2 | 同课多项异常分别累计；同课同一项只扣一次 |
| 基础任务 | 月度必修任务 | +10/月（候选） | 未完成必修阻断晋升 |

（源：2026-09-03-成熟老师升降级积分方案-最终确认版.html §02；V4.1 负向矩阵 2026-09-03 确认维持有效）

## 升降级主体机制

- **等级体系**：L1-L14，L14 封顶不再升级（V1.6 明确）。
- **评定周期**：L1-L3 每月 / L4-L8 每两月 / L9-L13 每三月 / L14 按保级观察。
- **升级线**（V2.0 回测校准推荐值）：L2 1,300 → L14 7,800（逐级递增）。
- **降级线**＝当前等级 −2 对应的升级线；确认规则＝连续 2 期低于线 或 深度缺口因子 0.2。L2/L3 降级线待冻结。
- **结算**：次月 1 日 0 点判定生效；升级/降级即时生效、旧等级积分清零重新累计；跨等级不串分；同一事件只记一次。
- **必修前置**：必修任务是晋升必要条件（与积分并列）；未完成必修→阻断晋升。

## 推荐引导（仅引导，不升降级）

内部计算、老师只看状态，不展示第二 0-100 分。健康分＝clamp(0, 100, 每百节净表现÷10)：

- **优先推荐**（健康分 ≥90）：更多匹配机会＋1-3 条建议；
- **正常推荐**（60-89）：正常流量＋改善建议；
- **降权推荐**（<60）：降低曝光，进运营观察；
- **待积累**（30 天课量 <5 节）：保留探索流量，不因低课量降权。

按日滚动（每日 11:00）；不参与 Level 判定、不清零周期积分。

## A0-A4 即时治理

A0 正常 → A1 提醒/召回（AC 触达，不扣分）→ A2 风险限制（降权+异常队列）→ A3 严重风险（暂停新预约 7 天+代课）→ A4 强制止损（停止推荐、冻结授课资格）。熔断流程：T 事实发生（分钟级进队列）→ T+1 召回确认 → T+4 执行动作 → 整改观察 → 恢复回写。执行优先级 A4＞A3＞A2＞短期推荐状态；A2-A4 不直接改 Level、不重复扣分、不清零周期总积分。

## 回测证据（2026-08-27 复算一致）

2026 年 5-7 月 28,550 条老师月记录：升级率观测 7.94%（预测 7.63%）、降级率 3.72%（3.64%）、动作匹配率 80.41%。推荐预测：NN AUC 0.693（时间外 0.692）、发生风险比 7.59×；30 天等权优于旧三维综合分（0.648），近期加权无增益——恢复 30 天等权。
