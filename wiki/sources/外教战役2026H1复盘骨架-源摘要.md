## 三个真问题（上半年表现）

| # | 真问题 | 上半年表现 |
|---|---|---|
| 一 | 新老师到底有没有变好？（薪酬改革生效以来） | 改革前（1-4月）7.85% → 改革后（5-6月）9.95%。有改善，但距目标差距很大 |

## 战役起点（5 个）

1. **后院承压**：够大而不够强，部分好老师流向 Polly；
2. **产能失血**：1-2 月 gap 少招 1400 → Q1 救火；开学季高峰利用率 97% 逼近临界；
3. **组织不整**：部分关键岗位没有负责人，中国侧两大区分别自治；
4. **基建孱弱**：最明显的是数据——Q1 开会基本用 Excel 拼凑数据；
5. **发育不良**：新师首月订课率低。

## 上半年打法逻辑（3+2+1）

以「**B+ 和 A 老师占比达到 15%**」为目标：① 市场投放大幅增加候选人数量；② 老师薪酬改革提升竞争力；③ 新师生匹配推荐系统提升好老师订课率；【补救】Q1 招聘救火；【补救】Q1 组织与基建补坑；【新增】5 月起倾斜产研和运营资源为 Cocos 上线做准备。

## 上半年得与失

### 业务线 · 得

- **救火保产能**：Q1 老师招聘达标率仅 69%（一季度国内高峰期老师订课率 98%）；4 月起招聘达标率恢复到 100%+，4 月底国内高峰期订课率恢复 91%，6 月底 87%。
- **薪酬改革**：老师侧——Polly 一年经验老师课时费起薪 65 比索 vs 51Talk 改革前 50 比索；改革后 51Talk 一年经验老师高峰期起薪 60-62-65 比索、无经验 50-52-54 比索。成本侧——5/6 月单课成本 vs 1-4 月增加 1.9 比索/课（+4%）；Q2 实际对比 Q2 财务模型节省 2.1 比索。老师流失率：【待补充】。
- **市场投放从零到一**：老师上岗交付量 Q1 416 → Q2 1036；师均招聘成本 Q1 5045 比索/launch → Q2 2382 比索/launch；贡献好老师占比和大盘持平。
- **推荐/匹配系统上线并初步验证**（07-07 认子战役三年中成果）：优秀老师利用率 M0 9.16%→80.4%、M1 37.04%→89.4%、M2 45.85%→91.1%；新系统约课复约率 29.7%→44.3%；评价体系重构——中东评价率 15.1%→21.8%（境内 44.4%）、中东好评率 86.4%→90%、差评率 7%→5%；六合一入口；教学视频覆盖 91%（新老师上一节课即生成）、自介视频 <30%→39%。
- **守住新版财务模型**：薪酬改革+大规模投放+财务模型调整+人工救火投入同时进行，财务模型没破。

### 业务线 · 失

- **[没做到] 好老师占比未达标**：目标 15%，实际 1-4 月 7.85% → 5-6 月 9.95%。
- **[没做到] 业务/用户无体感**：没聚焦「向一线和用户输出可感知价值」——「产品包装」只做到素材层（教学视频 91%／自介视频 39%），**营销外化几乎零投入——「有瓶无标签」**；价值前置明显不足。
- **[学费] 规模投放≠好老师**：7月7日复盘认为付费投放未带来预期质量，倾向Referral/回流/品牌；同期薪酬、投放与分发变化并存，尚非普遍渠道因果。

### 组织线

- **得**：架构完备度↑（开打时招聘和转介绍无主、国内运营无头 → 现在招聘 Jen 亲自负责、转介绍中+菲小组作战、中国侧外教运营王东统筹）；资源坚决倾斜 Cocos（从 5 月起，战役协同的组织决断）。
- **失**：战役初期中国侧统筹不足（副帅一号位思维不足，没有强力主张物理组织架构保障强协同）；内部冲突（Cocos 资源调动 + 国内/海外不同关注点引发资源冲突，Leon 作为负责人协调未做到理想——**与上方「得·资源倾斜 Cocos」并读：倾斜的决断是对的，协调是欠的**）。

### 认知线（外教战役与其他战役最大的不同：一边打一边才搞明白怎么打，认知战是真实存在的一条战线）

- **原始认知**：大规模投放+薪酬改革 → 好老师占比大幅提升 → 新版匹配推荐系统 → 业务和客户获得价值。
- **现实反馈**：买量占比提升 2% 远不及格；A/B+≠用户喜好——**B 里出现了被用户投票出来的好老师**（旧尺子看不见的极其振奋的线索）。
- **矫正/探索**：实际课程中能得出「好老师」且用户投票参与；「蜜月计划」F5 初见成效；直通车初见成效。
- **新认知**：①【产品化包装，好老师是售卖点】包装是产品的一部分，对手相信「包装是产品的一部分，可以对用户产生强烈的感知价值」；**被感知的质量 = 质量的一部分**（「视频要领先老师本身实现 B+/A 化」）。②【好老师是系统的产物，不是竞价的结果】好老师 = 感知识别（试用期二次定级）+ 训练 + 匹配 + 反馈激励（蜂巢）出来的，在体量和财务模型下不能简单用钱「买来」；与友商的真实差距在「机制和系统」，不在单点谁愿意付更高课时费。③【真正的领先，是系统领先】老师侧是最适合建设 Agent hive 蜂群组织的战场，弯道超车领先对手进入下一代「以智能体为中心的供应链管理系统」。
- **认知线 · 失**：**[学费] 最大的弯路 = 年初的原始认知（投放+薪酬→好老师），矫正花了半年**；**[学费]⭐⭐「自恋的北极星」**——选用户指标是第一反应（对的），但操作难度大、不好衡量，远不如内部指标（B+/A 占比）容易，于是「妥协」了；**最大的 learning：认定对的方向，就不要考虑难易度。没有选择「难而正确」，最后付出的代价比选择还大**——用 B+/A 当质量指标跑了一个季度，才发现这是一颗自恋的北极星；**[学费] 一考定终身**：把 A/B+ 初评当终审用了半年。

## 探索（上半年局部亮点）

1. 【所买即所见】**直通车（体验课老师直约付费课）**：已实现、国内开始试点——选老师转化率 转介绍 22.8% vs 系统分配 16%，小红书 13.2% vs 8.8%——**两个渠道切片中直约较高，缺样本与实验口径，不能据此认定净增或批准放量**（后续载体见 [直通车项目](../projects/%E7%9B%B4%E9%80%9A%E8%BD%A6%E9%A1%B9%E7%9B%AE.md) （[A](https://alidocs.dingtalk.com/i/nodes/G53mjyd80p2oeG7PcejMdKeo86zbX04v) · [Leon](https://alidocs.dingtalk.com/i/nodes/nYMoO1rWxaZnB3GdI9qL1KrqV47Z3je9)））。
2. 【蜜月可干预】**F5（新生前 5 节课特别关注）**：压「四害」、护蜜月期，已取得初步积极信号。
3. 【培训局部进展】**Center 培训（B → B+ 提升）**：以 TPCAP 中心老师为触点，4 试点中心 + CQH（Center Quality Head，中心质量负责人）机制——每日课堂抽查/视频审核/培训督促，只做事后反馈不打断教学；已实现自动取数 + 钉钉自动建任务派发；考核合格者课时费显著上调（与 PGTM 同构）。过程数据：必学培训完成率 98.4%（目标 99%+）、测试 center 质检完成率 58%、CE 抽检通过率 50%（10 节中 5 节达 B+）。

## 下半年打法（2026-07-07 时的重构方向，已被 07-13 H2 总纲演进）

**围绕「客户价值」+「决战下一代」重构战役**：

- **分战役一 · 建设「新师训练营」：从「一考定终身」到「看实战表现」（把尺子交给客户）**。新认知：好老师来自**四维真实表现**（教学硬件 + 教学技巧 + 教学行为 + 学生反馈），靠系统——招聘筛选 → 试用期反馈 → 月度激励 → 持续培训——持续发掘和培养。三层漏斗：合格招入 = 现行上岗标准 = 2000 人；试训毕业 = 30 天试用期合格 = 1400 人；表现优秀 = 四维评价高分 = 500 人。30 天四维打分：教学硬件（CPU+网络+教学环境与仪表）、教学技巧（CE demo 和 QA 分数）、教学行为（四害）、学生反馈（复约/收藏/好评/固定 + 投诉/固定解绑）。
- **分战役二 · 价值前置**（指向体验客户/新客户价值）：强化老师包装，和对手争夺「好老师宣传制高点」；直通车放量（国内→港澳→中东）；蜜月 F5 放量。
- **分战役三 · 匹配推荐**（指向付费客户/老客户价值）：推荐引擎全铺（关旧入口/全量铺开）；尾部老师「雪藏」。
- **决战下一代 · Agent Hive 建设试点**：完成 agent 可直读的数据集建设；完成「试用期监控-培训-沟通」三个系统组成的智能体群；月度版升降级规则、升快降慢。**「外教端蜂巢系统」四环：感知 / 评价-沟通 / 流量-培训 / 激励**——这一套系统是未来外教供应链的核心资产。
